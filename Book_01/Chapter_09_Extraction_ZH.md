## 1. 本章论点

随机性看似理性的反面——一种最后的手段——但计算机科学表明，它是一件刻意运用、威力强大、有时甚至**不可
或缺**的解题工具。随机化算法能比任何已知的确定性方法更快地给出好的近似答案；即便面对严格的是/否问题（这
个数是素数吗？），掷几枚骰子也能胜过穷尽式推理。本章的实用主线为：**抽样**（蒙特卡洛）让过于复杂而无法
精确计算的问题变得可解——从核物理到公共政策；**随机化检验**（米勒–拉宾）以微乎其微的一点确定性换取极大
的速度，揭示出确定性本身是可与时间、空间相权衡的第三种资源（布隆过滤器）；而**战术性随机**（抖动、随机
重启、大都会算法、模拟退火）则是在优化、创造与人生中逃出"局部最大值"——那些好但非最优的解——的办法。用
好随机的准则是：永远执行好点子；对坏点子的采纳意愿应与其糟糕程度成反比；并且要前置随机、随时间冷却。

## 2. 核心概念

```
概念名称：随机化算法（Randomized Algorithms）
定义：使用随机生成的数来解题的算法，与每一步每次都完全相同地推进的确定性算法相对。
为何重要：它们能比所有已知确定性算法更快地给出困难问题的好近似解；对某些问题更是唯一已知的高效途径。
作者如何使用：本章的组织性主线；每种技术（蒙特卡洛、米勒–拉宾、布隆过滤器、大都会）都是随机化算法。
相关概念：抽样、蒙特卡洛、错误概率、战术性随机。
```

```
概念名称：抽样 / 蒙特卡洛方法（Sampling / The Monte Carlo Method）
定义：通过从复杂量中随机抽样并观察结果来估计它，而非穷尽计算每一种可能。
为何重要：当可能性空间爆炸时（纸牌接龙、核反应、政策），抽样"至少给你一个答案，而别的方法什么都给不了"。
作者如何使用：布丰投针 → 拉普拉斯估计 π → 乌拉姆的接龙洞见 → 蒙特卡洛方法（乌拉姆、冯·诺依曼、梅特罗波
利斯）→ 公共政策与慈善（GiveDirectly）。
相关概念：随机化算法、组合爆炸、无知之幕。
```

```
概念名称：随机化素性检验（米勒–拉宾）
定义：对随机取值 x 检验米勒方程来判断一个数是否为素数；每一个通过检验的随机"见证"都把假阳性的概率削减到
四分之一。
为何重要：一个严格的是/否问题，靠随机比靠确定性因式分解快得多；它支撑着几乎所有在线安全。
作者如何使用：旗舰例子，说明即使在"看似毫无随机成分"之处随机也有用；四十次应用便把错误压到低于一千万亿
亿分之一。
相关概念：单向函数、密码学、错误概率、布隆过滤器。
```

```
概念名称：确定性 / 错误概率权衡
定义：在熟悉的时间–空间权衡之外，随机化算法新增第三维——你可以以一点小概率的错误换取时间和空间的节省。
为何重要：把计算（与人生）重构为常常在与"大概正确"而非"保证正确"的答案打交道；"没有绝对确定，但有足以应
付人生的把握"（密尔）。
作者如何使用：米岑马赫的表述；布隆过滤器为具体案例（容忍 1–2% 错误以省下巨量时间和空间）。
相关概念：布隆过滤器、米勒–拉宾、消极感受力。
```

```
概念名称：布隆过滤器（Bloom Filters）
定义：一种概率数据结构，能快速且紧凑地回答"我以前见过它吗？"，代价是一点小的假阳性率——工作方式与米勒–拉
宾类似，只是检验的是"新颖性"的见证。
为何重要：以确定性换时间和空间在大规模下的典型实例（一万亿个 URL）；用于搜索引擎抓取、浏览器恶意网址名
单和比特币。
作者如何使用：米岑马赫最爱的错误权衡例子。
相关概念：错误概率、米勒–拉宾、抽样。
```

```
概念名称：爬山法与局部最大值（Hill Climbing and Local Maxima）
定义：一种优化策略，反复做小的改动并保留任何改进，把解想象成有山有谷的地形；它止步于"局部最大值"——一个
胜过所有邻居、但可能仍低于全局最优的山峰。
为何重要：为一个普遍的陷阱命名——一个无法靠增量改进的好但非最优解，"一个用铁丝做成、会致命的局部最大
值"（龙虾笼）。
作者如何使用：十城度假（旅行商）问题；引出"为什么有时必须接受更差的解才能找到更好的"这一铺垫。
相关概念：贪心算法、全局最大值、抖动、大都会算法、模拟退火。
```

```
概念名称：用随机逃出局部最大值
定义：三种战术——抖动（卡住时做几次随机小改动）、随机重启／"霰弹式"爬山（打乱重来）、大都会算法（以与糟
糕程度成反比的概率接受坏改动）。
为何重要：要找到更好的解，往往必须先暂时接受更差的；随机就是办法——很多时候不只是可行，而是必需。
作者如何使用：度假规划、密码破译；通往模拟退火的桥梁。
相关概念：爬山法、大都会算法、模拟退火、创造力。
```

```
概念名称：模拟退火（Simulated Annealing）
定义：把优化问题当作材料的物理退火来处理——从"高温"（完全随机）开始，再缓慢"冷却"（越来越少地接受更差的
移动），在"冰点"附近停留最久。
为何重要：对"用多少随机、何时用"给出近乎确定的答案——前置随机、逐渐减弱；至今仍是该领域最有前景的优化方
法之一。
作者如何使用：柯克帕特里克在 IBM 的芯片布局算法击败了人类"大师"；发表于《科学》（被引 3.2 万次）。由此
得出用随机的三条人生准则。
相关概念：大都会算法、温度即随机、爬山法、《骰子人》。
```

```
概念名称：随机性、进化与创造力
定义：同一个"随机生成、择优保留"的过程支撑着生物突变、科学发现与人类创造力——"盲目变异与选择性保留"。
为何重要：把随机定位为具有生成性，而非仅是计算技巧；创造力就是通过"被抛出画框"来逃出局部最大值。
作者如何使用：卢里亚的老虎机洞见（突变对反应）；意外发现；威廉·詹姆斯与唐纳德·坎贝尔；迂回策略卡片；维基
百科随机条目；CSA 蔬菜箱。
相关概念：模拟退火、局部最大值、意外发现、抖动。
```

```
概念名称：随机的三条人生准则
定义：(1) 出自爬山法——永远执行好点子。(2) 出自大都会算法——你追随一个坏点子的可能性应与其糟糕程度成反
比。(3) 出自模拟退火——前置随机，随时间冷却，越接近"冰点"停留越久。
为何重要：把本章的算法化为具体指引，也纠正了《骰子人》"把随机注入一切"的荒唐。
作者如何使用：全章综合，以科克罗夫特安顿于一个幸福的"局部最大值"作例。
相关概念：爬山法、大都会、模拟退火、"锤炼你自己"。
```

## 3. 关键论断

```
论断：在某些问题上，随机化算法能胜过最好的确定性算法。
类型：理论
所给证据：随机化算法比所有已知确定性算法更快给出好的近似解；对多项式恒等检验，随机是唯一已知的高效途径。
支持强度：强。作为既有结论陈述；素性与多项式恒等两例具体。
```

```
论断：可以通过从复杂量中抽样来估计它。
类型：理论（拉普拉斯）
所给证据：布丰投针（1777）——短于线间距的针与线相交的概率为 2/π × 针长/间距；拉普拉斯（1812）指出由此可
以靠投针来估计 π。
支持强度：对原理为强。脚注坦承某些手工 π 估计（拉扎里尼，1901）好得可疑、很可能造假——一处诚实的告诫。
```

```
论断：在足够复杂的问题中，抽样胜过分析所有可能。
类型：诠释 / 经验（乌拉姆）
所给证据：乌拉姆放弃了接龙的组合计算（80 unvigintillion 种牌序），改为直接玩来估计可赢比例；同一洞见解决
了洛斯阿拉莫斯的核物理分支过程，成为蒙特卡洛方法。
支持强度：强。"更好"意为它至少给得出答案——抽样有误差，但可通过取更多、真正随机的样本来减小。科学计算的
基石。
```

```
论断：即便对严格的是/否问题（如素性检验），随机也有帮助。
类型：理论（米勒–拉宾）
所给证据：n 若为素数，米勒方程恒真；n 若非素数，则至多四分之一的随机 x 会给出假阳性，故每个随机见证都把
假阳性概率削减四倍——十次检验 → 低于百万分之一；十五次 → 十亿分之一；四十次 → 低于一千万亿亿分之一。
支持强度：强。有证明的界与精确数字；它是已部署密码学中的标准方法。
```

```
论断：素数相乘容易但因式分解难——一个支撑密码学的"单向函数"。
类型：理论 / 历史
所给证据：把千位素数相乘只需一瞬，分解其乘积却可能要数百万年。素数研究曾是"最明显无用的分支"（哈代），
直到 20 世纪的密码学。埃拉托斯特尼筛法有效但不高效（要用 √n 以下的素数去除：六位数需 168 个素数，十二位
数需 78,498 个）。
支持强度：强。有具名历史与具体计数。
```

```
论断：一种高效的确定性素性检验已存在（2002），但随机化的仍更快、至今仍在使用。
类型：历史 / 经验
所给证据：Agrawal、Kayal 与 Saxena（IIT，2002——AKS 检验）证明确定性素性判定属多项式时间，但米勒–拉宾在
实践中快得多。
支持强度：强。精确、有年份的结论，并附上"理论≠实践"的注脚。
```

```
论断：确定性是第三种资源，可与时间、空间相权衡（错误权衡）。
类型：理论（米岑马赫）
所给证据：布隆过滤器对一万亿个 77 字符的 URL 回答"我见过这个吗？"，同时容忍 1–2% 的错误，从而省下巨量时
间和空间；用于浏览器（恶意网址名单）和比特币。
支持强度：强。一种具名、已部署的技术；把错误概率当作一个维度的表述是明确的。
```

```
论断：抽样是理解过于复杂而无法整体把握之问题的最佳方式——包括公共政策。
类型：诠释
所给证据：罗尔斯的无知之幕在计算上不可解（仅评估一条受伤的胫骨横跨所有保险方案就已令人不堪重负；阿伦森
的 10 对 10¹⁰¹⁰ 秒表明量的差距成了质的差距）。精挑的轶事不具代表性；汇总统计单薄且掩盖异质性（奥梅拉斯
式）。随机抽样（GiveDirectly 每周三随机受访、逐字发布）能切开难题。
支持强度：中到强。一套严谨的复杂性论证外加一个真实慈善做法；从蒙特卡洛跃到政策评估是作者的诠释性提议。
```

```
论断：爬山法会困在局部最大值；你有时必须先让解变差才能改进它。
类型：理论
所给证据：十城度假（10! = 350 万条行程）；贪心/短视选择与两城对调达到一个胜过所有邻居、却可能低于全局最
优的局部最大值；龙虾笼是"一个用铁丝做成、会致命的局部最大值"（要逃出必须往更深处走）。
支持强度：强。干净的形式化，加上生动而在生物上真实的图景。
```

```
论断：随机——抖动、随机重启或大都会算法——是逃出局部最大值的办法，且常常必不可少。
类型：理论
所给证据：抖动（卡住时做随机小改动）；霰弹式/随机重启爬山（打乱重来，在局部最大值众多时很有效，如密码破
译）；大都会算法（以与变差程度成反比的概率接受一个更差的改动）。
支持强度：强。具名技术，机制清晰。
```

```
论断：模拟退火回答了"用多少随机、何时用"：前置随机，再缓慢冷却。
类型：理论 / 经验
所给证据：物理退火——缓冷得到晶体，急冷得到有缺陷的玻璃；柯克帕特里克把温度即随机映射到 IBM 芯片布局，
击败了人类"大师"；发表于《科学》，被引约 3.2 万次，至今仍属该领域最有前景的方法之一。
支持强度：强。一个具名、被高频引用、已部署的结论，附具体成功案例。
```

```
论断：同一个随机生成／择优保留的过程驱动着进化、发现与创造力。
类型：诠释 / 历史
所给证据：卢里亚的老虎机洞见区分了偶然突变（不均、如中大奖的谱系）与定向反应（均匀）——一项关于机遇、也
因机遇而生的诺奖发现；意外发现（沃波尔，1754）；威廉·詹姆斯（1880，"随机意象……环境作出选择"）与唐纳
德·坎贝尔（1960，"盲目变异与选择性保留"）；马赫与庞加莱（"保留了对的那些"）。
支持强度：中到强。一条有充分支撑的思想脉络；创造力论断是一种心智理论，而非可测结果。
```

```
论断：刻意的随机刺激有助于逃出创造性／实用的局部最大值——但纯粹随机是愚行。
类型：规范 / 诠释
所给证据：迂回策略卡片（伊诺与施密特）；维基百科随机条目；CSA 蔬菜箱；每月读书/品酒/巧克力俱乐部。反面告
诫：《骰子人》（莱因哈特／科克罗夫特）——万事掷骰终酿祸。三条人生准则纠正之；科克罗夫特本人最终冷却进一
个幸福的局部最大值（"你就傻了才会再去搅动它"）。
支持强度：中。具体可采纳的做法外加一个自省的告诫例；"准则"是作者对这些算法的综合。
```

## 4. 框架、模型与思维模型

```
名称：蒙特卡洛方法
描述：以随机样本模拟取代穷尽式概率计算。
组成：一个可模拟的生成过程（发牌、模拟粒子碰撞）；许多次随机试验；观察到的各结果比例。
运作方式：把过程随机跑很多次并统计结果；样本越多、越真随机，估计越好（它带有抽样误差，但在分析给不出答
案处能给出答案）。
适用时机：本身即概率性的问题（接龙、裂变），以及太棘手而无法直接计算的复杂确定性问题（政策、积分）。
局限：近似，带抽样误差；需要真正随机的样本。
```

```
名称：米勒–拉宾素性检验
描述：以概率方式认证一个巨大数为素数。
组成：以 n 和 x 表示的米勒方程；随机检验值 x（"见证"）；一个重复次数。
运作方式：每个满足方程的随机 x 都把假阳性概率削减四倍；k 次检验给出 ≤ (1/4)ᵏ 的错误。四十次检验 → 错误
低于一千万亿亿分之一。
适用时机：密码学——寻找／检验支撑安全通信的巨大素数。
局限：绝不会是绝对确定（只是"快得惊人地接近"确定）；有确定性替代（AKS，2002）但更慢。
```

```
名称：错误 / 确定性权衡（布隆过滤器）
描述：以一小的、有界的错误概率换取时间和空间的大幅节省。
组成：一个概率数据结构；一个可容忍的错误率；一个成员查询（"以前见过吗？"）。
运作方式：与米勒–拉宾一样，把项散列进检验"见证"的方程；一个小的假阳性率（1–2%）极大压缩了存储与查找。
适用时机：大规模去重、恶意网址检查、加密货币——凡"大致确定"就够用之处。
局限：有假阳性（成员判断绝无假阴性）；你必须接受偶尔出错。
```

```
名称：爬山法（及其地形）
描述：反复取最好的小改动来改进解；止步于没有邻居能胜过的山峰。
组成：一个解；一组小扰动（如十一种两城对调）；一个由山和谷构成的误差/质量地形。
运作方式：贪婪地往上爬，直到没有相邻移动能改进——一个局部最大值，它可能不是全局最大值（"雾中地形"）。
适用时机：空间巨大（10! 条行程）时的快速优化基线。
局限：困在局部最大值；"一个用铁丝做成、会致命的局部最大值"（龙虾笼）。
```

```
名称：大都会算法
描述：会有时接受更差移动的爬山法，其接受概率与移动变差的程度成反比。
组成：随机小改动；改进总是接受；变差以随变差增大而缩小的概率接受。
运作方式：在*每一次*决策处都用一点随机，使你不会长久困在局部最大值；由洛斯阿拉莫斯的蒙特卡洛团队提出——
该算法最初是为模拟物理系统的随机行为（当时是核爆炸）而设计的。
适用时机：局部最大值众多的优化地形；模拟退火的基础。
局限：可以无休止地排列——本身没有停止规则（模拟退火提供之）。
```

```
名称：模拟退火
描述：为随机设一张冷却进度表——从完全随机（"高温"）开始，随时间逐渐减少对更差移动的接受（"冷却"），在
"冰点"附近停留最久。
组成：一个随时间递减的温度参数（接受更差移动的概率）；大都会式的改动。
运作方式：对每个变差的改动掷骰，只在越来越高的阈值上接受（先 2+，再 3+，……，最后只往上走），对应缓慢
的物理冷却——得到有序晶体而非有缺陷的玻璃。（物理中的"温度"其实是速度——分子尺度的随机运动——恰与爬山
法加入的抖动相类；它所基于的大都会算法最初是为模拟核爆炸而造的。）
适用时机：困难优化（芯片布局、调度）；对"用多少随机、何时用"给出近乎确定的答案。
局限：需选定冷却进度表；仍是启发式，不保证最优。
```

```
名称：随机的三条人生准则
描述：如何在人生中用随机而不沦为骰子人。
组成：(1) 永远执行好点子（爬山法）；(2) 以与其糟糕程度成反比的概率追随坏点子（大都会）；(3) 前置随机、随
时间冷却（模拟退火）。
运作方式：把这些算法融为一种性情——早年大胆，后期收敛，"锤炼你自己，字面意义上的"。
适用时机：人生决策、创造力、逃出窠臼。
局限：一种定性综合，而非公式；一段人生的"冷却进度表"未被给出。
```

## 5. 研究与证据

```
研究：布丰投针与拉普拉斯估计 π
研究者：布丰伯爵（乔治-路易·勒克莱尔，1777）；皮埃尔-西蒙·拉普拉斯（1812）
年份：1777 / 1812
研究问题：一根落下的针与一条划线相交的可能性有多大——并能否借此估计 π？
方法：几何概率；拉普拉斯提议靠实际投针并数相交次数来估计 π。
关键发现：短于间距的针以 2/π × (针长/间距) 的概率相交；抽样能估计一个复杂量。
作者如何使用：抽样／蒙特卡洛的历史种子。
重要局限：手工估计 π 虽可行但低效。
提及的重复或争议：脚注——拉扎里尼 1901 年的估计（π ≈ 355/113 = 3.1415929）好得可疑；只要少一次相交结果
就会走样，暗示它被提前截断或造假（可用贝叶斯法则证实）。
```

```
研究：蒙特卡洛方法
研究者：斯坦尼斯瓦夫·乌拉姆、约翰·冯·诺依曼、尼古拉斯·梅特罗波利斯（洛斯阿拉莫斯）
年份：1946 年起
研究问题：如何计算那些可能性爆炸、无法精确算尽的过程的结果（接龙可赢性；核反应分支）？
方法：用随机抽样模拟过程，而非枚举所有可能性链。
关键发现：在穷尽分析不可能之处，抽样给出可用估计；以摩纳哥赌场命名为"蒙特卡洛"。
作者如何使用：随机化科学计算的起源与基石。
重要局限：近似；有抽样误差。
提及的重复或争议：无；如今是科学计算的基石。
```

```
研究：随机化素性检验（米勒–拉宾）
研究者：加里·米勒（伯克利博士，确定性但不可靠的方程）；迈克尔·拉宾（随机化与错误界）；沃恩·普拉特（实现）
年份：1970 年代中期（拉宾 1975 年 MIT 学术休假）
研究问题：如何高效检验巨大数的素性？
方法：对随机 x 检验米勒方程；非素数至多对四分之一的 x 给出假阳性，故重复能把错误逼向零。
关键发现：又快又能任意高置信；普拉特午夜运行发现 2⁴⁰⁰−593 为素数及当时已知最大的孪生素数。现代密码学把
错误调到低于一千万亿亿分之一（40 次应用）。
作者如何使用：旗舰"随机用于是/否问题"案例；笔记本、手机和信用卡的安全支柱。
重要局限：绝无绝对确定。确定性检验（AKS，2002）存在但更慢。
提及的重复或争议：一个数能"大概是素数"所引发的哲学不安。
```

```
研究：模拟退火
研究者：斯科特·柯克帕特里克与丹·格拉特（IBM），在大都会算法基础上
年份：1970 年代末–1980 年代初
研究问题：退火物理（缓慢冷却）能否指导优化——具体是 IBM 芯片电路布局？
方法：把各自由度当作原子/自旋；"加热"问题（随机起点），再缓慢"冷却"（越来越少接受更差移动）。
关键发现：退火算法击败了 IBM 的人类布局"大师"；发表于《科学》，被引约 3.2 万次；至今属最有前景的优化方法
之一。
作者如何使用：对"用多少随机、何时用"的确定性回答，以及"前置随机再冷却"这条人生准则的出处。
重要局限：数学家起初不信这个"太隐喻"的类比；需要一张冷却进度表。
提及的重复或争议：传统优化研究者最初的怀疑，随后被广泛采用。
```

```
研究：卢里亚"波动"洞见（突变对反应）
研究者：萨尔瓦多·卢里亚（本章未点名任何合作者）
年份：1943
研究问题：细菌抗性是对病毒的定向反应，还是源于先前的随机突变？
方法：培育多个细菌谱系，将末代暴露于病毒；比较抗性菌落的*分布*——均匀（反应）对不均/如中大奖（随机突
变），灵感来自看老虎机。
关键发现："中大奖"——抗性分布不均，像老虎机赔付，证明抗性源于先前的随机突变。（带来一项诺贝尔奖。）
作者如何使用：随机在生物学中的生成性，以及意外发现（一项*因机遇而生*的发现）。
重要局限：一项里程碑式实验；本章以发现叙事讲述。
提及的重复或争议：未发现；被表述为一项诺奖级结论。
```

```
研究：随机—选择的创造力理论
研究者：威廉·詹姆斯（1880，《伟人、伟大思想与环境》）；唐纳德·坎贝尔（1960，《盲目变异与选择性保
留》）；并引恩斯特·马赫与亨利·庞加莱
年份：1880 / 1960
研究问题：人类创造力与知识增长的机制是什么？
方法：以达尔文进化为类比论证——随机产生想法，再择优保留。
关键发现："盲目变异与选择性保留的过程，是一切……真正知识增长的根本"（坎贝尔）；创造力在如"翻腾的思想大
锅"般的心智中被放大（詹姆斯）。
作者如何使用：把"逃出局部最大值"这一主题扎根于一个百年之久的创造力理论，并为刻意随机刺激作铺垫。
重要局限：一种类比式的心智理论，而非经验测量。
提及的重复或争议：被呈现为一条反复出现、相互印证的思想脉络。
```

## 6. 实验

```
实验名称：乌拉姆的接龙抽样（由思想转为方法）
设置：估计洗好的接龙牌（Klondike）能赢一局的概率。
参与者：无——乌拉姆本人，在康复中。
过程：与其枚举约 80 unvigintillion 种牌序，不如直接玩很多局并记录赢的比例。
结果：在穷尽组合无望处得到可用估计——推广为用于核物理的蒙特卡洛方法。
诠释：在足够复杂的问题中，实际抽样胜过分析所有可能性链。
它证明了什么：在分析给不出答案处，抽样至少给得出答案。
可能的另类解释：抽样带误差且需真随机洗牌；本章明确"更好"指"能给出答案"，而非"更精确"。
```

```
实验名称：卢里亚波动实验
设置：把许多独立细菌谱系培育数代，再将末代暴露于病毒。
参与者：细菌培养物。
过程：比较各谱系间抗性菌落的分布：若抗性是对病毒的反应则均匀；若源于先前随机突变则不均/如中大奖。
结果：中大奖——高度不均，像老虎机赔付，指向先前的随机突变。
诠释：抗性源于偶然突变而非定向反应——进化遗传学的一项奠基结论。
它证明了什么：一个结果的*分布*（而非仅其平均）能揭示其因果机制。
可能的另类解释：本章讲述干净的结果；现实中该推断依赖严谨的对照与统计（此处未详述）。
```

## 7. 案例与故事

```
案例标题：布丰投针 → 拉普拉斯的 π（及拉扎里尼的造假）
人物 / 机构：布丰（1777）；拉普拉斯（1812）；马里奥·拉扎里尼（1901）
背景：以抽样估计一个量的起源。
发生了什么：布丰证明落针以 2/π × 针长/间距的概率与划线相交；拉普拉斯看出可借投针估计 π。后来的手工尝试
证实其可行但低效——而拉扎里尼 1901 年的估计（π ≈ 355/113，正确到七位）好得离谱，只要少一次相交就会破
功，故被视为很可能被截断或造假。
结果：蒙特卡洛的种子——外加一则关于"结果好得可疑"的告诫。
所示概念：抽样；（附赠）用贝叶斯法则识破一个造假实验。
为何此案例有用：一个迷人的起源故事，自带一堂关于可疑洁净数据的课。
复用潜力：高
```

```
案例标题：斯坦·乌拉姆、接龙与原子弹
人物 / 机构：斯坦尼斯瓦夫·乌拉姆；约翰·冯·诺依曼；尼古拉斯·梅特罗波利斯（洛斯阿拉莫斯）
背景：乌拉姆是曼哈顿计划的数学家，脑手术后康复中、担心自己丧失了能力，玩了大量接龙。
发生了什么：无法用组合算出可赢比例（80 unvigintillion 种牌序），他意识到可以直接*玩*并计数——即抽样。同
一想法攻克了核反应分支过程；他与冯·诺依曼、梅特罗波利斯一起把它做成蒙特卡洛方法（以摩纳哥赌场命名）。
结果：科学计算的一块基石，诞生于一个康复者的纸牌游戏。
所示概念：蒙特卡洛抽样；分析失败时，就模拟。
为何此案例有用：一个生动、有人情味的起源故事，串起纸牌、疾病、原子弹与现代计算。
复用潜力：高
```

```
案例标题：米勒、拉宾与午夜的素数
人物 / 机构：加里·米勒；迈克尔·拉宾；沃恩·普拉特
背景：检验巨大数是否为素数——密码学的支柱。
发生了什么：米勒的快速方程会给出假阳性；拉宾证明非素数至多骗过四分之一的随机取值，故用随机 x 反复检验会
把错误逼向零。普拉特实现了它，午夜时分在拉宾的光明节派对上来电：2⁴⁰⁰−593 是素数，且他发现了当时已知最大
的孪生素数。"我汗毛都竖起来了，简直难以置信。"
结果：米勒–拉宾检验——又快又能任意高置信——如今运行在几乎所有安全在线通信背后。
所示概念：随机化算法；确定性对速度的权衡；素数作为单向函数。
为何此案例有用：一个戏剧性的顿悟时刻，系在每一部手机和每一笔信用卡交易之上。
复用潜力：高
```

```
案例标题：布隆过滤器与万亿 URL 的网络
人物 / 机构：迈克尔·米岑马赫（哈佛）；伯顿·H. 布隆（发明者）
背景：搜索引擎如何避免重复处理已抓取过的页面。
发生了什么：存储并搜索一份一万亿个 77 字符 URL 的名单代价惊人——"药比病更糟"。布隆过滤器改为以概率方式回
答"我见过它吗？"（像米勒–拉宾那样检验新颖性的见证）；容忍 1–2% 的错误便省下巨量时间和空间。
结果：布隆过滤器随浏览器出货（恶意网址检查），并支撑比特币的一部分；确定性是可权衡的第三维。
所示概念：错误权衡；概率数据结构。
为何此案例有用：把一个抽象权衡在网络规模上具象化，并有日常部署。
复用潜力：高
```

```
案例标题：罗尔斯的无知之幕遇上计算复杂性
人物 / 机构：约翰·罗尔斯；斯科特·阿伦森（MIT）；厄休拉·勒古恩（奥梅拉斯）
背景：一个正义社会应最大化自由还是平等——靠想象你不知将生为谁来评判。
发生了什么：本章指出无知之幕在计算上不可解——仅评估一条受伤的胫骨横跨所有保险方案就已令人不堪重负；阿伦
森论证复杂性的量的差距（10 对 10¹⁰¹⁰ 秒；读一本书对读每一本可能的书）实为质的差距。罗尔斯的批评者也争论
该最大化哪种幸福（勒古恩的奥梅拉斯即藏在汇总数字里的反乌托邦）。
结果：计算机科学既道出了这一困难，又给出一件工具——抽样。
所示概念：复杂性作为哲学概念；抽样作为回应。
为何此案例有用：连接政治哲学与计算机科学；一次罕见而发人深省的跨界。
复用潜力：高
```

```
案例标题：GiveDirectly 的随机周三访谈
人物 / 机构：GiveDirectly（无条件现金转移，肯尼亚/乌干达）；丽贝卡·兰格
背景：慈善机构展示精挑的成功故事，而这些不具代表性。
发生了什么：精挑的轶事生动却有偏；汇总统计全面却单薄，掩盖异质性（某群体奥梅拉斯式地陷入绝境）。
GiveDirectly 改为每周三随机选一名受助者、采访、并逐字发布记录"无论内容如何"——首位是买了铁皮屋顶的玛丽。
（脚注：他们刻意取了第一个故事，而非精挑的故事。）
结果：随机抽样作为透明与说真话的做法，纠正选择偏差。
所示概念：抽样对轶事对汇总；代表性。
为何此案例有用：一个真实、有伦理共鸣的抽样应用，用于沟通与问责。
复用潜力：高
```

```
案例标题：十城度假与龙虾笼（局部最大值）
人物 / 机构：作者（示例）
背景：规划一次成本最小的十城之旅——一个 10! = 350 万条行程的旅行商问题。
发生了什么：贪心/短视算法（下一段选最便宜航班）给出基线；爬山法（试全部十一种两城对调、保留最优）改进它，
直到没有邻居能胜过——一个*局部*最大值，未必是全局最优（"雾中地形"）。龙虾笼是"一个用铁丝做成、会致命的
局部最大值"：龙虾必须往笼子*更深处*走才能逃出。
结果：你有时必须先让解暂时变差才能继续改进——这正是随机所能促成的。
所示概念：爬山法；贪心算法；局部对全局最大值。
为何此案例有用：一个可共情的规划问题，加上一个难忘、在生物上真实的致命局部最大值图景。
复用潜力：高
```

```
案例标题：柯克帕特里克击败 IBM 芯片布局大师（模拟退火）
人物 / 机构：斯科特·柯克帕特里克；丹·格拉特（IBM）；匿名布局"大师"
背景：在 IBM 芯片上布线——难解，且有棘手的邻近约束。
发生了什么：IBM 最强的布局专家是个"神秘大师"，不肯讲解方法。统计物理学家柯克帕特里克把温度即随机映射到该
问题：加热（随机起点），缓慢冷却（越来越少接受更差移动）。数学家不信这个"太隐喻"的类比——直到退火算法在
布局上胜过了大师。柯克帕特里克与格拉特没有藏私自封为大师，而是发表于《科学》（被引约 3.2 万次）。
结果：模拟退火成为该领域最有前景的优化方法之一；开放胜过藏私。
所示概念：模拟退火；物理到优化的类比；发表的价值。
为何此案例有用：一个"大卫对大师"的故事，带着关于开放与隐喻的干净寓意。
复用潜力：高
```

```
案例标题：卢里亚、老虎机与意外发现
人物 / 机构：萨尔瓦多·卢里亚；（造词者）霍勒斯·沃波尔
背景：细菌抗性是反应还是随机突变——卢里亚本无法检验。
发生了什么：在老虎机旁揶揄同事时，卢里亚看他中了大奖，忽然意识到突变与老虎机可以互相启发：偶然突变会使各
谱系间抗性*不均*、像中大奖，定向反应则均匀。他尽早离开舞会、启动实验——中大奖——后来得了诺贝尔奖。沃波尔
早已造出"serendipity"（意外发现，1754）一词，恰指这种既偶然又机敏的发现（源自《锡兰三王子》= 斯里兰卡）。
结果：一项*关于*机遇、又*因*机遇而生的发现。
所示概念：随机在进化中的作用；意外发现；分布揭示机制。
为何此案例有用：一个双重随机的故事（既在生物学里、又在发现之中），外加"serendipity"的词源。
复用潜力：高
```

```
案例标题：迂回策略、随机条目与《骰子人》
人物 / 机构：布莱恩·伊诺与彼得·施密特（迂回策略）；汤姆·格里菲思（维基百科随机条目）；卢克·莱因哈特／乔
治·科克罗夫特（《骰子人》）
背景：刻意注入随机以逃出创造性与实用的局部最大值——及其限度。
发生了什么：伊诺与施密特的迂回策略卡片给出随机的新视角（"把你抛出画框"）；汤姆把维基随机条目设为主页（还
借此明白了随机真正的样子——"巧合"感觉比概率所应有的更频繁）。CSA 蔬菜箱与每月俱乐部让饮食与文化随机化。但
《骰子人》（万事掷骰）是则告诫；作者科克罗夫特也"掷骰"过一阵，在"布朗运动式的慢动作"中漂泊，随后冷却进纽
约州北部一个湖畔的幸福局部最大值——"你就傻了才会再去搅动它"。
结果：随机刺激助你逃出窠臼；纯粹随机是愚行。由此有三条人生准则。
所示概念：逃出局部最大值；三条人生准则；校准对真随机的感知。
为何此案例有用：一簇可采纳的做法外加一个自省的告诫，把本章的算法系回日常生活。
复用潜力：高
```

## 8. 最佳教学范例

```
概念：可能性爆炸时抽样胜过分析
范例：乌拉姆算不出接龙的可赢比例（80 unvigintillion 种牌序），于是干脆玩很多局并计数。
为何有效：一个人人熟悉的游戏，让"用模拟代替枚举"立刻变得直观。
可能的另一领域：数学
```

```
概念：对是/否问题用随机（米勒–拉宾）
范例：每个通过检验的随机"见证"都把这个数暗中是合数的概率削减四倍；十次检验 → 低于百万分之一。
为何有效：一次利落、可量化的疑虑消解，展示随机如何对确定性问题给出近乎确定的答案。
可能的另一领域：商业
```

```
概念：确定性权衡（布隆过滤器）
范例：为避免重复处理一万亿个网页，接受 1–2% 的错误率，从而省下巨量时间和空间。
为何有效：一个"大致确定"显然够用的网络规模问题，让第三个权衡维度变得可感。
可能的另一领域：商业
```

```
概念：抽样行为，别拆解机制（多项式恒等检验）
范例：要检验 2x³ + 13x² + 22x + 8 是否等于 (2x+1)(x+2)(x+4)，不必全部乘开——代入随机 x；在若干随机输入上
都相等将是越来越大的巧合。同理，面对两个不起眼的小玩意你会"随便按按钮"而非撬开外壳，电视里的毒枭也会随机
划开几包货来判断整批。
为何有效：一个数学案例加两个日常直觉泵，让"检验输出"显然比"分析内部"更聪明——而对多项式恒等这是*唯一*已
知的高效途径。
可能的另一领域：商业
```

```
概念：局部最大值与"须先变差才能改进"
范例：笼中的龙虾必须往笼子*更深处*走才能逃出——"一个用铁丝做成、会致命的局部最大值"。
为何有效：一个真实、略显残酷的生物图景，让一个抽象的优化陷阱令人难忘。
可能的另一领域：日常生活
```

```
概念：模拟退火／前置随机
范例：让行程从完全随机（"高温"）起步，再只在越来越高的骰子点数上接受更差的改动（先 2+、再 3+……），最后
只往上走——就像缓慢冷却一块晶体。
为何有效：一个掷骰机制，把抽象的冷却进度表变得具体可玩。
可能的另一领域：日常生活
```

```
概念：分布揭示机制
范例：卢里亚：各谱系间抗性均匀意味着定向反应；如中大奖般不均则意味着先前的随机突变——正如老虎机赔付。
为何有效：表明一个结果的*形状*（而非其平均）能裁决一个因果问题。
可能的另一领域：心理学
```

```
概念：随机刺激逃出窠臼
范例：迂回策略卡片，或把维基百科随机条目设为主页，"把你抛出画框"。
为何有效：把"逃出局部最大值"为任何人可操作化的廉价、可采纳做法。
可能的另一领域：心理学
```

## 9. 反直觉洞见

```
洞见：随机能胜过最好的确定性推理。
常见看法：机遇是最后的手段，是一种放弃。
作者论证：随机化算法比任何已知确定性方法更快给出好的近似解，有时更是唯一的高效途径（多项式恒等检验）。
证据：蒙特卡洛；米勒–拉宾；拉宾本人的"神秘……但它有效"。
为何令人惊讶：它颠覆了"推理永远胜过掷骰"的直觉。
```

```
洞见：你能靠掷骰解决一个严格的是/否问题。
常见看法：确定性问题需要确定性答案。
作者论证：对素性，随机见证能把假阳性概率任意压低，远快于确定性因式分解。
证据：米勒–拉宾的 (1/4)ᵏ 界；四十次检验 → 低于一千万亿亿分之一。
为何令人惊讶：关于一个事实的确定，竟从任一单步都无确定的过程中浮现。
```

```
洞见：一个"大概是素数"的数足以保障全世界的交易。
常见看法：数学是绝对确定的领域。
作者论证：现代密码学运行在只被认证到假阳性率低于 10²⁴ 分之一的数上——实际上确定，而且远快于证明。
证据：在线银行与加密背后的 40 次应用标准。
为何令人惊讶：信任的基础设施运行在经过计算的*不确定*之上。
```

```
洞见：要到达最好的解，你常常必须先接受一个更差的。
常见看法：永远走改进的一步；绝不后退。
作者论证：纯爬山困在局部最大值；抖动、重启与大都会算法刻意让解变差以逃出并找到全局最优。
证据：龙虾笼；十城度假；模拟退火。
为何令人惊讶：进步需要暂时的退步——并被写成了一个算法。
```

```
洞见：抽样若干案例能同时胜过轶事与汇总统计。
常见看法：要理解复杂议题，就用宏观统计（或生动故事）。
作者论证：精挑的轶事不具代表性；汇总统计单薄且掩盖异质性（奥梅拉斯）。近看随机样本比两者都更能切开难题。
证据：罗尔斯/政策的复杂性论证；GiveDirectly 的随机逐字访谈。
为何令人惊讶：诚实的窗口既不是故事、也不是汇总——而是那个随机样本。
```

```
洞见：创造力是随机加选择——刻意"把自己抛出画框"。
常见看法：创造力是定向的洞察或纯粹的天赋。
作者论证："盲目变异与选择性保留"（坎贝尔）——随机产生想法，再保留好的——支撑着发现；你可以诱发它（迂回
策略、随机条目）。
证据：詹姆斯、坎贝尔、马赫、庞加莱；卢里亚的意外发现；伊诺的卡片。
为何令人惊讶：心智的最高成就与骰子和突变共享同一机制。
```

```
洞见：纯粹随机是愚行；*经锤炼*的随机是智慧。
常见看法：要么理性规划，要么"随波逐流"。
作者论证：骰子人的全然随机酿祸；解药是三条准则——永远执行好点子、按坏点子的糟糕程度成比例地追随它、随时
间冷却。
证据：《骰子人》；科克罗夫特本人安顿进一个幸福的局部最大值。
为何令人惊讶：随机的最优用量既非零、也非最大，而是一张递减的进度表。
```

## 10. 独特或不寻常的想法

```
想法：确定性是一种可以像时间和空间那样花费的资源。
为何显得独特：它为经典的计算权衡增添了第三个轴——你可以用一剂受控的错误来买速度和内存。
与其他主题的潜在联系：近似计算；风险容忍；"够好即可"的决策规则；经过校准的疑虑的价值。
```

```
想法：复杂性的差距如此巨大，以致成了质的、而非仅是量的。
为何显得独特：阿伦森的"10 对 10¹⁰¹⁰ 秒"把速度差异重构为*种类*上的差异——读一本书对读每一本可能的书——从
而让计算机科学对哲学有了真正的话语权。
与其他主题的潜在联系：计算哲学；可行性作为一个概念（而非仅工程）问题；无知之幕。
```

```
想法：龙虾笼作为"一个用铁丝做成、会致命的局部最大值"。
为何显得独特：它把一个抽象的优化陷阱变成一件致命的实物，逃出它必须先走"错"的方向。
与其他主题的潜在联系：沉没成本；先变差再变好的勇气；"脱困"。
```

```
想法：温度即随机；退火是它的一张进度表。

与其他主题的潜在联系：学习率进度表；探索随一生递减（参见第 2 章的"时间跨度"）；青春的冒险收敛为安顿的常
规。
```

```
想法：一项关于机遇的发现本身也可以因机遇而生。
为何显得独特：卢里亚的发现是双重随机的——其内容（突变）与其触发（偶然看到老虎机）皆然，一个自我印证的意
外发现案例。
与其他主题的潜在联系：偶然在科学中的作用；有意设计的意外发现；为何暴露于随机很重要。
```

## 11. 张力、矛盾与开放问题

```
议题："抽样胜过分析"对抽样固有的误差。
作者立场：抽样"更好"是因为它至少给得出答案，而非更精确；误差随更多、真随机的样本而缩小。
可能的反驳：在高风险领域残余误差要紧，而本章未说明多少样本能让一个估计对某个决策可信。"更好"被限定为"能
给出答案"，却可能被过度解读为"可靠"。
何种证据有助厘清：把样本量/误差界与犯错代价挂钩的指引。
```

```
议题：一个"大概是素数"的数被当作确定——那有多安全？
作者立场：四十次应用给出低于 10²⁴ 分之一的错误，"实际上确定"。
可能的反驳：全球金融的基础设施建立在经过计算的不确定之上；本章赞美这一点，却未深究对抗性或系统性的尾部风
险（糟糕的随机数发生器、相关性故障）。"快得惊人地接近"并非零。
何种证据有助厘清：当随机本身被攻破时的故障模式分析。
```

```
议题：为政策抽样——谁的样本，代表性如何？
作者立场：随机抽样（GiveDirectly 式）胜过精挑的轶事与单薄的汇总。
可能的反驳：一个近看的随机样本仍需选择测什么、如何诠释；小样本能误导，"随机"报道也能被操纵或功效不足。本
章展示了*做法*，却未论证其*充分性*。
何种证据有助厘清：一个随机样本须多大、如何结构化，才能刻画一个异质总体以回答某个具体政策问题。
```

```
议题：三条人生准则是综合，而非公式。
作者立场：永远执行好点子；按糟糕程度成比例地追随坏点子；前置随机再冷却。
可能的反驳：一段人生的"冷却进度表"未被给出——冷却多快、如何知道自己当前的"温度"，都留给了直觉。《骰子
人》的对照生动，但中间地带是定性的。
何种证据有助厘清：一套从人生阶段或不确定度到恰当随机水平的有原则映射（与第 2 章的探索/利用"时间跨度"相
连）。
```

```
议题：校准对"真"随机的感知（汤姆的维基巧合）。
作者立场：暴露于真随机会重新校准你——表面"巧合"因概率而生的频率高于直觉的预期。
可能的反驳：这是作为轶事给出的（一个人的主页），校准论断未经检验；更深的一点（人类误判随机）为真，但此处
证据不足。
何种证据有助厘清：关于"结构化地暴露于随机抽取是否改善概率校准"的研究。
```

## 13. 心理学联系

## 19. 供跨书比较的本章摘要

```
主论点：随机并非最后的手段，而是一件刻意运用、威力强大、有时不可或缺的解题工具。随机化算法能胜过最好的确
定性算法——抽样（蒙特卡洛）让太复杂而无法精确计算之事变得可解；随机化检验（米勒–拉宾）以微乎其微的一点确
定性换取极大速度，揭示确定性是与时间、空间并列的第三种资源；战术性随机（抖动、重启、大都会算法、模拟退
火）则是在优化、创造与人生中逃出局部最大值的办法。用好机遇：永远执行好点子、按坏点子的糟糕程度成比例地追
随它、前置随机再冷却。

五大概念：
1. 随机化算法与蒙特卡洛抽样
2. 随机化素性检验（米勒–拉宾）与单向函数
3. 确定性 / 错误概率权衡（布隆过滤器）
4. 爬山法、局部最大值及逃出之法（抖动、重启、大都会、模拟退火）
5. 随机在进化与创造中的作用（盲目变异 + 选择性保留）与三条人生准则

三大论断：
1. 随机能胜过最好的确定性推理，有时更是唯一的高效途径。
2. 确定性是一种可与时间、空间相权衡的资源——"大概是素数"保障着互联网。
3. 要到达全局最优，你常常必须先接受一个更差的解；随机（前置再冷却）就是办法。

三大案例：
1. 乌拉姆的接龙 → 蒙特卡洛方法（及原子弹）
2. 米勒–拉宾与午夜的孪生素数来电（密码学的支柱）
3. 柯克帕特里克的模拟退火击败 IBM 芯片布局"大师"

三大研究：
1. 蒙特卡洛方法（乌拉姆、冯·诺依曼、梅特罗波利斯，1946 年起）
2. 米勒–拉宾素性检验（米勒、拉宾、普拉特，1970 年代中期）
3. 模拟退火（柯克帕特里克与格拉特，约 1980；《科学》，被引约 3.2 万次）

最独特的想法：确定性是一种可花费的资源，而复杂性理论中巨大的量的差距（10 对 10¹⁰¹⁰ 秒）实为质的——从而
给了计算机科学真正的哲学话语权，并把"大概正确"重构为常态、理性的处境，而非一种失败。

最反直觉的想法：你能靠掷骰子解决一个严格的是/否问题（这个数是素数吗？），比穷尽推理更快也更有用——而且要
到达最好的解，你有时必须刻意选一个更差的。

最大的弱点或开放问题：本章长于论证随机*有用*，却略于说明*用多少*——样本量/误差界的指引被限定为"能给出答
案"而非"可靠"，政策抽样论证展示了做法却未论证其充分性，三条人生准则是一种定性综合、其"人生冷却进度表"留给
了直觉（若能与第 2 章的探索/利用"时间跨度"相连会更好）。

最佳内容机会：围绕龙虾笼、局部最大值与模拟退火做一期"如何脱困"长视频——配上柯克帕特里克击败 IBM 大师与三
条人生准则——或做"为什么最聪明的一招有时是掷骰子"（乌拉姆的接龙 → 蒙特卡洛 → 原子弹）。
```
