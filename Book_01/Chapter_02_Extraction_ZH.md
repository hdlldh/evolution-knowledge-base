## 1. 章节论点

每一次在"新的"与"熟悉的"之间反复做出的选择，都是探索–利用权衡的一个实例，其形式化形态就是计算机
科学中的多臂老虎机问题。本章的核心主张是：正确的平衡点不取决于性情，而取决于**时间跨度（interval）**
——你还能享用所学多久。最优算法（吉廷斯指数、置信上界）表明，未曾尝试过的选项理应获得一份系统性的
加成——对未知抱有乐观在数学上是站得住脚的，而非天真；同时，遗憾至多只能以对数速度增长。把这套框架
套到一生上，童年就被重构为一个理性的探索期，晚年则是一个理性的利用期；而 A/B 测试与自适应临床试验，
不过是同一个问题分别以金钱和生命为赌注的版本。

## 2. 核心概念

```
概念名称：探索–利用权衡（Explore/Exploit Tradeoff）
定义：在收集信息（探索）与运用已有信息去获取一个已知的好结果（利用）之间的张力。作者强调，在计算机
科学中这两个词是中性的技术术语，剥离了它们在日常英语中的褒贬色彩。
为何重要：把"我该不该试点新的？"从一个性格问题重构为一个有答案、且答案取决于可测量情境的计算问题。
作者如何使用：全章的组织框架。他们坚持两种失败模式同样真实：从不探索无法过好一生，但从不利用同样糟糕
——生命中许多最好的时刻**本身就是**利用（节日里的家庭团聚、乐队为热爱他们的观众演奏金曲、一对久经
考验的伴侣随着"他们的歌"起舞）。
相关概念：多臂老虎机、时间跨度、吉廷斯指数、最优停止（第 1 章）。
```

```
概念名称：多臂老虎机问题（The Multi-Armed Bandit Problem）
定义：一间赌场里摆满赔率未知的老虎机；你想最大化总收益，这既需要试机器，也需要偏向已发现的最好的
那些。名字来自"独臂老虎机"——老虎机的俚称。
为何重要：探索–利用张力的形式化归宿；Peter Whittle 称它"以最本质的形式体现了一切人类行动中显而易见
的冲突"。
作者如何使用：全章的中心模型，应用于餐厅、音乐、航空公司、网页、药物试验乃至人的一生。
相关概念：期望值、吉廷斯指数、UCB、不安分的老虎机、A/B 测试。
```

```
概念名称：时间跨度（The Interval）
定义：你还能享用所学成果的时长。
为何重要：本章最承重的观念——"时间跨度决定策略"。探索的价值只会随时间**下降**，因为剩余的享用机会
在减少；利用的价值只会**上升**，因为你今天所知的最佳咖啡馆按定义至少不亚于上个月所知的那家。
作者如何使用：用以解释 Stucchio 的餐厅行为、好莱坞的续集潮、Carstensen 关于衰老的发现，以及最终整段
人生的弧线。也被反向使用：通过观察一个人的策略，可以推断出他所感知的时间跨度。
相关概念：贴现、社会情绪选择性、最优停止的时间跨度。
```

```
概念名称：赢则守，输则换（Win-Stay, Lose-Shift）
定义：Robbins 于 1952 年针对两台机器提出的策略——随机选一个摇臂，只要它还在出彩就一直拉；一旦失手
就换另一个。
为何重要：第一个被证明优于随机的策略，也是"守住赢家"这一持久原则的源头。
作者如何使用：作为一个历史性的第一步，其对错都有教益：对的部分是"赢则守"在很宽的条件范围内都是最优
策略的组成部分；错的部分是"输则换"过于轻率，且这条规则完全没有时间跨度的概念。
相关概念：吉廷斯指数、Zelen 的赢者优先算法。
```

```
概念名称：吉廷斯指数（动态分配指数）
定义：对每个摇臂而言，那个一旦提供给你、你就甘愿从此再不拉它的保证收益率——一个同时涵盖其已知价值
与探索价值的单一数字。策略：永远拉指数最高的那个摇臂。
为何重要：它在几何贴现下完整地解出了多臂老虎机问题，把探索–利用的张力坍缩为最大化单一数量。关键在于
每个摇臂的指数是**各自独立**计算的，因此摇臂有多少个并不影响。
作者如何使用：本章的数学核心，也是其最惊人数字的来源：一个从未试过的 0–0 摇臂得分 0.7029，胜过一台
已知有 70% 出彩率的机器。
相关概念：几何贴现、《一掷千金》的贿赂类比、UCB、期望值。
```

```
概念名称：几何贴现（Geometric Discounting）
定义：把每一次未来收益都按上一次的一个固定比例折算——明天的晚餐值今晚的 90%（或 99%）。
为何重要：它是使吉廷斯指数精确最优的那条假设，也是本章自己标记为经验上站不住的那条假设。
作者如何使用：这是 Gittins 的关键建模动作——把目标重构为"在一个无尽但被贴现的未来中最大化收益"，
而非在一个固定时间跨度内。作者给出了一个令人难忘的理由：如果你认为任何一天被公交车撞到的概率是 1%，
那就该把明天的晚餐折算成今晚的 99%，仅仅因为你可能吃不上它了。
相关概念：贴现函数、时间跨度、行为经济学中的双曲贴现。
```

```
概念名称：遗憾及其最小化（Regret and Its Minimization）
定义：某一策略实际获得的总收益，与"若你一开始就知道哪个摇臂最好、每次都拉它"本可获得的总收益之差。
为何重要：把一种情绪转化为可度量、可用来给算法打分的量；Lai 与 Robbins 证明了可达到的最小遗憾只以
对数速度增长。
作者如何使用：提供一种有数学背书的宽慰——你会永远不断累积遗憾，但在一个好策略之下，你每年新增的
遗憾都应少于前一年。
相关概念：遗憾最小化框架（Bezos）、UCB、Barnard 的"无法估量的损失"。
```

```
概念名称：置信上界算法（Upper Confidence Bound, UCB）
定义：选择置信区间**上端**最高的那个选项——也就是在现有证据下**可能**最好的那个，而不是迄今表现
最好的那个。
为何重要：达到接近最小的遗憾，计算量远小于吉廷斯指数，且不需要几何贴现假设。
作者如何使用：作为 Gittins 之后的实用继任者，也作为"不确定性下的乐观"以及"给人和事以善意推定"的
形式化依据。
相关概念：置信区间、误差棒、乐观机器人、吉廷斯指数。
```

```
概念名称：不确定性下的乐观（Optimism in the Face of Uncertainty）
定义：UCB 背后的原则——系统性地按未知项"合理可能达到的最好水平"来评估它，从而自然地把探索注入决策
过程。
为何重要：说明乐观可以是"完全理性的"而非一种偏误，并给出本章的实用建议：在没有相反证据时，对新的人
和新的事往做最好的设想。
作者如何使用：把数学与生活伦理相连——"长远来看，乐观是对遗憾最好的预防"。文中引用 MIT 的 Leslie
Kaelbling 所造的"乐观机器人"：它们通过抬高未探索区域的价值来进行探索。
相关概念：UCB、善意推定、探索加成。
```

```
概念名称：不安分的老虎机（The Restless Bandit）
定义：各摇臂的收益概率会随时间变化的老虎机问题。
为何重要：这才是现实情形，而它是不可解的——本章明言不存在能完整求解它的可行算法，且人们相信永远
不会有。
作者如何使用：用以为本章自己的工具箱划界，并为永久性的探索背书："身处一个不安分的世界，你自己也须
保有几分不安分。"那家让你失望的餐厅，也许已经换了老板。
相关概念：非平稳性、梭罗的《漫步》、沃霍尔的"可乐就是可乐"。
```

```
概念名称：自适应（基于老虎机的）临床试验
定义：在试验仍在进行时就把病人分配向表现更好的疗法倾斜的试验设计，而非在结束前始终维持固定分组。
为何重要：本章赌注最高的应用——常规试验优化的是"决定性地回答问题"，而不是"治好试验中的这些病人"。
作者如何使用：通过 Zelen 的赢者优先算法与 ECMO 之争，论证标准设计的伦理性并非不证自明。
相关概念：A/B 测试、《贝尔蒙报告》、赢则守输则换、Don Berry。
```

```
概念名称：A/B 测试
定义：把用户随机分配到页面的不同版本，并按选定指标锁定胜者。
为何重要：用作者的话说，它把互联网变成了"世界上最大的对照实验"，而它在结构上与临床试验完全相同。
作者如何使用：借奥巴马竞选的案例，展示探索–利用算法已经在驱动商业互联网的大部分；并抛出那句
"在这个多臂老虎机问题里，你不是赌徒，你是彩池"。
相关概念：多臂老虎机、临床试验、由用户承担的探索成本。
```

## 3. 核心论点

```
论点：决策几乎从来不是孤立的，而期望值也不是故事的全部。
论点类型：理论性 (Theoretical)
提供的证据：1–1 与 9–6 的对比——一旦把你将来针对同一批选项做出的所有决策都计入，仅按期望值排序
（50% 对 60%）就会给出错误答案。
支持强度：强 (Strong)（对这一模型类别而言属定义性而非实证性）。这是全章赖以成立的前提：人们"倾向于
孤立地看待决策"，而老虎机框架纠正的正是这个习惯。
```

```
论点：纯粹的利用会自我瓦解，因为你拥有的每一个"最好"，最初都不过是对你而言"新的"东西。
论点类型：阐释性 (Interpretive)
提供的证据：直接针对 Robert Pirsig 在《禅与摩托车维修艺术》(1974) 中"'什么是最好的？'优于'有什么新
鲜事？'"的立场展开反驳。无实证证据；论证是结构性的——尚未被发现的"最好"可能仍在外面，因此新事物至少
值得分得一部分注意力。
支持强度：作为论证为强 (Strong)，并且值得注意：这是本章唯一一次与具名作者的明确交锋。
```

```
论点：正确的探索–利用平衡取决于你还能享用所学多久的时间跨度——"时间跨度决定策略"。
论点类型：理论性 (Theoretical)
提供的证据：结构性论证（探索的价值只能下降、利用的价值只能上升），并以 Stucchio 搬入 / 搬离时的餐厅
行为，以及 Carstensen 的时间跨度实验操纵加以佐证。
支持强度：强 (Strong)。Carstensen 的两个反转条件（设想跨州搬家；设想多活二十年）给了它真正的实验
支持，而不只是例证。
```

```
论点：策略会泄露时间跨度——好莱坞的续集潮意味着这个行业相信自己的时间跨度已所剩无几。
论点类型：阐释性 (Interpretive)
提供的证据：票房前十中的续集数量：1981 年 2 部、1991 年 3 部、2001 年 5 部、2011 年 8 部；2011 年
创下大制片厂发行片中续集占比的纪录，2012 年与 2013 年又接连打破。大制片厂利润在 2007 至 2011 年间
下滑 40%，过去十年中有七年票房下滑；并引述《经济学人》关于制片厂被成本上升与收入下滑夹击的表述。
支持强度：中等 (Moderate)。相关性有充分记录、解读也合理，但行业自身的战略推理是从行为反推的——作者
自己称这是一个被经济数据"证实"的"预感"。
```

```
论点：赢则守、输则换的表现可靠地优于随机。
论点类型：理论性 (Theoretical)（已证明）
提供的证据：Robbins 1952 年的证明，文中作了描述但未复现。
支持强度：强 (Strong)
```

```
论点：在很宽的条件范围内，"赢则守"是最优策略的组成部分；"输则换"不是。
论点类型：理论性 (Theoretical)
提供的证据：Robbins 之后的一系列论文；并可在吉廷斯指数表中直接看到——沿任一行从左向右，指数总是
上升；而"九胜之后一负"的记录仍得 0.8695。
支持强度：强 (Strong)。表格把这种不对称做成了可见的事实，而非断言。
```

```
论点：在几何贴现下，吉廷斯指数完整地解出了多臂老虎机问题。（顺序很重要：正是这条限制条件使该结论
成立，而本章也是把它作为限制、而非附带说明来陈述的。）
论点类型：理论性 (Theoretical)（定理）
提供的证据：作为定理陈述；并附 Gittins 本人谦逊的说法（"这还算不上费马大定理"）。推导未给出；
《一掷千金》的贿赂类比替代了推导。
支持强度：作为结论为强 (Strong)，但本章未提供证明。
```

```
论点：一个完全未经尝试的选项（0–0 记录）比一台已知有 70% 出彩率的机器更有吸引力。
论点类型：理论性 (Theoretical)
提供的证据：贴现率 0.9 时的吉廷斯指数表：0–0 得 0.7029，而其期望值为 0.5000。贴现率 0.99 时，同一个
0–0 摇臂相当于一个 86.99% 的保证出彩率。
支持强度：在模型假设内为强 (Strong)，也是本章最惊人的结论。请注意它完全是几何贴现加长时间跨度的
产物。
```

```
论点：探索加成衰减得很慢——即便第一次就失手（0–1），指数仍高于 50%；而持续 50% 的表现也只是缓慢地
收敛到 0.5000（1–1 → 0.6346；2–2 → 0.6010）。
论点类型：理论性 (Theoretical)
提供的证据：指数表。
支持强度：强 (Strong)
```

```
论点：数学为"篱笆那边的草更绿"这句老话给出了依据——未知者有变得更好的可能，哪怕你预期它不会有什么
不同，或者它同样可能更糟。
论点类型：阐释性 (Interpretive)（对一项形式结论的解读）
提供的证据：吉廷斯指数的结构；以及作者的例子——一名未经检验的新秀（至少在赛季初）比一名看似能力
相当的老将更有价值，恰恰因为我们对他所知更少。
支持强度：中等到强 (Moderate to Strong)。形式化的那一点是扎实的；"草更绿"的说法属修辞，而本章紧接着
就警告：草看起来绿一点，并不必然值得你翻过篱笆，更不用说去办第二笔抵押贷款。
```

```
论点：吉廷斯指数只在很强的假设下最优，且难以手工应用。
论点类型：理论性 (Theoretical)（作者自陈的限制）
提供的证据：三条具名的限制——(1) 几何贴现，而"行为经济学与心理学的一系列实验表明人们并不这样贴现"；
(2) 一旦选项之间的切换有成本，它就不再最优；(3) 难以临场计算，作者用一个笑话来说明（"等一下，我能
解决这个争论。那家餐厅 35 次里好了 29 次，这家 16 次里好了 13 次，所以吉廷斯指数是……喂，人都上哪儿
去了？"）。
支持强度：强 (Strong)。这是本章在约束自己的招牌结论。
```

```
论点：可达到的最小遗憾随每次拉动以对数速度增长；总遗憾永不停止增加，但好策略会让其增速随时间下降。
论点类型：理论性 (Theoretical)（已证明）
提供的证据：Lai 与 Robbins，1985 年——文中给出三条结论：在非全知的前提下遗憾大概永不停止增加；在
最优策略下它增长得更慢；可能的最小增速是对数级。
支持强度：强 (Strong)
```

```
论点：对数级遗憾意味着你在头十次拉动中犯的错，和接下来九十次中一样多；第一年犯的错，和这个十年余下
时间里一样多。
论点类型：理论性 (Theoretical)（对上一条的例示）
提供的证据：对数的直接性质。
支持强度：作为算术为强 (Strong)；请注意它在"遵循一个遗憾最小化算法"的前提下成立，而非自动适用于
一段人生。
```

```
论点：UCB 算法给出的建议与吉廷斯指数相似，但计算量显著更小，且不需要几何贴现假设。
论点类型：理论性 (Theoretical)
提供的证据：直接陈述；其机制（选置信上界最高者）作了解释，并指出它与 Gittins 的平行之处——都为每个
摇臂赋一个数字，都高于期望值，也都随证据累积而向期望值收敛。
支持强度：机制部分为强 (Strong)；"建议相似"这一说法是断言而非展示。
```

```
论点：乐观可以是完全理性的，且"长远来看，乐观是对遗憾最好的预防"。
论点类型：阐释性 (Interpretive) / 规范性 (Prescriptive)
提供的证据：UCB 算法的遗憾保证；Kaelbling 的乐观机器人作为工程上的存在性证明。
支持强度：中等 (Moderate)。形式化的那一部分（乐观的价值估计在老虎机问题中最小化遗憾）是扎实的；但
把它外推到"应当如何对待新认识的人"是作者的推断，而"对他们往最好处设想"是一条模型之外并未直接授权的
规范性建议。
```

```

## 4. 框架、模型与思维模型

```
名称：多臂老虎机
描述：在收益率未知的若干选项之间反复选择，以最大化累积回报。
组成部分：摇臂（选项）；未知的收益概率；一串拉动；一个时间跨度或贴现函数。
运作方式：每一次拉动同时是一次测试和一次下注。最优策略要求把每个摇臂的信息含量与其期望收益一并
估价。
适用时机：任何"结果会教给你某些将来还用得上的东西"的重复决策——餐厅、招聘、约会、产品功能、疗法、
内容推荐。
局限：经典版本假定收益概率固定、无切换成本、反馈即时可观测。Whittle 说它"很快成了经典，也成了'顽固
难解'的代名词"。
```

```
名称：赢则守，输则换
描述：只要摇臂还在出彩就继续拉；一旦失手就换。
组成部分：两个摇臂；每次拉动一个二元结果。
运作方式：随机起始，随后是一条纯反应式的切换规则。
适用时机：当你需要某种简单且可证明优于随机的办法时；其中"赢则守"的一半远远超出了原始设定的适用范围。
局限："输则换"过于轻率——一顿糟糕的饭不该抹掉一百顿好饭，而且"好的选项不应因为不完美而被过重惩罚"。
这条规则没有时间跨度的概念，所以哪怕是你在这座城市的最后一晚，它也会叫你换一家。
```

```
名称：贝尔曼的逆向归纳解
描述：当选项总数与机会总数事先已知时的精确解。
组成部分：一个已知的有限时间跨度；对全部可能未来的枚举。
运作方式：从最后一次拉动出发，针对每一种可能的历史确定最佳选择，再一路倒推回起点——与第 1 章的完全
信息秘书问题是同一个手法。
适用时机：规模小、设定完备的问题。
局限："铁板钉钉"，但计算量爆炸——选项一多、赌场之行一长，所需工作量就令人眩晕乃至不可能；何况你
通常也并不知道时间跨度。这正是该问题长期未被真正解决的原因。
```

```
名称：吉廷斯指数
描述：把每个摇臂化约为一个数字——那个一旦给你、你就甘愿从此再不拉它的保证收益——然后永远拉最高的
那个。
组成部分：每个摇臂的胜负记录；一个几何贴现率；由此得出的指数表。
运作方式：Gittins 设想了一笔贿赂，正如《一掷千金》中的"银行家"出钱请你不要打开手提箱。你愿意接受
"确定之物"的那个价位，**就是**该摇臂的价值。由于每个指数是各自计算的，摇臂的数量无关紧要。
适用时机：具有几何贴现、且无切换成本的重复选择；指数表可针对某个贴现率预先算好一次，此后对该形式的
任何问题反复使用。
局限：作者点名三条——几何贴现在经验上可疑；切换成本破坏最优性；对人类而言临场计算不现实。
为何用贴现而非时间跨度：本章为这一转换给出的动机是，对制药公司和医生而言"相关的时间跨度究竟应该是
多少并不完全清楚"——公司打算无限期存在，一项突破可能惠及尚未出生的人，然而今天治愈一位病人又比明年
治愈一位更有价值。贴现能处理这种"无尽但被加权"的未来，而任何固定时间跨度都做不到。
关键数值（贴现率 0.9）：0–0 → 0.7029；0–1 → 仍高于 0.5；1–1 → 0.6346；2–2 → 0.6010；9–6 → 0.6300；
九胜后一负 → 0.8695。贴现率 0.99 时，0–0 → 0.8699。
```

```
名称：置信上界（UCB）
描述：选择置信区间伸得最高的那个摇臂，即那个**可能**最好的摇臂。
组成部分：每个摇臂的一个估计值加一个不确定性范围（误差棒）；该区间随数据增多而收窄。
运作方式：按乐观的潜力而非观测均值排序。一家只有一条平庸评价的餐厅，仍保有一种"可能很棒"的潜力，
而一家有数百条平庸评价的餐厅则没有。
适用时机：几乎所有 Gittins 太难用的地方——不需要贴现假设，计算便宜得多，遗憾接近最小。
局限：本章未明确给出。（推断：所谓"与 Gittins 相似"是断言，且 UCB 仍假定收益是平稳的。）
```

```
名称：遗憾最小化框架（Bezos）
描述：把自己投射到八十岁，选择那个能让回望时的遗憾最少的选项。
组成部分：一个很长的设想时间跨度；一份预期遗憾清单；"为失败而遗憾"与"为没试过而遗憾"之间的不对称。
运作方式：Bezos 知道自己不会为尝试一家网络书店并失败而遗憾，却会为从未尝试而遗憾——"那会日复一日
纠缠我"——这使得离开 D. E. Shaw 的安稳职位成了"一个极其容易的决定"。
适用时机：时间跨度很长、且失败的损失可以挽回的一次性高风险选择。
局限：它本身并不是一个老虎机算法——它是一条恰好偏向探索的启发式。本章把它作为"计算机科学可以形式化
之物"提出，而非作为一种被证明有效的方法；并且请注意，它是一则幸存者偏差浓厚的孤例。
```

```
名称：Zelen 的随机化赢者优先（自适应试验）
描述：1969 年提出的一种带老虎机色彩的临床试验设计。
组成部分：一个装有每种疗法各一个球的帽子；有放回地抽球以分配每位病人。
运作方式：抽一个球来决定疗法。若成功，就再往帽子里放一个该疗法的球；若失败，则放入一个**另一种**
疗法的球。分配会朝着正在取胜的那一方漂移。
适用时机：在"扣留一种可能救命的疗法"存在伦理困境的试验中。
局限：与标准方法论出入很大，而这恰恰引发了 ECMO 案例所记录的争议——常规组的病人太少，无法让批评者
信服。
```

```
名称：作为老虎机的 A/B 测试
描述：把用户随机分配到页面版本，并按选定指标监测。
组成部分：多个版本；一个流量分配；一个指标；一个终止点；一个被锁定的胜者，或被提升为下一轮对照的
版本。
运作方式：经典做法是固定时长内均分流量，随后把全部流量给胜者。
适用时机：高流量、单个用户风险低、反馈迅速的决策。
局限：均分意味着在整个测试期间有一半用户拿到较差的选项——与本章针对常规临床试验提出的结构性反对
完全相同。更好的算法"仍在激烈争论中"。
```

## 5. 研究与证据

```
研究：赢则守，输则换
研究者：Herbert Robbins（哥伦比亚大学）
年份：1952
研究问题：对于双臂老虎机，是否存在一个优于随机的简单策略？
方法：数学证明。
主要发现：赢则守、输则换的表现可靠地优于随机。
作者如何使用：走出"不可解"的第一步，也是"守住赢家"这一原则的源头——该原则一直存活到最优策略之中。
重要局限：限于两台机器；没有时间跨度概念；"输则换"过于反应式。
提及的重复验证或争议：后续一系列论文进一步考察了"守住赢家"；作者报告"赢则守"得到验证，而"输则换"
没有。
```

```
研究：已知有限时间跨度下的精确解
研究者：Richard Bellman（兰德公司）
年份：未提及（二战后时期；本章的叙述顺序显示为 1950 年代——Robbins 1952 年的证明之后"接下来几年"）。
研究问题：当选项数与机会数事先已知时，如何最优地下注？
方法：从最后一次拉动开始的逆向归纳。
主要发现：在这一受限情形下存在精确解。
作者如何使用：说明该问题只在不现实的知识条件下可解，而一般情形仍然敞开。
重要局限：选项一多或时间跨度一长即计算上不可行；要求已知时间跨度。
提及的重复验证或争议：未发现。
```

```
研究：吉廷斯指数（动态分配指数）
研究者：John Gittins，现为牛津大学统计学教授；受 Unilever 委托
年份：1970 年代

## 6. 实验

```
实验名称：Tversky 与 Edwards 的两灯观察/下注任务
设置：一个装有两盏灯的盒子，每盏以固定但未知的百分比亮起；共 1,000 次机会。
参与者：未提及。
流程：每次机会中，参与者要么选择观察哪盏灯亮起（获得信息但无收益），要么在不观察的情况下下注（有
收益但无信息）。下注要到整场结束才揭晓。
结果：在 60/40 的分割下，参与者平均观察 505 次、下注 495 次。最优策略是在观察 38 次后转为下注，从而
留下 962 次机会去兑现。
解释：人们大幅度地过度探索——就观察阶段而言超出了一个数量级。
它证明了什么：先观察后下注的**结构**对人们而言是直觉的，而探索的**数量**却被严重误校——与第 1 章
秘书问题中"形式对、参数错"的模式完全相同。
可能的替代解释：该设计禁止你从自己的下注中学习，这很不自然，可能让观察显得比实际更必要；参与者可能
不信任小样本，或者对真实分割本身仍不确定，而不只是信心不足；由于收益结构未说明，他们优化的也可能
并非实验者所设想的东西。
```

```
实验名称：Meyer 与 Shi 的航空公司选择
设置：两个选项——准点率已知的老牌航空公司，与毫无记录的新公司。
参与者：未提及。
流程：反复选择，在一段时期内最大化准点到达次数。一旦放弃新航空公司，就再也无法获得关于它的信息。
结果：新航空公司在表现好时被用得太少、表现差时被用得太多；参与者未能干净切断，常常摇摆，尤其是在
两家都表现不佳时。
解释：作者将其解读为与过度探索一致。
它证明了什么：双向的校准失灵，以及在执行最优策略中"果断切换、再不回头"这一环节上的具体失败。
可能的替代解释：在两者都表现不佳时来回摇摆，可能反映的是一种合理的怀疑——条件是非平稳的（一个不安分
的老虎机）；果真如此，继续探索就不是错误，而本章自己在下一页恰恰提出了这种可能性。
```

```
实验名称：Steyvers、Lee 与 Wagenmakers 的四臂老虎机
设置：四个摇臂，十五次连续选择。
参与者：一组人；人数未提及。
流程：参与者选择摇臂；其行为随后被事后归入若干策略类型。
结果：30% 类最优；47% 类赢则守输则换；22% 在新摇臂与迄今最佳之间随机交替。
解释：非最优的那部分多数人，其行为方式会在本该纯粹利用的后期产生探索。
它证明了什么：简单启发式主导着人类的老虎机行为，而人们所用的具体启发式偏向探索。
可能的替代解释：只有十五次拉动和四个摇臂时，探索期本就理应占据时间跨度中很大一部分，因此该分类可能
夸大了次优程度；从很短的行为序列中反推策略，其可识别性很弱。
```

```
实验名称：Carstensen 与 Fredrickson 的三十分钟同伴选择
设置：一次强制选择——愿与谁共度三十分钟：一位直系亲属、一本近期读过的书的作者，或一位新近结识、
看来志趣相投的人。
参与者：年轻与年长成年人；人数未提及。
流程：先做基线选择，随后进行两次时间跨度操纵——请年轻人设想自己即将跨州搬家；请年长者设想一项医学
突破让他们多活二十年。
结果：基线——年长者选直系亲属，年轻人对作者或新识同样心动。操纵之后——设想搬家的年轻人也选了家人；
设想多活二十年的年长者变得与年轻人无从分辨。
解释：社交偏好追踪的是被感知的剩余时间，而非实足年龄。
它证明了什么：本章中最清晰的因果证据，表明驱动探索–利用行为的是时间跨度而非特质——而且双向皆然。
可能的替代解释：假设性情境可能引发需求特征，或只是启动了"结束"这一概念，而未真正改变被感知的时间
跨度；设想多活二十年同时也改变了对健康的预期，而不只是时间。
```

案例标题：音乐记者的地狱
人物 / 组织：Scott Plagenhoef，Pitchfork 前主编

结果：一个真正奏效的承诺装置。"你会在工作时想办法挤出一点空隙，去听点你就是想听的东西。"
所阐释的概念：被迫的探索是一项实实在在的成本，而非特权——"记者是殉道者，他们探索，好让别人得以
利用。"更锋利的一点是：持续探索意味着"你永远无法享用自己鉴赏力的果实"——专业素养只有在利用阶段才能

此案例为何有用：具体、有趣，并且颠覆了读者"一份充满新鲜事物的工作即天堂"的预设。它也是一个真实的
承诺装置，与第 1 章的 McLay 和 Rapoport 配对。

```
案例标题：ECMO 系列试验
人物 / 组织：Robert Bartlett（密歇根大学）；Marvin Zelen；Jim Ware（哈佛公共卫生学院）；Don Berry
（时在明尼苏达大学，后往 MD Anderson 癌症中心）
背景：ECMO 把本应流向肺部的血液引出体外，由机器充氧后送回心脏——一种侵入性极强、自身带有包括栓塞在
内风险的极端手段，用于其他办法都已穷尽的情形。1975 年它救活了加州奥兰治县一名连呼吸机都无法提供
足够氧气的女婴；她如今已过完四十岁生日，已婚并育有子女。更早的成人研究曾显示它并无获益。
经过：Bartlett 1982–84 年的研究采用了 Zelen 的赢者优先算法：一名常规疗法婴儿死亡，随后连续十一名
ECMO 婴儿全部存活；此后八名 ECMO 婴儿全部存活，两名常规疗法婴儿全部死亡。Ware 并不信服，采用了一种
不那么激进的设计——随机化直至出现预设数量的死亡，随后把所有人转过去。十名常规疗法婴儿中四名死亡；
九名 ECMO 婴儿全部存活；第二阶段二十名病人全部接受 ECMO，十九名存活。Berry 在《统计科学》上主张
Ware 研究本身就不道德、本不该开展。1990 年代一项近两百名婴儿的英国研究回到了常规均分；常规组多死亡
二十四名婴儿。
结果：每项研究都说服了它自己的作者，却都未能说服整个领域。Berry 转往 MD Anderson 设计基于老虎机的
癌症试验；2010 年 2 月 FDA 发布了自适应设计的指导文件。
所阐释的概念：以生命为收益的探索–利用；获取干净证据的代价。
此案例为何有用：本章后果最重的案例，一个方法论选择上附着着真实的死亡人数，而且各方都存在真实的专家
分歧，而非一个整洁的道德结论。
复用潜力：高 (High)

人物 / 组织：Laura Carstensen（斯坦福）；Barbara Fredrickson
背景：针对以衰退与脱离社会为基础的传统解释，探究社交网络为何随年龄缩小。
经过：在三十分钟同伴选择中，年长者更愿选一位直系亲属，而年轻人对一本书的作者或一位有希望的新识同样
心动。设想跨州搬家的年轻人也选了家人；设想一项医学突破让自己多活二十年的年长者，则变得与年轻人无从
分辨。
结果：差别关乎被感知的时间跨度，而非年龄。年长者总体上也对自己的社交网络更满意，报告的情绪幸福感常
高于年轻成年人。
所阐释的概念："时间跨度决定策略"，并在两个方向上都得到了实验证明。
此案例为何有用：本章最有力的证据，并且把一个刻板印象（老人固执、年轻人善变）转化为双方各自的理性
行为。
复用潜力：高 (High)
```

```
案例标题：大学与养老院
人物 / 组织：无——作者的一处观察
背景：两个结构上完全相同的处境：一个满是你尚未认识的人的新社交环境。
经过：上大学通常是积极而令人兴奋的；而搬进养老院却可能是痛苦的。
结果：这种差别部分被归因于我们在人生那两个阶段所处的探索–利用位置。
所阐释的概念：时间跨度决定了新奇被读作机会还是被读作丧失。
此案例为何有用：一句话就让时间跨度这个观念在情感上变得可感；对任何关于衰老的作品都是有力素材。
复用潜力：高 (High)
```

```
案例标题：你祖父的那家餐厅
人物 / 组织：无——一条示例性的经验法则
背景：如何权衡长辈的建议。
经过：作者建议：当你祖父告诉你哪些餐厅好时，要听——那是数十年搜索所得的珍珠。但当他每天只在下午五点
去同一家餐厅时，你尽可放心去探索别的选项，哪怕它们多半会更差。
结果：把长辈所积累的**数据**（有价值）与他们当下的**策略**（按一个与你不同的时间跨度校准）干净地
区分开来。
所阐释的概念：最优策略依赖于时间跨度；信息可迁移而策略不可。
此案例为何有用：立即可操作、易记，并且用本章自己的机器化解了一种常见的代际摩擦。
复用潜力：高 (High)
```

```
案例标题：Pirsig 的"什么是最好的？"——以及作者的反驳
人物 / 组织：Robert Pirsig，《禅与摩托车维修艺术》(1974)
背景：本章的开篇论证。Pirsig 抨击"有什么新鲜事？"这个搭话开场白。
经过：Pirsig 认为这个问题"若被排他性地追求，结果只会是没完没了的琐碎与时尚的游行队伍，是明日的
淤泥"，并推崇"什么是最好的？"远为优越。作者反驳道：你最爱的每一首歌、每一家餐厅，最初都不过是对你
而言"新的"东西——这提醒我们，尚未被发现的"最好"可能仍在外面，因此新事物至少值得分得一部分注意力。
结果：本章的奠基性论证，以与一位具名文学权威交锋的方式登场。
所阐释的概念：为何纯粹的利用会自我瓦解——你只能利用探索已经找到的东西。
此案例为何有用：一个具名的、经典的对手，远比与一种泛泛的直觉争辩更引人；而这也是本章唯一一次与另一位
作者的明确分歧。
复用潜力：高 (High)
```

```
案例标题：Lydia Davis 论重读
人物 / 组织：Lydia Davis（"……以及利用"一节的题记）
背景：恰好置于本章转向衰老之处。
经过：Davis 描述了一个终身读者都熟悉的关口：在她余下的时间里，是该读越来越多的新书，还是"停止那种
徒劳的消耗——之所以徒劳是因为它没有尽头——转而开始重读那些曾给我最强烈快乐的书"。
结果：不适用——这是对困境的陈述，而非化解。
所阐释的概念：时间跨度，由一个正身处其中的人从内部道出。
此案例为何有用：本章核心观念最动人的表述，而且它来自文学而非数学。用作一篇作品的开头或结尾都很理想。
复用潜力：高 (High)
```

```
案例标题："及时行乐"是自相矛盾的
人物 / 组织：罗宾·威廉姆斯在《死亡诗社》(1989) 中；以及作者
背景："抓住时间跨度"一节的开场。
经过：面对"抓住今天吧，孩子们。让你们的生命超凡脱俗"，作者称这条建议"极其重要"，却也"有几分自相
矛盾"——抓住一天与抓住一生是全然不同的两件事。他们为"吃喝快活吧，因为明天我们就要死了"提出了一个
反面版本："去学一门新语言或一件乐器，去和一个陌生人闲聊，因为人生很长，谁知道多年之后会绽放出怎样
的喜悦。"
结果：一句名言被重构为依赖时间跨度，而非普遍正确。
所阐释的概念：继承而来的智慧默默编码了某个特定的时间跨度，出了这个范围它就是错的。
此案例为何有用：一个人人认得的文化符号被转化为教学示例，外加一句可独立成立的原创箴言——既可作引语，
也可作收尾。
复用潜力：高 (High)
```

```
案例标题：浆果丛与可乐
人物 / 组织：Andy Warhol（被引用）；以及作者
背景：评估不安分老虎机问题在现代生活中究竟有多大的杀伤力。
经过："一片浆果丛可能这周成熟、下周腐烂，但正如安迪·沃霍尔所说，'可乐就是可乐'。"作者补充道，
"拥有一套由进化针对一个持续变动的世界所调校出来的本能，在一个工业标准化的时代未必有用"。
结果：一个论证——许多现代收益异常平稳，因此经典的平稳算法比原本更能迁移过来。
所阐释的概念：进化失配；非平稳性作为祖先环境而非工业环境的特征。
此案例为何有用：本章唯一明确的进化失配主张，也是一组利落的双意象对照。

## 8. 最佳教学示例

```
概念：利用并不是一种恶习
示例：节日里的家庭团聚；一个书虫端着热咖啡窝进阅读椅、手边是一本心爱的旧书；乐队为热爱他们的观众
演奏金曲；一对久经考验的伴侣随着"他们的歌"起舞。
为何有效：它抢在读者把"利用"当作贬义词之前，先点出四个没人愿意放弃的场景，从而让这套技术词汇的中性
成为可感之事，而非一句断言。
可迁移领域：日常生活 (Everyday Life)
```

```
概念：探索加成
示例：吉廷斯指数表左上角那一格——0–0 记录的期望值是 0.5000，指数却是 0.7029，胜过一台已知十次出彩
七次的机器。
为何有效：一张表里的一个数字，就推翻了读者"一个已被证实的 70% 选项必然胜过一个全然未知者"的默认
判断，而且它可以对照表格核实，不必凭信。
可迁移领域：数学 (Mathematics)
```

```
概念：作为无差异价格的吉廷斯指数
示例：《一掷千金》里的银行家出钱请你不要打开手提箱；你愿意接受这笔确定之物的价位，就是那只箱子对你
的价值。
为何有效：把一个抽象指数转化为一笔有明确数字的、熟悉的交易；而游戏节目这一形式意味着大多数观众本就
具备这种直觉。
可迁移领域：商业 (Business)
```

```
概念：为何时间跨度支配策略
示例：Stucchio 刚到浦那时到处吃，临走时回到老地方——"就算我找到一家稍好一点的，我也只会再去一两次，
那何必冒这个险？"
为何有效：同一个人、同一座城市、相反的策略，唯一变动的变量是剩余时间。这是读者可以拿自己来做的一次
天然对照实验。
可迁移领域：日常生活 (Everyday Life)
```

```
概念：置信上界
示例：一家只有一条平庸评价的餐厅，仍保有一种"可能很棒"的潜力，而一家有数百条平庸评价的餐厅则没有。
为何有效：它教的是"不确定性本身就是资产"，所用的对照中两个选项均值相同，差别只在样本量。
可迁移领域：日常生活 (Everyday Life)
```

```
概念：对数级遗憾
示例：你在头十次拉动中犯的错，和接下来九十次中一样多；第一年犯的错，和这个十年余下时间里加起来
一样多。
为何有效：把一个增长率翻译成一条可感的时间线，并且给出了真正的宽慰而不作过度承诺——遗憾仍在累积，
只是越来越慢。
可迁移领域：心理学 (Psychology)
```

```
概念：作为探索机器的儿童
示例：一个把家里每样东西都往嘴里放的婴儿，是在"一丝不苟地拉遍赌场里所有的摇臂"。
为何有效：一个意象就把一种令人抓狂的日常行为映射到形式模型上，并把它的价值判断从"缺陷"翻转为"能力"。
可迁移领域：心理学 (Psychology)
```

```
概念：用户不是玩家，而是奖池
示例："在这个多臂老虎机问题里，你不是赌徒，你是彩池。"
为何有效：不到十个字完成一次视角反转；它把整节 A/B 测试内容从"一项读者或许会采用的技术"重构为"一件
正在对你施加之事"。
可迁移领域：商业 (Business)
```

## 9. 反直觉洞见

```
洞见：一个完全未经尝试的选项，可能比一个已知不错的选项更有吸引力。
常见看法：在一个未知者与一个已被证实的 70% 表现者之间，当然选后者。
作者的论证：吉廷斯指数给 0–0 记录赋值 0.7029（而其期望值为 0.5000），因为当你还要再次行动时，信息
本身是有价值的。在贴现率 0.99 时，这个未知者相当于一个 86.99% 的保证收益。
证据：贴现率 0.9 与 0.99 下的两张指数表。
为何令人意外：它把"篱笆那边的草更绿"变成了数学上正确的推断，而不是一种认知错误——未知者有上行空间，
即便其期望值更低。
限定条件：这完全依赖于几何贴现与一个很长的时间跨度；在时间跨度短、存在切换成本或一次性赌注的情况下
并不成立。
```

```
洞见：乐观是理性的，不是天真。
常见看法：现实主义意味着按选项实际交付过的东西来评判它。
作者的论证：UCB 算法有意按选项"合理可能达到的最好水平"来评估它，而这恰恰是达成接近最小遗憾的原因。
"乐观是对遗憾最好的预防。"
证据：UCB 的遗憾保证；Kaelbling 的乐观机器人。
为何令人意外：它为"善意推定"提供了形式化的辩护，把一种通常被当作偏误的性情转化为算法上的美德。
```

```
洞见：你永远不会停止累积遗憾——而这正是好消息。
常见看法：一个足够智慧的人最终会走出遗憾。
作者的论证：Lai 与 Robbins 证明，在非全知的前提下总遗憾永不停止增加；但最好的策略会让它以对数速度
增长，因此每一年新增的遗憾都少于前一年。
证据：1985 年的证明。
为何令人意外：它把一个不可企及的目标（没有遗憾）替换为一个可企及的目标（一个递减的速率），既更诚实
也更能宽慰人。
```

```
洞见：人们过度探索——尽管我们通常指责自己墨守成规。
常见看法：人类是习惯的动物，对新奇事物取样不足。
作者的论证：在反复选择的情境中，三项研究都发现了相反的结果——最惊人的是 38 次就够的地方观察了 505 次。
证据：Tversky 与 Edwards 1966；Meyer 与 Shi 1990 年代；Steyvers、Lee 与 Wagenmakers。
为何令人意外：它同时抵触民间心理学与本章自己"要多探索"的建议——本章指出了这一张力，但只借助非平稳性
作了部分化解。
```

```
洞见：年长者不是在退缩，而是在优化。
常见看法：晚年社交圈的缩小反映衰退、脆弱与脱离社会。
作者的论证：Carstensen 表明这种缩小是刻意修剪边缘关系、以聚焦于一个有意义的核心，并且它追踪的是被
感知的时间跨度而非年龄——面临搬家的年轻人表现相同，设想多活二十年的年长者则表现得像年轻人。
证据：Carstensen 与 Fredrickson 带双向时间跨度操纵的选择实验，以及年长者报告更高情绪幸福感的发现。
为何令人意外：它把一个衰退叙事转化为理性策略叙事，而双向的操纵排除了那个最显然的替代解释。
```

```
洞见：人生应当随时间变得更好。
常见看法：青春是巅峰；衰老是下坡。
作者的论证：探索多数时候必然令人失望——吉廷斯指数与 UCB 把未知者的吸引力抬高到超出预期——因此一段
转向所爱之物的人生，其质量理应上升。
证据：探索加成的结构，加上 Carstensen 的幸福感发现。
为何令人意外：它从那套推荐年轻人追新的同一套数学中，推出了一个关于衰老的乐观结论。
```

```
洞见：儿童的任性，也许比我们所知的更明智。
常见看法：儿童是认知有缺陷的成年人缩小版。
作者的论证：他们在利用类能力上表现糟糕、在探索类能力上表现优异——而这恰恰契合他们在时间跨度上所处的
位置。我们关于理性的直觉"过多地被利用而非探索所塑造"。
证据：Gopnik 的功能性论证；与驯鹿、瞪羚等早成性动物的对照。
为何令人意外：它颠倒了发育缺陷模型，并把矛头指向读者自己对"理性"的定义，指其偏狭。
```

```
洞见：标准临床试验或许才是伦理上更成问题的那一种设计。
常见看法：分组固定的随机对照试验是伦理上的黄金标准。
作者的论证：它优化的是解决问题，而不是治好入组的这些病人；而试验进行中累积的信息本可用来帮助这些人。
证据：ECMO 系列；Berry 对 Ware 研究公开发表的反对；英国研究常规组的 24 例超额死亡；FDA 2010 年的
自适应设计指导文件。
为何令人意外：它把方法论上的保守派变成了需要为自己辩护的一方。不过本章谨慎地报告，这仍是一个"少数
但在壮大"的立场，而那些自适应研究本身也被批评为信息量不足。
本章自己提供的反驳（复用此洞见时不得略去）：(1) 统计学把医学从临时性的相互说服转变为关于"何种证据
有说服力"的共同标准，而改变既定惯例有打破这一平衡的风险；(2) ECMO 侵入性极强，本身带有包括栓塞在内
的风险；(3) 更早的成人研究显示它相对常规疗法并无获益——这是随机化之所以站得住脚的最强理由；(4) 规模
最大的那次重复验证（英国研究）发现的效应量小于两项美国研究。
```

## 11. 张力、矛盾与开放问题

```
议题：本章说人们过度探索，随后又用后半部分敦促读者多探索。
作者立场：两者兼有。实验室证据显示过度探索；而生命周期论证说我们关于理性的直觉偏向利用，强调新奇是
理性的，在人生较早阶段尤其如此。
可能的反驳：二者可以调和——实验室任务的时间跨度短且已知，利用本就该更早占主导，而人生的时间跨度很长
——但本章从未明确说出这层调和。就文本呈现而言，读者同时被告知自己探索得太多、以及应该多探索。
何种证据有助于澄清：具有真正长时间跨度或开放式时间跨度的老虎机实验；或直接测量人们的探索率是否追踪
其实际剩余的时间跨度。
```

```
议题：吉廷斯指数被当作解法提出，随后又被大幅拆台。
作者立场：它在几何贴现下"完整地解出"了该问题，但只在很强的假设下最优、遇切换成本即失效、且不切实际
到无法计算。
可能的反驳：既然人们明显不按几何方式贴现，而切换成本在本章自己的例子中又无处不在（搬城市、换航空
公司、换疗法），那么那些招牌数字——包括著名的 0.7029——可能无法迁移到它们被用来阐明的任何一个日常
情境中。
何种证据有助于澄清：在双曲贴现与现实切换成本下，最优策略究竟改变多少；以及 UCB 的建议在实践中是否
与 Gittins 分道扬镳——本章断言不会，却未加展示。
```

```
议题：关于临床试验的伦理论证，建立在小到无法定论的研究之上。
作者立场：自适应设计让试验内部的病人得到了更好的治疗；英国的常规设计付出了额外 24 条婴儿生命的代价。
可能的反驳：密歇根研究几乎没有对照组，这恰恰是它未能说服人的原因；而英国研究发现的效应更小——这提示
美国的估计可能被夸大了。若真实效应更小，"这份知识的代价"这一框架所承担的修辞分量，就超出了证据所能
支撑的范围。Ware 与英国研究者回应的是真实的不确定性，而不仅仅是惯例。
何种证据有助于澄清：在一系列真实效应量下，比较自适应设计与常规设计预期损失生命数的模拟研究；以及
关于自适应试验产出被领域接受之结果的频率的证据。
```

```
议题：在 A/B 测试与临床试验中，被最小化的是谁的遗憾？
作者立场：本章指出二者在结构上同一，并观察到 A/B 测试中有一半用户拿到较差选项，以及你是"彩池"。
可能的反驳：老虎机框架优化的是**实验者**的累积收益。对用户和病人而言，相关的问题是知情同意与分配，
而非总量意义上的遗憾——《贝尔蒙报告》的素材提出了这一点，而 A/B 测试那一节并未回到它。Hammerbacher
的引语指向了这里，但本章并未继续追下去。
何种证据有助于澄清：不是实证问题——这是一个关于"算法应当编码谁的目标函数"的规范性问题。
```

```
议题：几何贴现被假定、被承认在经验上不成立，然后照用不误。
作者立场：明确标注：行为经济学与心理学表明人们并不按几何方式贴现。
可能的反驳：本章一边把 0–0 的指数值当作日常决策的指引提出，一边承认生成这些数字的假设并不描述真实
的人。要么这些数字是规范性的（你**应当**这样贴现）——而这是本章并未作出的另一个论证；要么它们是
描述性的，因而是错的。
何种证据有助于澄清：在双曲贴现下重新计算的指数值，用作对照。
```

```
议题：不安分的老虎机被宣告为不可解，而这动摇了本章的大部分应用。
作者立场：不存在可行的算法，且人们相信永远不会有；尽管如此，Gittins 与 UCB 仍提供"相当好的近似解"，
在收益变化不大时尤其如此——而作者主张现代收益异常静态（"可乐就是可乐"）。
可能的反驳：餐厅会换主厨，人会变，疗法会与不断演化的病原体相互作用，网络用户的偏好会漂移——本章自己
的例子大多是非平稳的。沃霍尔那句话是关于工业标准化的断言，而不是关于"所用例子中真正要紧的那些收益
是否稳定"的证据。
何种证据有助于澄清：测量本章各领域中收益实际漂移的速度，以及在该漂移下平稳算法损失多少。
```

```
议题：Gopnik 关于童年的说法是一个没有鉴别性检验的功能性故事。
作者立场：漫长的依赖期之所以存在，是为了容许探索，同时由照料者吸收其成本。
可能的反驳：人类的长期未成熟有若干相互竞争的解释——脑容量与骨盆限制之争、习得复杂文化的需求、延长的
社会学习。探索–利用的说法与这些解释是相容的而非竞争的，而文中并未给出任何有利于它的证据。
何种证据有助于澄清：跨物种比较，考察依赖期长度与该物种必须习得的环境"摇臂空间"之广度的关系。
```

```
议题：Bezos 的遗憾最小化是一则带幸存者偏差的轶事，却被当作框架使用。
作者立场：作为"计算机科学可以形式化之物"的例子提出——"一种遗憾最小的人生"。
可能的反驳：这套框架的例证来自一个它极为奏效的人。同样的推理在八十岁时也会认可无数最终失败的创业；
而遗憾最小化并不区分那些代价可轻易撤回的探索与不可撤回的探索——这一区分的重要性，超出了该框架自身
逻辑所愿承认的程度。
何种证据有助于澄清：运用"预期遗憾"框架的人平均是否做出更好的决定，而不只是那些著名的成功者自称用过
它。
```

## 13. 心理学关联

- **发展心理学。** Gopnik 关于漫长童年作为探索期的论述，以及把儿童的"缺陷"（不做长期规划、无法专注）
  重构为探索能力。
- **社会情绪选择性理论。** Carstensen 的研究计划是本章的实证支点；其双向时间跨度操纵是"如何检验一个
  动机性解释"的范本。
- **衰老与情绪幸福感。** 年长者对自己的社交网络更满意，报告的情绪幸福感也常高于年轻成年人——这是本章
  关于"利用有回报"的证据。
- **遗憾与反事实思维。** Barnard 的"关于本可如何的无法估量的损失"、Bezos 的八十岁投射，以及遗憾的
  形式化定义，都是从不同方向指向同一个心理对象；本章的独到之处在于把它变得可度量。
- **预期遗憾作为动机装置。** Bezos 用的是投射而非计算，这更接近前瞻性事后诸葛 / 事前验尸技术，而非
  任何老虎机算法（推断）。
- **贴现。** 几何贴现与双曲贴现被明确点名为模型与人类心理分道之处——本章引用了"行为经济学与心理学的
  一系列实验"，但未点名。
- **过度探索作为一种系统性偏误。** 三项研究方向一致；值得注意的是，它指向与更为人熟知的现状偏误与
  习惯文献相反的方向（推断：本章并未与那批文献交锋）。
- **乐观作为适应性而非偏误。** UCB 为乐观的先验提供了规范性辩护，这与抑郁现实主义和乐观偏误两个传统
  形成有趣的对照（推断）。
- **承诺装置与自控。** Plagenhoef 只往 iPod 里装新音乐是教科书式的承诺装置，而它在这里服务于**强迫
  探索**而非抑制冲动——与通常的情形恰好相反。
- **新奇追求与无聊。** 本章把"追新的冲动"在长时间跨度下视为理性的，从而为一种通常被当作气质来讨论的
  特质给出了功能性解释。
- **决策疲劳——被提出后即被搁置。** 本章的开篇段落是对选择耗竭的生动描写（意大利菜还是新开的泰国餐厅、
  最好的朋友还是新认识的人、"还没吃上第一口你就已经累了"、放张唱片也不再让人放松）。此后本章再未回到
  它：全篇把探索的成本纯粹建模为放弃的收益，从不当作认知耗损。这处空缺值得记录，因为那正是选择过载
  文献会发起攻击的位置。

## 14. 数学与决策科学关联

- **多臂老虎机。** 本章的中心形式体系，也是序贯决策理论中对探索–利用问题的经典框定。
- **期望值及其不足。** 9–6 与 1–1 的对比表明，一旦把未来的决策计入，仅按期望值排序（60% 对 50%）就会
  给出错误答案。
- **指数策略（index policies）。** 吉廷斯指数是指数策略的原型——把一个相互耦合的多臂问题分解为各臂
  独立的计算，才是该定理真正的内容。
- **贴现的无限时间跨度。** Gittins 把问题从固定时间跨度重构为一个无尽但被几何贴现的未来，这正是它变得
  可解的原因；贴现因子在这里扮演的角色，相当于第 1 章秘书问题中的时间跨度。
- **动态规划 / 逆向归纳。** 贝尔曼的精确解，文中明确回指到完全信息秘书问题。
- **遗憾界与在线学习。** Lai 与 Robbins 的对数下界是在线学习理论的奠基结论之一；UCB 是达成该下界的
  标准算法族。
- **置信区间与不确定性量化。** UCB 的机制是区间估计的直接应用——只是驱动决策的是区间的上端而非其中心。
- **不确定性下的乐观作为设计原则。** 优化与强化学习中的一项通用技术，在这里得到了它的白话名称。
- **非平稳性与不可解性。** 不安分的老虎机作为一项被陈述的否定性结论——本章自己的框架在此承认无可行解。
- **序贯实验设计。** 自适应试验、赢者优先分配与 A/B 测试都是序贯设计问题；本章的贡献在于指出它们是
  同一个问题。
- **球罐模型（urn schemes）。** Zelen 的球与帽子机制是一个随机化球罐模型，属经典概率构造。
- **进化失配（本章唯一一处此类主张）。** "拥有一套由进化针对一个持续变动的世界所调校出来的本能，在一个
  工业标准化的时代未必有用"——一片浆果丛这周成熟、下周腐烂，但"可乐就是可乐"。其论证是：祖先环境是
  不安分的老虎机，而许多现代收益是平稳的，因此我们的探索本能可能是对着错误的问题类别校准的。

## 15. 体育关联

**书中的直接示例：** 有一处。作者写道，"一名未经检验的新秀（至少在赛季初）比一名看似能力相当的老将
更有价值，恰恰因为我们对他所知更少"——这是把探索加成直接应用于阵容决策。

**推断出的应用（本人推断）：**

- **轮换与青训出场时间。** 让一名青训毕业生上场是一次探索，代价体现在预期积分上；时间跨度就是俱乐部的
  竞争视野。三月已退出争冠的球队时间跨度很长、应当探索；争冠的球队时间跨度很短、应当利用。这解释了
  为何在一个报废赛季的末段派人首秀不是感情用事，而是正确的打法。
- **把时间跨度当作对主教练下课风险的判读。** 一位突然不再轮换、每周都派上同样十一人的主教练，正在暴露
  一个很短的感知时间跨度——好莱坞续集的签名，被搬到了教练席上。
- **新秀溢价是可量化的。** 吉廷斯的逻辑说，1–1 记录的球员应优先于 9–6 记录的球员；用球探的话说，一小
  段有希望的产出具有期权价值，而一段更长的平庸记录没有。这是反对过度看重年轻球员生涯平均值的论据。
- **定位球与战术变化。** 尝试一套不寻常的战术套路是探索，其回报是"对手如何应对"的信息，而这份信息只在
  还有比赛可用它时才有价值。杯赛冲刺的末段，就该利用。
- **赛季中与休赛期的学习。** 训练是一个被补贴的探索阶段，其含义与 Gopnik 完全一致——吸收糟糕收益的
  "照料者"，就是教练组与友谊赛赛程。
- **对手球探中的不安分老虎机。** 对手会调整，因此两个赛季前失效的战术如今可能重新奏效——那家"换了老板"
  的餐厅，被搬到了对手的后防线上。
- **运动科学中的自适应设计。** 用半支队伍测试一整个赛季的训练干预，就是一次 A/B 测试，也带有同样的
  反对：那半支队伍全程都在用更差的方案。赢者优先分配会在赛季中把运动员移向更好的方案。
- **职业生涯弧线。** 一名运动员自身的探索–利用曲线——早期的位置试验，晚期对标志性打法的精炼——与本章
  的生命周期论证如出一辙。

## 16. 人工智能与机器学习关联

**书中直接内容：** MIT 的 Leslie Kaelbling 所造的"乐观机器人"——通过抬高未探索地形的估值来进行探索
——是本章唯一明确的 AI 例子。本章也指出，探索–利用算法"在经济上与技术上都实际驱动着互联网相当大的
一部分"。

**推断出的关联（本人推断）：**

- **强化学习。** 探索–利用权衡是 RL 的定义性问题；贴现因子 γ 恰恰就是本章的几何贴现，而时间跨度就是
  有效视野 1/(1−γ)。ε-greedy、Boltzmann 探索、UCB 与 Thompson 采样是标准的几大算法族。
- **生产环境中的 UCB 与 Thompson 采样。** 在推荐、广告投放与版式优化中，老虎机算法是固定分流 A/B 测试
  的标准替代品——正是本章所说"仍在激烈争论中"的那项改进。
- **乐观初始化。** 把初始价值估计设得很高以强制探索，就是本章的吉廷斯加成直觉在一行代码里的实现。
- **LLM 智能体中的探索。** 一个在工具、搜索查询或候选方案之间做选择的智能体面对的就是老虎机；时间跨度
  就是它还会遇到这个任务多少次——这意味着在一次性的用户请求中应更便宜地利用，而在长期运行或重复的
  工作流中应更多探索。
- **样本效率与冷启动。** 0–0 的指数把"推荐系统为何应当推送未被评分的条目"形式化了：一个没有数据的条目
  具有期权价值，这是冷启动启发式的有原则版本。
- **已部署模型的非平稳性。** 不安分的老虎机就是分布漂移的另一个名字；持续再训练与滑动窗口统计，正是对
  本章那条不可解性结论的实务回应。
- **RLHF 与评测。** 在"新的提示分布"与"精炼已知分布"之间分配标注预算，是一次针对数据收集的老虎机博弈，
  而不仅仅是针对模型输出的。
- **课程学习与发展式 AI。** Gopnik 的童年论证可映射为：先铺开广泛、低风险的探索，再进入任务特定的
  优化——照料者的补贴变成了训练环境的安全性。
- **实时实验的伦理。** 本章的临床试验论证可直接迁移到"在用户身上 A/B 测试模型版本"：同样是由谁承担探索
  成本的问题，而其知情同意规范远弱于医学。
- **遗憾作为标准指标。** 累积遗憾是在线学习算法的首要理论标尺；Lai–Robbins 的对数界至今仍是衡量新算法
  的基准。

CARD ID: B01-C02-05

## 19. 跨书对比章节摘要

```
主要论点：在"新的"与"熟悉的"之间做选择，就是多臂老虎机问题，而其答案由"你还能用上所学多久"这一时间
跨度决定。最优算法给未经尝试的选项一份系统性加成，使乐观在数学上成为理性的；而同一套结构支配着 A/B
测试、临床试验、童年与晚年。

前五大概念：
1. 探索–利用权衡
2. 多臂老虎机问题
3. 时间跨度（"时间跨度决定策略"）
4. 吉廷斯指数与探索加成
5. 遗憾最小化与置信上界 / 不确定性下的乐观

前三大论点：
1. 探索的价值只随时间下降、利用的价值只上升，因此时间跨度决定策略——Carstensen 在两个方向上都作了实验
   证明。
2. 一个完全未经尝试的选项可能胜过一个已知 70% 的表现者（0–0 记录的吉廷斯指数为 0.7029），因此偏好未知
   是理性的，而非天真。
3. 可达到的最小遗憾只以对数速度增长，因此好策略会让你每年新增的遗憾少于前一年。

前三大案例：
1. ECMO 系列试验——自适应设计与常规设计之争，以婴儿的生命为收益
2. Stucchio 在浦那与纽约的餐厅——时间跨度在一个人的行为中清晰可见
3. 奥巴马的 DONATE 按钮及其 5,700 万美元（以 Hammerbacher 的"最聪明的头脑"一句作配重）

前三大研究：
1. Carstensen 与 Fredrickson 带双向时间跨度操纵的同伴选择实验
2. Tversky 与 Edwards，1966——38 次就够的地方观察了 505 次
3. Lai 与 Robbins，1985——对数级遗憾界

最独特的观点：一个被观察到的探索–利用比例，会泄露行动者所感知的剩余时间跨度——于是好莱坞的续集潮、
一位祖父固定的晚餐时刻、一位年长者更小的社交圈，都可以被读作关于时间的同一句陈述。

最反直觉的观点：一个你一无所知的选项，可能严格地比一个你知道不错的选项更有吸引力——探索加成使得"篱笆
那边的草更绿"成为一个正确的推断，而非一个认知错误。

最大的弱点或开放问题：本章报告人们过度探索——其证据基础比这一主张的显著程度所暗示的更单薄——随后又
敦促读者多探索，却从未说出其中的调和。它承认自己的核心结论依赖于几何贴现（而它说人们并不这样贴现）
以及切换成本的缺席（而它自己的例子无一没有切换成本）；与此同时，那个更现实的非平稳情形被宣告为永久
不可解，且未附任何引证。它后果最重的临床试验论证，建立在规模极小的研究之上，而其规模最大的一次重复
验证发现的效应更小。此外，本章以一段对决策疲劳的生动描写开篇，此后却从未为它建模：全篇把探索的成本
一律当作放弃的收益，从不当作耗损。

具名的分歧（供本书总览使用）：Robert Pirsig，《禅与摩托车维修艺术》——本章唯一一次与具名作者的明确
交锋。

最佳内容机会：一期关于探索加成的长视频，围绕吉廷斯指数表左上角那一格（0.7029 胜过一台已知 70% 的机器）
与 Unilever 的起源故事展开，落点在"乐观是一种可被证明为理性的性情，而非一种气质"。
