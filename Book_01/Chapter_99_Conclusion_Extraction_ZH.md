## 1. 本章论点

任何受空间与时间约束的系统都面对同一组核心计算问题，这使计算机"不仅是我们的工具，也是我们的战友"。由此本书
提炼出三条智慧：(1) 有些算法可直接迁移到人的生活（37% 法则、LRU、置信上界）；(2) 使用一个最优的*过程*即便
*结果*糟糕也应带来宽慰——一种"计算式斯多葛主义"；(3) 启发式、近似与策略性随机是应对难解问题之道，故"够好"往
往真的够好，而我们在能选时应挑可解的问题。结论的原创贡献是一座从计算机科学通往伦理学的桥——**计算式善
意**：因为与他人交往会把困难的计算问题（首要是模拟我们的心智）抛给他们，我们应把请求、选项乃至物理环境构造
得*把思考的劳作降到最小*，对他人也对自己。收尾的重构：做出假设、偏好更简单的方案、以错误换延迟、并冒险——
这些"不是我们无法理性时所作的让步，而正是理性之所是"。

## 2. 核心概念

```
概念名称：计算式善意（Computational Kindness）
定义：把问题——社交请求、选择与设计——构造得使它们施加于他人和自己的计算（认知）负荷最小。
为何重要：一座从计算机科学通往伦理学的桥；因为"计算是坏事"（好算法把思考的劳作最小化），减轻他人的脑力劳作
是一种真正的善意——且常与传统礼节相背。
作者如何使用：晚餐分组与"我随便"案例；18 美分硬币；停车场设计；餐厅座位；公交站显示屏。
相关概念：过程对结果、验证对搜索、自旋对阻塞、模拟他人之心（第 11 章）。
```

```
概念名称：过程对结果（"计算式斯多葛主义"）
定义：以你是否遵循了可得的最优过程来评判自己，而非结果碰巧是否好——因为连最优算法也常给出坏结果。
为何重要：37% 法则有 63% 的时候失败；LRU（乃至未卜先知）也保证不了缓存命中；UCB 不消除遗憾，只放慢它。遵循
最优过程就是你所能做的全部。
作者如何使用：宽慰而非自责的教训，锚定于伯特兰·罗素的"最智之举"（那个*大概*最幸运的举动）。
相关概念：结果偏误（第 1 章）、37% 法则、LRU、UCB、善待自己。
```

```
概念名称：验证对搜索（复杂性鸿沟）
定义：识别一个好选项远比生成一个容易——"其鸿沟之宽，如同'一听就知是好歌'与'当场写一首'之别"。
为何重要：它解释了为何人们偏好一个*受约束*的请求（"下周二下午 1–2 点"）胜过一个开放的（"你方便时"），即便
约束是任意的——接受/拒绝是验证；提议是搜索。
作者如何使用：面试排期悖论，以及"提供具体选项"的主张。
相关概念：计算式善意、难解性（第 8 章）、停机问题（第 11 章）。
```

```
概念名称：自旋对阻塞（谁的 CPU 在付账？）
定义：当一个资源不可用时，可以"自旋"（在"好了没？"的循环里不断查询）或"阻塞"（停下、去做别的、待其空闲时被
通知）。
为何重要：在共享的人类场景里被烧的 CPU 是他人的心智；开放式座位让顾客"自旋"，而"登记—通知"让他们"阻塞"——
一种计算上更善意的设计。
作者如何使用：餐厅座位与公交站显示屏（一种"认知补贴"）。
相关概念：计算式善意、设计、调度（第 5 章）。
```

## 3. 关键论断

```
论断：有些计算机科学算法可直接迁移到人的问题。
类型：综合 / 规范
所给证据：37% 法则（最优停止）、最近最少使用准则（缓存）、置信上界（探索/利用）被点名为可即取即用的例子。
支持强度：在书内为强——每一个都在前面各章被开发与辩护。
```

```
论断：以过程而非结果评判决策——连最优策略也常失败。
类型：规范 / 诠释
所给证据：37% 法则 63% 的时候失败；LRU 乃至未卜先知也保证不了缓存命中；UCB 只放慢遗憾的累积。罗素：那个*大
概*最幸运的举动才是"最智之举"。
支持强度：强。扎根于本书自身前面的结果，外加一个哲学依据。
```

```
论断：对难解问题，启发式、近似与策略性随机使"够好"真的够好——而我们在能选时应挑可解的问题。
类型：综合 / 规范
所给证据：计算机科学家访谈中反复出现的主题；全书（尤其第 8 章）划出的可解/难解界线。
支持强度：在本书框架内为强。
```

```
论断：与他人交往会把计算问题施加于他们，故我们可通过降低那负荷来"计算式善意"。
类型：诠释（本书通往伦理学的原创之桥）
所给证据：面试排期悖论（人们偏好受约束的请求）；"计算是坏事"作为一条隐含的 CS 指令；晚餐分组与"我随便"案
例；具体设计实例。
支持强度：中到强。一个有说服力、举证充分的原理，被明确框为桥/类比，而非已证之律。
```

```
论断：设计能彻底改变它所提出的认知问题——故设计者应把脑力劳作最小化。
类型：规范
所给证据：沙利特的 18 美分硬币（数学上对找零最优，却"至少和旅行商问题一样难"；2 美分或 3 美分硬币在计算上更
善意）；螺旋停车楼（计算负荷为零）；自旋对阻塞的餐厅座位；作为"认知补贴"的公交站倒计时。
支持强度：强。数个具体、生动的设计案例，附一项具名研究。
```

```
论断：有界的、"够好"的理性并非让步——它正是理性之所是。
类型：诠释（本书的救赎性论点）
所给证据：计算机磨到完美答案的图景"是易问题所赋予的奢侈"；在难题中（人几乎总面对难题），最优算法会做假设、
偏好更简单的方案、以错误换延迟、并冒险。
支持强度：作为本书的收官论证为强；本质上属诠释。
```

## 4. 框架、模型与思维模型

```
名称：三条智慧
描述：本书对"计算思维为人的生活提供什么"的收官综合。
组成：(1) 可迁移的算法（37% 法则、LRU、UCB）；(2) 过程重于结果 / 计算式斯多葛主义；(3) 以启发式/近似/随机拥
抱难解，并挑可解的问题。
运作方式：任何受空间与时间约束的系统都面对同一组计算问题，故计算机的解成为生活的向导。
适用时机：应用全书的高层清单。
局限：一个综合、而非新结论；每条都在前面被辩护、而非在此。
```

```
名称：计算式善意
描述：一种伦理与设计原则：把你施加于他人的思考劳作最小化。
组成："计算是坏事"的洞见；验证对搜索的鸿沟；与单纯礼节的背离。
运作方式：主张你的偏好而非隐匿；提供少数具体选项而非众多开放选项；设计出提出简单计算问题的环境（硬币、停
车、座位、标识）。
适用时机：社交协调，以及任何人须推敲的设计。
局限：可能显得"不礼貌"；善意的约束与被强加的约束之间的界线未被指明。
```

```
名称：自旋对阻塞
描述：等待一个稀缺资源的两种方式，以及一面透视"设计消耗谁的注意力"的镜子。
组成：自旋（反复轮询）对阻塞（停下并被通知）；轮询的代价对上下文切换的代价。
运作方式：在计算中是一个时间权衡；在人类场景里，"自旋"烧掉他人的注意力（开放式座位、眯眼盯着公交），而"阻
塞"释放它（登记—通知、倒计时显示屏）。
适用时机：设计队列、候诊、通知、交通。
局限：阻塞需要基础设施（通知系统、到达预测），而这可能并不存在。
```

## 5. 研究与证据

```
研究：沙利特的最优面额分析
研究者：杰弗里·沙利特（滑铁卢大学）
年份：2003
研究问题：向美国投放哪一种单一新硬币最能减少找零平均所需的硬币数？
方法：对面额的组合/算法分析。
关键发现：18 美分硬币平均而言把硬币数最小化——但它使找零"至少和旅行商问题一样难"（简单的贪心算法不再最
优）。若计入计算之易，2 美分或 3 美分硬币几乎一样好、却"计算上善意"得多。
作者如何使用：旗舰例子，说明设计应权衡用户的*计算*代价，而不只是材料与金钱。
重要局限：一个理论性的货币设计结果，而非已实施的政策。
提及的重复或争议：未发现。
```

```
研究："受约束请求" / 范围不敏感之平行
研究者：未指明（作者自身的访谈观察；"著名研究"被引却无出处）
年份：未指明。
研究问题：为何人们更愿意迁就一个任意受约束的请求、而非一个开放的？
方法：作者在排期面试时的非正式观察，与广为人知的范围不敏感发现并置。
关键发现：受访者更愿在"下周二下午 1–2 点 PST"有空、而非"本周方便时"；同样，据称人们为救一只企鹅比救八千只
捐更多钱，且更担心死于恐怖主义、甚于死于（含恐怖主义在内的）任何原因。
作者如何使用：为验证对搜索的鸿沟与计算式善意作铺垫。
重要局限：企鹅/恐怖主义"研究"被引却无出处——此处为轶事；按本书自身规则，视为例证、而非既定数据。
提及的重复或争议：无；未给出处。
```

## 7. 案例与故事

```
案例标题：面试排期悖论
人物 / 机构：布莱恩·克里斯汀与汤姆·格里菲思
背景：为本书安排访谈。
发生了什么：受访者平均而言，被约一个具体时段（"下周二下午 1:00 到 2:00 PST"）时比被约"本周方便时"更可能有
空。接受或拒绝一个具体提议是验证；生成一个好时间是搜索——一个难得多的计算。
结果：一个具体的约束，即便任意，也是一种善意。
所示概念：验证对搜索；计算式善意。
为何此案例有用：一个可共情、可立即照做的例子，说明整条原理。
复用潜力：高
```

```
案例标题：布莱恩的西班牙之行与没人想看的斗牛
人物 / 机构：布莱恩·克里斯汀与两位朋友
背景：大学毕业那个夏天，一边走一边商定行程。
发生了什么：当发现赶不上一场他们查过资料、计划过的斗牛时，三人各自安慰对方——才发现没人想去。每人都"乖乖采
纳了他们所感知到的他人的热情程度"，从而在一个反馈回路里*制造*了那份热情。
结果：礼貌地隐匿偏好，制造出一个幻影共识。
所示概念：不表明偏好的代价；模拟他人之心；计算式善意。
为何此案例有用：一个生动、好笑、普遍的例子，揭示礼节隐藏的计算之害。
复用潜力：高
```

```
案例标题："我随便"——阴暗的计算内里
人物 / 机构：作者
背景：一群朋友决定去哪吃饭。
发生了什么：看似善意的说法如"我随便"或"今晚你想做什么？"做了两件令人不安的事：它把认知的皮球踢出去（"这是个
问题，你来处理"），且通过隐匿你的偏好，迫使他人去*模拟*你的——这是一个心智所能尝试的最难计算之一。计算式善
意则反而主张偏好（"我个人倾向 x——你觉得呢？"）或提供两三个具体选项。
结果：善意与礼节相背；主张偏好扛起了认知负荷。
所示概念：计算式善意对传统礼节。
为何此案例有用：本章最可引用、最能改变行为的教训。
复用潜力：高
```

```
案例标题：18 美分硬币
人物 / 机构：杰弗里·沙利特（滑铁卢大学）
背景：哪一种新硬币能把找零所需硬币数最小化。
发生了什么：18 美分硬币在数学上最优，但它破坏了简单的贪心找零算法（54 美分变成三枚 18 美分、一枚 25 美分也
不用），并使找零"至少和旅行商问题一样难"。2 美分或 3 美分硬币几乎一样好，却对收银员善意得多。
结果：数学上最优的设计，可以是认知上最残忍的。
所示概念：计算式善意作为设计原则。
为何此案例有用：一个精确、出人意料的案例，把"最优"与"可用"分开。
复用潜力：高
```

```
案例标题：停车场、餐厅座位与公交站显示屏
人物 / 机构：作者
背景：施加或减轻计算的日常设计。
发生了什么：多车道停车场迫使一个最优停止问题；单螺旋停车楼把计算负荷降到零（取第一个车位）。开放式餐厅座位
让顾客"自旋"（警惕地轮询）；登记—通知让他们"阻塞"。公交站倒计时（"10 分钟后到达"）让你*一次*决定，而非时时
刻刻重新决定——一种"认知补贴"，对客流量的提振或许不亚于降低票价。
结果：设计构造了人须求解的计算问题；好设计把它们最小化。"设计的首要目标之一，理应是保护人免于不必要的紧
张、摩擦与脑力劳作"——而且这有回报：令人紧张的商场停车会让购物者花得更少、来得更少。
所示概念：设计中的计算式善意；自旋对阻塞；最优停止（第 1 章）；贝叶斯推断（第 6 章）。
为何此案例有用：一簇具体、可采纳的设计教训，把全书系在一起。
复用潜力：高
```

## 9. 反直觉洞见

```
洞见：计算是"坏事"——好算法把思考的劳作最小化。
常见看法：更周全的斟酌更好。
作者论证：好算法的要点是尽量少想；把思考强加于他人（或自己）是一种代价，故把它最小化是一种善意。
证据：验证对搜索的鸿沟；受约束请求悖论。
为何令人惊讶：它把"少想"重构为目标，而非捷径。
```

```
洞见："礼貌"可以是计算上不善意的。
常见看法：隐匿你的偏好（"我随便"）是体贴。
作者论证：它把认知的皮球踢出去，并迫使他人模拟你的心智——一个巨大的计算；主张你的偏好才是真正的善意。
```

- **过程对结果 / 结果偏误。** "计算式斯多葛主义"是结果偏误（以结果评判决策）的直接解药——呼应第 1 章的处理与

- **范围不敏感。** 企鹅与恐怖主义之例援引了那个众所周知的失败：情感反应无法随量级缩放。

## 14. 数学与决策科学联系

## 16. 人工智能与机器学习联系

**书中直接：** 结论点名了可迁移的算法（37% 法则/最优停止、LRU 缓存、探索/利用的 UCB）与自旋对阻塞的系统权
衡；"计算是坏事"是一条明确的算法设计指令。

**推断的联系（提取者）：**
- **以人为本 / 善意的界面设计。** 计算式善意本质上是 AI 系统的用户体验与选择架构：一个助手应提供具体选项（验
  证），而非要求用户表述一个未充分指定的目标（搜索）——从而减轻人的认知负荷。
- **计算代价作为目标。** "把思考的劳作最小化"平行于随时算法、有界/元推理，以及延迟对质量的权衡——只在划算处
  花（人或机器的）算力。
- **评估中的过程对结果。** 以决策质量而非一个带噪的单一结果来评判一个策略，映照强化学习中的离策略评估与"奖励
  对回报"之别。
- **自旋对阻塞。** 一个直接的系统概念（轮询对中断/回调），与调度、服务与智能体编排相关。
- **收缩选项空间。** 提供一小组精选选项，联系着约束解码、候选生成 + 重排，以及那些呈现少数好选项而非一整片开
  放的界面。

## 19. 供跨书比较的本章摘要

```
主论点：每一个受空间与时间约束的系统都面对同一组计算问题，故计算机是"战友"、而不只是工具。全书教训凝为三条
智慧——可迁移的算法（37% 法则、LRU、UCB）；过程重于结果（"计算式斯多葛主义"）；以及以启发式/近似/随机应对
难解，此处"够好"真的够好。结论的原创贡献是计算式善意：既然与他人交往（及设计他们的环境）会把困难的计算问题
——首要是模拟我们的心智——抛给他们，我们就应把请求、选项与设计构造得使思考的劳作最小化。而有界的、抄近路的
理性并非让步；它正是理性之所是。

五大概念：
1. 计算式善意（一种伦理与设计原则）
2. 过程对结果（"计算式斯多葛主义"）
3. 验证对搜索（为何具体约束是一种善意）
4. 自旋对阻塞（设计消耗谁的注意力）
5. 三条智慧 / 有界理性作为真正的理性

三大论断：
1. 与他人交往会把计算问题施加于他们；我们可通过降低那负荷来"计算式善意"。
2. 以过程而非结果评判决策——连最优策略也常失败。
3. 抄近路（假设、更简单的方案、错误对延迟的权衡、冒险）正是理性之所是，而非其失败。

三大案例：
1. 面试排期悖论（受约束的请求 > 开放的请求）
2. "我随便"与布莱恩的幻影共识斗牛
3. 18 美分硬币与计算上善意的设计（螺旋停车、登记—通知、公交倒计时）

三大研究：
1. 沙利特的最优面额分析（2003）
2. （被引、无出处的）范围不敏感之平行——企鹅、恐怖主义
3. 无更多（结论作综合、而非呈现新研究）

最独特的想法：计算式善意——直接从复杂性理论导出一种伦理与设计原则（把他人的注意力当作稀缺的计算资源），含
"认知补贴"。

最反直觉的想法："礼貌"（说"我随便"）可以是计算上残忍的，而数学上最优的设计（18 美分硬币）可以是对人最糟的
——因为把思考的劳作、而非把数字最小化，才是真正的目标。

最大的弱点或开放问题：范围不敏感的"研究"（企鹅、恐怖主义）被引却无出处，作用为例证而非证据；且结论未标出"计
算上善意的约束"与"凌驾自主的强加"之间的界线。

最佳内容机会："你能说的最善意的话是'我不随便'"——经由排期悖论、幻影共识斗牛、18 美分硬币与公交站认知补贴讲
计算式善意。
```
