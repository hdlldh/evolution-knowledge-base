## 1. 章节论点

将 AI 引入某项任务，并不会自动意味着整个任务变得完全自动化——预测只是决策解剖结构（第 8 章）众多要素之一，而完全自动化要求数据收集、判断和行动也全部由机器执行，而不仅仅是预测。这样做是否值得，取决于机器（相对于人类）执行其他每一个要素的相对收益。在三种相互重叠的情形下，完全自动化会变得尤其有吸引力：当一项任务除预测之外的所有其他要素都已经自动化时（如现代采矿业）；当行动速度的收益很高、因为真的没有时间供人类思考时（"没有时间思考"，如自动紧急制动或里约奥运会的摄像机追踪）；以及当减少等待/通信时间的收益很高时（如太空探索，光速通信延迟使实时人类控制变得不切实际）。但完全自动化也受到纯粹经济效率之外的力量的制约：法律可能要求人在回路中（如致命自主武器）；外部性可能促使监管机构或法院以有利于让人类继续承担责任的方式分配责任；而在真正充满价值判断的领域（如幽默、艺术、体育和照护），人类可能仅仅是更偏好由另一个人类而非机器来执行这项行动，这与机器在技术上能否同样好、甚至更好地完成这项工作无关。

## 2. 核心概念

```
概念名称：完全自动化要求自动化所有要素，而不仅仅是预测
定义：第 8 章"决策的解剖结构"框架的一次直接应用：由于一项决策由输入数据、预测、判断和行动构成（训练和反馈支撑着预测），一项任务只有在数据收集、判断和行动全部由机器执行时，才算得上是*完全*自动化——而不仅仅是机器提供了预测。"AI"与"自动化"之间之所以界限模糊，具体是因为 AI 在其当前形态下，通常只处理预测这一要素。
为何重要：纠正了一种常见的混淆——为某项任务加入 AI/预测，与将该任务完全自动化并非一回事——并提供了精确的词汇，用以准确询问还需要哪些额外要素（判断、行动、数据收集）也由机器完成，完全自动化才能实现。
作者如何使用：直接作为本章的组织性问题提出，随后通过对比特斯拉的 Autopilot（截至本书写作时，依然需要人类定期干预，并根据合同要求驾驶员双手放在方向盘上）与力拓公司的全自动矿用卡车（除预测之外无需额外的判断或行动自动化，因为这些要素早已自动化）加以说明。
相关概念：决策的解剖结构（第 8 章）、机器执行其他要素的收益
```

```
概念名称："没有时间思考"vs."没有必要思考"（放弃控制权的两种不同理由）
定义：一旦机器做出预测后，将行动的完全控制权交给机器，有两种相关但不同的正当理由："没有时间思考"指的是预测与所需反应之间的时间间隔太短，人类认知来不及及时行动的情形（纯粹从速度角度支持自动化）；"没有必要思考"指的是预测本身已经直接、明显地指向唯一正确的行动，即便有时间运用人类判断，也几乎不会增加任何价值的情形（从判断的琐碎性角度支持自动化）。
为何重要：区分了两种经常被混为一谈的、支持完全自动化的不同经济学论证——一种关乎行动速度的收益，另一种关乎（无需人类判断的）收益——有助于识别在某项具体的自动化决策中，二者中的哪一个（或两者）适用。
作者如何使用："没有时间思考"以特斯拉紧急制动轶事加以说明（在高速公路车速下，人类确实无法在预测与所需制动之间做出反应），并以自动紧急制动法规的一般逻辑加以说明。"没有必要思考"以里约奥运会水下游泳摄像机为例加以说明（一旦游泳选手的位置被预测出来，正确的摄像机动作本质上是毫无争议的，因此对人类操作员而言不再有任何有意义的判断可做），并被推广至篮球等运动，研究人员正在将类似的自动化摄像机追踪技术拓展到这些领域。
相关概念：可编码判断（第 9 章）、硬编码判断
```

```
概念名称：由通信成本驱动的自动化（太空探索案例）
定义：与行动速度和判断琐碎性并列的第三种独立的完全自动化理由：当远程机器与人类决策者之间的通信成本/延迟本身高得令人望而却步时，完全自动化就变得必要——不是因为原则上无法获得人类判断，而是因为向人类传递信息并接收人类指示所需的时间，相对于情况的时间敏感性而言太长。
为何重要：将通信延迟（而非仅仅是处理速度或判断复杂性）识别为完全自动化的一个独立经济驱动因素——是与"没有时间/必要思考"这一对概念不同的独立类别，与预测者和决策者之间存在显著物理或信息距离的任何领域都相关。
作者如何使用：以商业月球采矿项目为例加以说明：无线电信号往返月球至少需要两秒钟，使得地球上的人类远程操作月球机器人成为"一个缓慢而痛苦的过程"，无法对突发危险（例如，意外出现的悬崖）做出足够快的反应；本章指出，如果没有 AI 支撑机器人行动的完全自动化，此类商业项目"很可能是不可能的"。
相关概念：没有时间思考、预测机器作为原本不可行的商业模式的推动者（呼应第 2 章的亚马逊例子）
```

```
概念名称：法律/社会要求人在回路中
定义：完全自动化在技术和经济上均可行，但依然受到法律、政策或社会/伦理惯例的制约，要求人类继续作为决策的一部分——无论机器能否表现得同样好或更好。
为何重要：确立了"这项任务是否应当完全自动化"并非一个纯粹的技术/经济问题——法律和伦理约束能够压倒本来有利的自动化经济学，本章主张，随着自动化蔓延到风险更高的领域，这一模式很可能会扩大。
作者如何使用：以艾萨克·阿西莫夫虚构的机器人三大法则（一次对监管问题的早期预见，旨在硬编码消除机器人伤害人类的可能性）加以说明；以经典的"电车难题"思想实验加以说明（这一问题因自动驾驶汽车即将真实面对与之类似的现实情境而变得不再抽象，需要有人——很可能是法律——来决定谁生谁死）；并以 2012 年美国国防部指令加以说明（该指令被广泛解读为要求人在回路中参与致命无人机攻击决策），与一个假设性的完全自主武器（能独立识别、锁定并击杀目标，无需人类参与）相对照——本章指出，即便一台预测机器在技术上能够区分平民与战斗人员，敌方也很可能很快学会如何利用或迷惑这台预测机器，使得所需的精度水平在短期内难以获得。还以特斯拉 Autopilot 的条款和条件为例加以说明，该条款尽管认可车辆的技术驾驶能力，仍在法律上要求驾驶员始终双手放在方向盘上。
相关概念：外部性、电车难题、责任分配
```

```
概念名称：外部性作为完全自动化的一个约束
定义：一个标准的经济学概念——某项行动的成本由做出该行动的决策者以外的一方承担——此处用于解释为何自动化那些可能伤及第三方（例如公共道路上的公众）的决策，与自动化那些潜在危害完全局限于决策组织内部的决策（例如私人矿场）相比，在法律和审慎层面受到截然不同的对待。
为何重要：为本章的核心经济学解释提供了依据，说明为何某些自动化情境（采矿）能够以相对较少的阻力推进，而另一些情境（公共道路上的自动驾驶汽车）则面临更严格的审查和更缓慢的监管审批——这种差异其实并非关乎技术能力，而是关乎谁承担机器出错的风险。
作者如何使用：直接对比：城市街道上的自动驾驶汽车事故，会将成本强加于未曾选择承担这一风险的外部方（其他司机、行人），而私人矿场内涉及自动矿用卡车的事故，只会影响已经与矿场相关联（且大概率因这种关联而获得补偿）的资产/人员——解释了为何政府对前者的监管远比后者严格；与标准的经济学外部性纠正手段相联系（例如，碳税作为"内部化"气候外部性的机制），并具体与责任分配——经济学家提出用于将自主机器所造成损害的外部性内部化的机制——相联系，迫使被追责的"内部化"一方（例如，承担责任的制造商或运营商）承担原本会落在外部方身上的成本。
相关概念：法律要求人在回路中、责任分配、监管作为自动化的一种障碍
```

```
概念名称：人类偏好人类（充满价值判断的行动，与机器能力无关）
定义：这一观察指出，在某些具有强烈社会、情感或体验意义的行动类别中，人们更偏好由人类（而非机器）来执行这项行动，即便在名义上被优化的指标上，机器能够表现得同样好、甚至更好；这反映了一种独特的"人类行动的收益"，其重点不在于能力，而在于行动的来源本身，对其被接受/体验的方式而言具有内在的重要性。
为何重要：识别出一类"机器执行行动的收益"抵抗纯粹基于能力的自动化逻辑——某些任务可能永远不会被完全自动化（或即便自动化后也永远不会被完全接受），仅仅是因为该行动由人类执行与由机器执行"意味着什么"不同——这是一种与法律/监管约束真正不同的约束。
作者如何使用：以 Mike Yeomans 的笑话推荐研究（第 5 节）加以说明；推广至艺术领域（艺术的价值往往源自观众对艺术家人类体验的了解）以及体育竞技（如果机器能跑得比任何人类都快，比赛的观赏性会降低，因为部分刺激感恰恰依赖于有人类选手参与竞争）；延伸至照护情境（陪孩子玩耍、照顾老人），在这些涉及社交互动的行动中，由人类提供服务可能内在地更好——或者至少目前更受偏好——即便机器"知道"同样的信息，尽管本章指出，随着人们逐渐习惯机器人照护者、甚至机器人体育竞赛，这种偏好可能会随时间发生变化。
相关概念：法律要求人在回路中、满意化/制度性偏好（在精神上呼应第 11 章）
```

## 3. 核心论点

```
论点：预测机器参与某项任务，并不自动意味着该任务被完全自动化，因为预测只是决策制定所需的若干要素之一（输入数据、判断、行动），即便预测已被自动化，其他每一个要素依然可以独立地继续由人类执行。
类型：理论性 (Theoretical)
提供的证据：将第 8 章"决策的解剖结构"框架具体应用于自动化问题的直接重述；以特斯拉（依然由人类监督的 Autopilot）与力拓公司（完全自主的矿用卡车）之间的对比加以说明。
支持强度：作为一个与本书既有框架相一致的概念性/定义性论断而言强 (Strong)，尽管在本章中它更多是作为一项组织性前提，而非一项被独立检验的实证发现。
```

```
论点：力拓公司在其位于澳大利亚皮尔巴拉地区的铁矿中引入自动驾驶卡车，已经为公司节省了 15% 的运营成本，之所以能够做到这一点，具体是因为采矿任务除预测（危险检测/导航）之外的每一个要素早已自动化或优化，使预测成为实现完全自动化所需的"最后一步"。
类型：实证性 (Empirical)
提供的证据：具体数字——在实现完全自主之前先是远程（基于珀斯的）卡车控制，2016 年引入 73 辆自动驾驶卡车，节省 15% 的运营成本，尽管温度超过 50 摄氏度，卡车依然 24 小时运行、无需上厕所休息、驾驶室无需空调，并且由于没有驾驶员，卡车无需"前后之分"（无需掉头）——引用于尾注 4 和 5。
支持强度：强 (Strong) —— 具体、量化、有明确日期的数字（73 辆卡车、2016 年、15% 的节省、50 摄氏度的温度），与一家具名公司（力拓）和地点（皮尔巴拉）相关联。
```

```
论点：一辆汽车的自动紧急制动系统，对一处危险（高速公路上一辆被前方卡车挡住视线、人类司机看不到的停驶车辆）做出反应的速度，快于人类司机本可能做到的速度，避免了司机本人判断如果手动驾驶很可能会发生的碰撞。
类型：实证性（单一轶事性报告） (Empirical)
提供的证据：特斯拉车主俱乐部论坛成员"jmdavis"（2016 年 12 月 12 日）发布的一篇详细的第一人称帖子，描述了事件经过（仪表盘显示一辆看不见的前车、自动紧急制动在前方卡车明显反应之前就已启动、卡车随后为躲避这辆实际已经停驶的车辆而转向、jmdavis 的特斯拉"留有充裕的空间"停了下来），以及他自己的判断——如果手动驾驶，很可能来不及及时停车；本章补充说明，特斯拉此前刚刚推送了一次软件更新，实现了基于雷达的预测改进，随后美国汽车制造商与交通部达成协议，将于 2023 年前把自动紧急制动列为标准配置。
支持强度：中等 (Moderate) —— 一则生动、详细、具名来源的轶事，但只是单一的自我报告案例，而非汇总的安全数据；更宏观的监管事实（2023 年标准化协议）具有更强的机构分量，且可独立核实。
```

```
论点：2016 年里约奥运会一台机器人水下游泳摄像机，能够追踪游泳选手并自动定位以捕捉从泳池底部拍摄的正确画面，取代了此前需要人类操作员手动预测游泳选手位置的设置——之所以能在此实现完全自动化，是因为所需的行动速度和涉及的判断（获得"正确的画面"）在游泳选手位置能被预测出来之后，都是直接了当/可编码的。
类型：实证性 (Empirical)
提供的证据：对该摄像机功能（追踪游泳选手，移动以从泳池底部捕捉正确画面）的描述，与此前的人类操作员方案相对比，引用于尾注 6；提及研究人员正在将类似的自动化摄像机追踪技术拓展到篮球等更复杂的运动，引用于尾注 7。
支持强度：中等 (Moderate) —— 一个具体、有明确日期、具名的事件（2016 年里约奥运会），具有清晰的前后对比，尽管未给出量化的表现对比数据（例如画面质量或成本节省）。
```

```
论点：目前，完全自主的致命武器（能独立识别、锁定并击杀目标，无需人类参与）的自动化，其受到的制约与其说来自纯粹的预测能力，不如说来自（a）法律/政策要求（2012 年美国国防部指令，被广泛解读为要求在攻击决策中保持人在回路中）以及（b）一种对抗性动态——战斗人员很可能很快学会利用或迷惑任何被赋予区分平民与战斗人员任务的预测机器，使得所需的精度水平在短期内不太可能可靠地实现。
类型：阐释性 (Interpretive)
提供的证据：援引 2012 年美国国防部指令（引用于尾注 9）及其被广泛的解读；本章自身关于假设性锁定预测机器遭对抗性钻空子的推理；明确加以限定，指出"尚不清楚这一要求是否必须始终得到遵守"，但对人类干预的需求"即便预测机器有可能独立运作，也将限制其自主性"，引用于尾注 10。
支持强度：中等 (Moderate) —— 植根于一份真实、可引证的政策指令以及一个逻辑严谨的对抗性钻空子论证，但关于未来精度可得性的论断，是一项前瞻性判断，而非一项经过实证证明的事实。
```

```
论点：人们发现机器推荐的笑话不如他们相信是人类推荐的同样笑话那样有趣，即便实际的推荐过程是算法式的——这意味着一项推荐被感知到的来源（人类 vs. 机器），独立于该推荐的实际质量或来源，会影响满意度。
类型：实证性 (Empirical)
提供的证据：研究者 Mike Yeomans 及其合著者的一项研究（泛泛引用，正文中未详述样本量/方法论），发现机器实际上更擅长推荐人们会觉得有趣的笑话，但人们更愿意相信推荐来自人类，并且在（无论真假地）被告知推荐来自人类时，报告的满意度最高——无论该推荐实际上是否由机器生成。
支持强度：强 (Strong) —— 一位具名的研究者，以及一个具体、干净的实验发现（机器推荐客观上更好，但被归因于人类的推荐更受偏好/被评为更有趣），尽管本章正文未给出确切的研究细节（样本、统计显著性）。
```

```
论点：自动驾驶车辆在公共城市街道上运行与在私人矿场运行之间的经济学区别，最好用外部性加以解释——城市街道事故将成本强加于未曾选择承担这一风险的第三方，而矿场事故只影响已经与矿场相关联的各方——这种外部性上的差异，而非底层技术上的差异，解释了为何监管对二者的处理方式如此不同。
类型：理论性/阐释性 (Theoretical/Interpretive)
提供的证据：直接的比较推理（城市街道 vs. 矿场）；引用标准的经济学外部性纠正工具（碳税作为气候外部性的内部化机制），并类比应用于自主机器损害的责任分配。
支持强度：作为将成熟经济学理论（外部性、通过责任/征税进行的庇古式纠正）应用于一个新情境（自动驾驶车辆监管）而言强 (Strong)，呈现出清晰的逻辑结构，尽管本章未引用具体的责任判例法或监管条文。
```

```
名称：用于评估完全自动化准备程度的"其他要素"清单

运作方式：随着机器执行预测之外每一项额外要素的收益相对于人类执行而言不断上升，某项任务就会朝着完全自动化迈进——采矿业达到了这一临界点，因为在 AI 到来之前，判断和行动早已被自动化/优化；特斯拉的驾驶（截至本书写作时）尚未达到这一临界点，因为有意义的判断/行动问题依然悬而未决；太空机器人技术则具体通过通信成本经济学达到了这一临界点。
适用场景：作为任何组织决定是否（以及以多快速度）为某项 AI 赋能任务追求完全自动化的诊断工具——而非假设"我们加入了预测，所以下一步就是完全自动化"，这个框架迫使人们对每一个剩余要素进行明确评估。
局限性：该框架是定性的；本章并未提供一个公式或临界值，来精确判断收益何时有利于机器完全执行某项要素，而是依赖逐案的例证性推理。
```

```
名称：基于外部性的监管预测框架
描述：一个用于预测某个具体自动化情境将受到多严格监管（因而完全自动化在法律/实践上有望多快变得可行）的框架，依据是该自动化行动的潜在危害被外部化（由第三方承担）的程度，与被内部化（仅由已经与该决策相关联的各方承担）的程度。

运作方式：高外部性（公共道路上的自动驾驶汽车、自主武器）预示着更严格的监管、更缓慢的完全自动化采用，以及更高的法律要求人在回路中的可能性；低外部性（自动矿用卡车、工厂车间机器人）预示着更宽松的监管和更快的完全自动化采用。
适用场景：作为企业或政策制定者用于预判哪些可自动化的 AI 领域将面临最大监管阻力的战略预测工具，也有助于理解为何完全自动化在各行业间进展不均——不仅仅是因为技术准备程度不同，也是因为外部性状况不同。
局限性：本章预测（而非通过已完成的例子加以证明）"一场围绕责任分配的重大政策发展浪潮"将随着自动化需求的增加而到来——这是一项经过适当限定的前瞻性论断，而非一种已经被观察到的监管模式。

背景：本章开篇，作为"没有时间思考"的主要例证——一种预测与所需行动之间的间隔太短、人类来不及反应的情形。
发生了什么：2016 年 12 月 12 日，jmdavis 正以约 60 英里/小时的速度在佛罗里达州的高速公路上行驶，此时他的特斯拉仪表盘显示前方有一辆他本人看不到的车（被他正前方的卡车挡住了视线）。他的紧急制动突然启动，在前方卡车明显减速之前；片刻之后，那辆卡车为躲避一辆实际上因路面碎片而停驶的车辆而转向路肩——而特斯拉经过雷达增强的预测（来自此前刚刚推送的一次软件更新）在卡车司机做出反应之前就已经检测到并做出了反应。jmdavis 写道，如果是手动驾驶，他很可能来不及及时停车，因为他自己根本看不到那辆停驶的车。

案例标题：力拓公司在皮尔巴拉的自动矿用卡车
人物/组织：力拓公司（矿业公司）；澳大利亚皮尔巴拉地区
背景：本章核心、最充分展开的案例，说明当预测之外的每一个要素都已经自动化时，完全自动化在经济上是最优的。

体现的概念：当一项任务的所有其他要素都已经自动化、预测是唯一剩下的瓶颈时，完全自动化作为自然的终点。

## 9. 反直觉洞见

```
洞见：机器在某项任务上可以客观上*优于*人类（推荐人们会觉得有趣的笑话），但人们依然更偏好——并报告更高的满意度——相信这项任务是由人类完成的，即便该推荐实际上是机器生成的。
常见看法：人们对某项推荐或行动的满意度，追踪的是其实际质量；更好的推荐应当在不考虑来源的情况下，产生更满意的用户。
作者的论证：对于某些类别的行动而言，行动被感知到的来源（人类 vs. 机器）会独立地影响满意度，这种影响与该行动被衡量的质量相分离，有时甚至与之相冲突——这意味着"更好"的机器表现，并不能保证在人类来源具有内在价值的领域中获得偏好或被采纳。
证据：Mike Yeomans 及其合著者的笑话推荐研究（第 5 节）。
为何令人惊讶：它表明自动化的经济学逻辑（机器能把 X 做得更好/更便宜）并不会自动转化为自动化的可取或被接受——这是一种不同于本章前面所讨论的法律/监管约束的独立约束，植根于该行动的人类来源对接受者而言意味着什么。
```

```
洞见：完全自主致命武器的主要障碍，可能并非抽象意义上的预测精度，而是任何用于锁定目标的预测机器都会立即成为对抗性操纵的目标这一事实——战斗人员很可能学会"迷惑"它——这意味着相关的技术门槛不仅仅是"它能否在正常条件下区分平民与战斗人员"，而是"它能否在主动的对抗条件下做到这一点"，这是一个远为更困难、更开放的问题。
常见看法：自主武器政策主要是一个伦理/法律问题，技术是一个已解决或可解决的背景条件。
作者的论证：这里完全自主性依然不切实际，还有一个实质性的技术原因（而不仅仅是伦理/法律原因）——对抗性钻空子——本章将其视为至少与政策指令本身同等重要，用以解释为何人在回路中的要求持续存在。
证据：本章自身关于战斗人员学会利用假设性预测机器的推理，与 2012 年国防部指令相结合。
为何令人惊讶：它将一场看似纯粹的伦理与政策辩论（机器是否应当被允许自主杀戮？）重新构建为——也许在短期内首要地——一个稳健性/安全工程问题（这台预测机器能否抵御蓄意的对抗性操纵？）。
```

## 10. 独特或不寻常的观点

```
观点：将"人类偏好人类"（在笑话、艺术、体育、照护方面）视为一个合理、独立的"人类行动收益"经济学类别——与由速度、成本或判断可编码性所驱动的收益并列，但在类别上截然不同。
为何显得独特：大多数关于自动化的经济学分析聚焦于基于效率/能力的收益；本章明确纳入一个充满价值判断、基于偏好的类别（其中一项行动的*来源*独立于其被衡量的质量而具有重要性），是对本书原本以效率为中心的框架的一次显著拓宽，并直接预示了第 16 章关于工作重新设计的讨论。
与其他主题的潜在联系：对真实性/人类来源之偏好的行为经济学；艺术与表演的社会学；劳动中价值与意义的哲学。
```

## 11. 张力、矛盾与开放问题

```
问题：本章预测人类对人类来源行动（笑话、艺术、体育、照护）的偏好可能是持久的，但随即又加以限定，指出人们"可能会随着时间推移，更能接受机器人照顾我们和我们的孩子"，并且"甚至可能享受观看机器人体育竞赛"——这意味着本章并未明确表态，"人类偏好人类"这一优势究竟是一种稳定、持久的自动化约束，还是一种可能随时间侵蚀的暂时性文化偏好。
作者的立场：真正的不确定/有所保留——本章清楚地陈述了当前的偏好，但明确将其标注为可能随时间变化，而非断言其永久性。
可能的反驳：如果这种偏好是文化上偶然的、很可能会转变的（正如本章自身所暗示的），那么"人类偏好人类"作为完全自动化的一道障碍，可能比本章前面所讨论的、基于更持久结构性特征（问责制、风险分配）而非变动的消费者品味的法律/外部性约束更为薄弱、更具时限性。
有助于解决此问题的证据：关于消费者/受众对 AI 完成的创造性、体育或照护行动的接受度随时间变化的纵向数据，本章并未提供（而这些数据在写作时可能尚不存在）——值得核实后续章节（第五部分，社会）是否重新审视这一持久性问题。
```

## 19. 跨书对比章节摘要

```
主要论点：将 AI 预测引入某项任务，并不会自动使其完全自动化——完全自动化还要求机器处理数据收集、判断和行动（第 8 章的决策解剖结构）——当预测之外的每一个要素都已经自动化时（采矿），当人类没有时间或没有必要思考时（紧急制动、奥运会摄像机），或当通信成本/延迟使人类控制变得不切实际时（太空机器人技术），完全自动化在经济上就会变得具有吸引力；但完全自动化也受到效率之外力量的制约——法律/伦理要求人在回路中（自主武器、电车难题）、塑造监管的外部性（公共道路 vs. 私人矿场），以及在充满价值判断的领域（幽默、艺术、体育、照护）中人类对人类来源行动的真实偏好，这与机器能力无关。
前 5 大核心概念：（1）完全自动化要求自动化所有决策要素，而不仅仅是预测。（2）"没有时间思考"vs."没有必要思考"作为不同的自动化理由。（3）由通信成本驱动的自动化（太空探索）。（4）外部性作为自动化的监管/责任约束。（5）人类偏好人类，作为充满价值判断、与能力无关的自动化局限。
前 3 大核心论点：（1）力拓的矿用卡车实现了完全自动化，因为预测是唯一剩下的依赖人类的要素（节省 15% 成本）。（2）自主武器在实现完全自主性方面，既面临法律障碍（2012 年国防部指令），也面临技术障碍（对抗性钻空子）。（3）机器在某项任务上（笑话推荐）能够客观上超越人类，但人们依然更偏好相信这项任务是由人类完成的。
前 3 大案例：（1）力拓公司皮尔巴拉自动矿用卡车。（2）特斯拉自动紧急制动轶事（jmdavis）。（3）2012 年美国国防部关于自主武器人在回路中的指令，配以电车难题。
前 3 大研究：（1）Mike Yeomans 及其合著者的笑话推荐研究（机器更好，人类更受偏好）。（2）[未发现第二项独立详述的正式研究——其他大部分证据来自公司/政策案例。]（3）[未发现第三项正式研究。]
最独特的观点：将"人类偏好人类"（在笑话、艺术、体育、照护方面）正式归类为一个独立的、人类行动收益的经济学类别——与速度、成本或判断可编码性方面的考量相分离、不可化约。
最反直觉的观点：当人们（无论真假地）被告知推荐来自人类时，他们评价机器推荐的笑话更有趣——尽管机器在客观上更擅长推荐人们会觉得有趣的笑话。
最大的弱点或开放问题：本章并未解决"人类偏好人类"究竟是一种持久的结构性自动化约束，还是一种很可能随时间侵蚀的变动文化偏好（本章明确对两种可能性都有所保留），使得这一因素在长期自动化预测中应占多大权重、相对于本章前面所讨论的更持久的法律/外部性约束而言，仍是一个悬而未决的问题。
最佳内容创作机会："为何一家矿业公司比任何一家汽车公司都更早实现了完全机器人化"（第 17 节）——一个具体、量化、令人惊讶的案例，围绕一个清晰、可迁移的诊断方法（有多少个非预测要素早已自动化），而非关于行业光环或技术复杂度的假设，重新构建了"哪些行业将率先实现自动化"这一问题。
