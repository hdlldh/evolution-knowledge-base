## 1. 章节论点

预测与判断之间的界限，并不像前几章可能暗示的那样固定：因为判断本身是通过反复出现的人类决策表现出来的，而 AI 天生擅长从反复出现的例子中学习模式，机器往往能够通过对人类所接收的输入以及据此做出的决策这类配对数据进行训练，学会*预测人类判断*本身——底层的预测问题变成了"给定这个输入，人类会怎么做？"这并不会消除人类的角色，但确实意味着预测能够侵入此前被认为需要持续人类参与的领域。尽管如此，人类在三种具体情形下依然保有持久的优势：机器缺乏学习判断所需的感官、揭示偏好或受隐私保护的数据的情形；相关事件过于罕见、机器没有足够的例子可供学习的情形（罕见事件、"未知的未知"）；以及人类能够用一个对底层过程的*模型*（而非原始历史数据）来做出良好决策、即便数据不足的情形——阿伯拉罕·瓦尔德在二战时期对轰炸机装甲的分析，生动地说明了这一独特的人类能力。

## 2. 核心概念

```
概念名称：预测人类判断（"人类会怎么做？"）
定义：这一观点认为，判断本身可以成为预测的目标——机器无需（或除了）预测外部世界状态，还可以在配对数据（人类接收到的输入，以及人类据此做出的决策）上进行训练，用以预测在新的输入下人类会做出什么决定，从而有效地学会模仿/自动化决策中的判断这一步骤，而不仅仅是预测这一步骤。
为何重要：这重新构建了第 8–9 章确立的人机边界：此前判断被视为一种不可化约的人类能力，机器仅仅是接收预测供其使用；而本章展示出，只要有足够的重复例子数据，判断本身也可以被机器学会——由此提出了一个（被直接提出的）问题：AI 最终能否很好地预测人类判断，以至于完全绕开对人类的需求。
作者如何使用：通过 Waymo 的自动驾驶汽车加以引入（它们不仅要学会如何抵达目的地，还要学会以让车内其他人感到舒适的方式刹车/驾驶——这是一种关于乘坐舒适度的人类判断，为每一种情况手工编码是不切实际的，因此系统改为被训练用以预测"人类在这种情况下会怎么做？"），随后加以推广："在任何人类反复做出决策的环境中，只要我们能够收集到他们所接收的输入数据以及他们据此做出的决策数据，我们就很可能通过奖励预测机器去预测'人类会怎么做？'来实现这些决策的自动化。"
相关概念：硬编码判断（第 9 章）、奖励函数工程、Grammarly 和 Lola 案例
```

```
概念名称：机器在预测判断方面的局限——可描述的偏好 vs. 细微的偏好
定义：区分了明确/可描述的判断标准（因而相对容易被机器学会）与更难以阐明或预见的细微人类偏好——后者机器依然可能学会，但需要足够多观察到的例子，有时甚至能够发现连人类专家自己都无法事先描述的标准。
为何重要：为"机器能够预测判断"这一论断增添了一个重要的细微差别：学习的难易程度取决于判断标准是否属于可以被明确化的类型，而机器在某些情况下能够发现连人类专家自己都从未阐明过的隐性人类决策标准（默会知识，呼应第 9 章 McAfee/Brynjolfsson 的引言）。
作者如何使用：以 Lola（一家旅行预订 AI 创业公司）为例加以说明，其 AI 发现在可描述的标准上（酒店可得性、价格）应用判断很容易，但最初无法匹配人类旅行顾问在迪士尼世界家庭度假预订方面的深厚默会专长（例如，知道要在大门开放前在乐园内预订早餐，从而让一家人能够在灰姑娘城堡前与孩子拍摄一张无遮挡的照片）——然而本章指出，Lola 的 AI *确实*最终发现了人类顾问事先无法描述的决策模式，例如偏好现代化酒店或位于街角的酒店。
相关概念：预测人类判断、默会知识（第 9 章）、人类训练者
```

```
概念名称：人类训练者（监督 AI 直至最终无需人工纠正）
定义：在过渡期让人类监督 AI 判断预测的表现、纠正其错误的做法，使 AI 能够从这些纠正中学习，直到它变得足够好、不再需要人工纠正——在自动化一个容错空间极小的流程时，这一点尤为重要。
为何重要：描述了"机器学会预测判断"在实践中实际发生的现实操作路径——并非单一的训练事件，而是一个持续的人在回路中的纠正过程，具有一个明确（尽管隐含）的终点，届时人类对于该任务的这一具体方面而言就不再必要了。
作者如何使用：在 Lola/Grammarly 讨论之后，作为一般性原则提出，没有给出单独完整展开的例子，但隐含地与两个案例中"从专家纠正过的语料库学习"（Grammarly）、"接受/拒绝建议的反馈"（Grammarly），或"观察到的顾问预订记录"（Lola）的描述相联系。
相关概念：预测人类判断、例外预测（第 7 章）
```

```
概念名称：人类拥有而机器（目前）尚不具备的三种数据
定义：一个分类法，列出了三种具体的数据优势，这些优势目前使人类在机器日益擅长预测判断的情况下依然保持相关性：（1）人类感官——人类的眼睛、耳朵、鼻子和皮肤在许多方面依然超越机器的感官能力；（2）人类是自身偏好的最终仲裁者——消费者偏好数据之所以有价值，正是因为只有人类才能揭示它，这也是企业大力投资（会员卡折扣、以数据换取免费服务）来提取它的原因；（3）受隐私限制的数据——只要人们对某些类别的信息（性活动、财务状况、心理健康状况、"令人反感的想法"）守口如瓶，机器在这些领域预测行为时就会缺乏足够的数据，为植根于人际理解、不需要同样明确数据的人类判断留下空间。
为何重要：为"人类会被排挤出局吗？"这一问题提供了一个具体的三部分答案——将"人类是一种资源"这一抽象论断，落实为具体、可操作的比较优势类别，招聘/组织决策可以据此构建。
作者如何使用：直接回答了本章"人类会被排挤出局吗？"这一小节标题；三种数据类型各自都配有一个简短的支撑性例子（会员卡；谷歌/Facebook 以数据换取免费服务的模式；受隐私保护的类别清单）。
相关概念：预测依赖数据、隐私权衡（预告了第四部分的讨论）
```

```
概念名称：数据稀少下的预测（罕见事件再探）
定义：机器预测判断能力的第二个持久局限：机器需要足够多观察到的例子才能学会某个模式，因此本质上罕见的（或完全新颖的）事件，会使机器缺乏足够的数据来预测该事件本身、或人类会对其运用何种判断——直接建立在第 7 章"已知的未知"（罕见、可预见地难以预测的事件，如选举/地震）和"未知的未知"（真正前所未有的事件）之上。
为何重要：确立了预测判断，与预测任何其他结果一样，受制于相同的基本数据可得性约束——无论机器的模式匹配能力变得多么复杂，它都无法预测"人类在一个它从未观察到人类真正面对过的情况类型中会怎么做"。
作者如何使用：明确交叉引用了第 7 章的已知的未知/未知的未知框架，重申人类在数据稀少情况下的预测能力依然相对出色（例如，即便随着人们年龄增长依然能够认出人脸，这是第 7 章一个被重复使用的例子），并将这一观点延伸至战略性商业决策：一家面对真正新技术（互联网、生物工程，或 AI 本身）的公司，无法被机器很好地预测，因为数据中不存在相关相似的先例，而人类能够跨越不同情境进行类比推理。本章进一步以日常但前所未有的公司决策为例加以扎根：你应该在产品线中增加一款新产品吗？与竞争对手合并吗？收购一家创新型创业公司或渠道合作伙伴吗？这里更犀利的机制并非仅仅因为这些事件罕见，而是人们的行为会*恰恰因为*所考虑的这项决策而发生改变——因此过去的行为不再是未来行为的有用指引，使预测机器缺乏相关数据。
相关概念：已知/未知分类法（第 7 章）、未知的已知与读书反事实例子（对第 7 章的回顾）
```

```
概念名称：实验与建模，作为人类（有时也是机器）应对数据不足的两种方案
定义：当你缺乏足够的自然/历史数据来预测某个结果或其背后的判断时，做出良好决策的两种不同策略：（1）实验——通过随机分配不同条件（例如，一项随机对照试验）来刻意生成新数据，并观察结果，人类和（当情境足够频繁发生时）机器都可以使用；（2）建模——对生成所观察数据的过程建立深入、结构性的理解，从而能够推断出缺失或反事实的数据，而无需直接观察它，在实验不可行时（因为情境发生频率不够高，或实验成本过高）尤其有价值。
为何重要：为克服前面所述"数据稀少下的预测"这一局限，提供了两种互补的人类（并部分可由机器使用的）工具——表明数据稀缺并不总是意味着决策瘫痪，但通常确实需要投资于新数据生成（实验）或投资于结构性理解（建模），这两者目前都更多依赖于独特的人类技能，尤其是对于一次性或高风险情境而言。
作者如何使用：重新审视了第 7 章的图书推荐反事实例子，用以具体引入随机对照试验/实验的概念（随机将部分读者分配到"处理组"（读这本书），另一部分分配到"对照组"（不读这本书），随后比较各组在工作中如何应用 AI）；随后通过 ZipRecruiter 定价案例（重温第 9 章）加以引入，并且最生动地，通过阿伯拉罕·瓦尔德的二战轰炸机装甲案例（第 7 节）加以引入。
相关概念：随机对照试验（第 7 章哥伦比亚银行案例）、反事实（第 7 章）、阿伯拉罕·瓦尔德的轰炸机案例、人类奖励函数工程师
```

## 3. 核心论点

```
论点：在任何人类反复做出决策、并且能够收集到他们所接收的输入以及他们据此做出的决策的领域中，很可能通过训练一台预测机器去预测"人类会怎么做？"来实现这些决策的自动化——驾驶并非一个独特或特殊的案例。
类型：理论性/阐释性 (Theoretical/Interpretive)
提供的证据：Waymo 自动驾驶案例（通过预测人类驾驶反应而非为每种场景手工编码规则，来学习让人感到舒适的刹车行为），被推广为一项更宏观的原则。
支持强度：中等 (Moderate) —— 驾驶这个例子展开充分、合情合理，但这一泛化论断（"在任何环境中……"）被作为一项宏观原则加以断言，本章内并未在多个额外领域中独立加以检验。
```

```
论点：Grammarly 成功地预测了人类编辑会怎么做——超越了机械的语法规则应用，去评估偏离"完美"语法的表述是否实际上更受人类读者的偏爱——通过从两个数据源学习：一个由熟练编辑校对过的文档语料库，以及接受或拒绝其建议的用户反馈。
类型：实证性 (Empirical)
提供的证据：一个具体、可核实的例证例子（本章将其自己前面的一句话输入 Grammarly，Grammarly 标记出"It's"应为"Its"，以及"grammer"拼写错误，并指出"main"一词经常被过度使用）；对 Grammarly 创立过程（2009 年，由 Alex Shevchenko 和 Max Lytvyn 创立）及其双重训练方法的描述。
支持强度：对于这一例证性机制而言强 (Strong)（一个具体、读者可自行核实的例子），尽管未给出关于 Grammarly 整体表现的量化精度/采用率指标。
```

```
论点：Lola 的 AI 在自动化旅行预订判断方面，能够轻松复制在可描述标准（酒店可得性、价格）上的判断，但最初无法匹配人类旅行顾问在家庭度假预订方面更深层、默会的专长——尽管随着时间推移，该 AI 能够发现人类顾问自己也无法事先阐明的决策模式。
类型：实证性 (Empirical)
提供的证据：《纽约时报》报道中的一段直接引言：该 AI "无法匹敌，例如，一位拥有多年为迪士尼世界预订家庭度假经验的人类顾问的专业能力。人类能够更加灵活——比如，知道该建议一个希望为孩子们在灰姑娘城堡前拍一张无遮挡照片的家庭，应当在大门开放前预订乐园内的早餐"；本章自身的后续观察指出，Lola 的 AI 确实发现了顾问原本无法阐明的其他偏好（例如，偏好现代化酒店或街角酒店）。
支持强度：对于这一具体报道的例子而言强 (Strong)（归属于具名创始人的公司和一家主流新闻媒体），尽管关于"最终发现"隐性标准这一论断，仅以两个简短的例子（现代化酒店、街角酒店）加以佐证，而非系统性证据。
```

```
论点：人类通过三种具体机制，在预测判断方面相对于机器保有持久的、基于数据的优势：更优越的感官能力（视觉、听觉、嗅觉、触觉），作为真实偏好数据的唯一直接来源，以及隐私规范使得整整一类与行为相关的数据（性活动、财务、心理健康、不可接受的想法）无法被机器获取。
类型：理论性/阐释性 (Theoretical/Interpretive)
提供的证据：针对每一个类别给出的例证性、未量化的例子（会员卡折扣和免费的谷歌/Facebook 服务作为提取偏好数据的机制；被具名列出的受隐私保护的类别）。
支持强度：中等 (Moderate) —— 一个合理、条理清晰的分类法，但通过例证性推理呈现，而非通过量化各项优势实际规模或持久性的数据/研究。
```

```
论点：对于罕见或真正新颖的情形（延伸自第 7 章的已知的未知/未知的未知类别），机器在预测判断方面依然表现不佳，包括关于如何应对新技术的战略性决策，因为数据中没有足够相似的历史先例可供机器学习，而人类能够跨越表面上不同的情境进行类比推理。
类型：理论性 (Theoretical)
提供的证据：对第 7 章分类法的重申性交叉引用；人类即便随年龄增长依然能识别人脸的例子（重复使用自第 7 章）；断言一家面对互联网、生物工程或 AI 驱动颠覆的公司，无法通过机器预测得到良好的战略判断服务。
支持强度：中等 (Moderate) —— 与已确立的已知的未知/未知的未知框架逻辑一致，但本具体章节除了重申并延伸第 7 章的论证外，并未添加新的独立证据。
```

```
论点：阿伯拉罕·瓦尔德在二战时期对返航轰炸机损伤模式的分析——正确地建议在返航飞机*没有*发现弹孔的地方增加装甲，而非在有弹孔的地方——需要对底层数据生成过程（哪些飞机得以幸存、被观测到）进行结构性建模，而无论是原始数据本身，还是一台预测机器（无论是当时，还是据作者所言，在可预见的未来）都无法产生这样的洞见。
类型：历史性/实证性（一个具体、有充分记录的历史事件） (Historical/Empirical)
提供的证据：所描述的推理过程：工程师希望在不影响性能的前提下为飞机增加装甲，但无法通过代价高昂/致命的实验来确定具体位置；统计学家阿伯拉罕·瓦尔德被咨询；他意识到观测到的弹孔数据存在系统性偏差，因为它排除了未能返航的轰炸机（在未被观测到的、大概率致命的位置被击中而被摧毁）；空军工程师据此在*没有*观测到弹孔的位置增加了装甲，提高了生存率，引用于尾注 3。
支持强度：强 (Strong) —— 一个具体、有充分记录的历史案例（在统计学中被广泛视为幸存者偏差的经典例证），具有清晰的因果机制和结果，归属于一位具名、有资历的历史人物。
```

```
论点：瓦尔德的洞见需要理解生成（缺失）数据的过程——本章断言，这种推理"在可预见的未来"依然"超出了预测机器的能力范围"，尤其是在相关问题没有先前历史例子可供借鉴的情况下（正如二战轰炸机存活率问题当时那样）。
类型：阐释性 (Interpretive)
提供的证据：紧接在瓦尔德案例之后的直接断言，被构建为一种持久的、结构性的局限，而非暂时的技术差距。
支持强度：中等 (Moderate) —— 一项关于预测机器可预见未来能力的强论断，以坚定的信念提出，但没有独立的技术证据来证明这种推理为何对当前或近期的 AI 而言在结构上是不可能的（而非仅仅是困难的）。
```

## 4. 框架、模型与思维模型

```
名称："人类会怎么做？"作为一个通用训练目标
描述：对许多自动化问题的一次重构：与其试图直接手工为每一种情况指定正确的行为，不如收集配对数据，涵盖（a）人类决策者所接收的输入，以及（b）人类据此做出的决策，然后训练一台预测机器，在给定（a）的情况下预测（b）——有效地将判断自动化转化为一个标准的监督式预测问题。
组成部分：一个反复出现的人类决策过程；可收集的输入数据；可收集的结果数据（人类的实际决策）；一台被训练用于将输入映射到人类决策输出的预测机器。
运作方式：适用于任何"反复"做出、具有可观察输入和输出的决策——机器不需要明确的规则，只需要足够多的配对例子来学习从输入到人类判断的映射，就像它学习任何其他预测任务一样。
适用场景：作为识别判断密集型任务中自动化机会的通用模板，不同于（也补充了）此前"硬编码判断"（第 9 章）的方法——这种方法让机器从例子中学习判断，而不需要人类事先明确阐明奖励函数。
局限性：只有当（a）该决策发生的频率足够高，能够产生充足的训练数据，（b）相关的输入和人类决策实际上能够被捕捉为数据，且（c）所要预测的人类判断不依赖于机器在结构上无法获取的数据类型（感官、揭示偏好或受隐私保护的数据）时才有效——这些局限在本章后续小节中得到了展开。
```

```
名称：实验 vs. 建模（作为应对数据不足情境的两部分工具箱）
描述：一个框架，区分了在历史/观测数据不足时做出良好决策或预测的两种不同策略，二者的差别在于是生成新数据（实验）还是通过结构性理解从现有/有限数据中提取更多信息（建模）。
组成部分：实验——随机分配到处理/对照条件，观察结果对比；需要一种发生频率足够高、值得设计并开展试验的情境。建模——对数据生成过程的一种基于理论的理解，能够对（例如关于未观测到的反事实或系统性缺失的数据）做出正确推断，而无需直接观察每一个相关案例。
运作方式：实验通过图书推荐随机对照试验的概念加以说明，并被明确指出一旦某种情境发生频率足够高，机器同样也能加以利用（本章将这一点与机器如今在各类电子游戏中通过自我对弈/实验超越人类联系起来）。建模通过 ZipRecruiter 需要为其单靠定价实验无法揭示的更长期利润最大化目标建模、以及最戏剧性地，通过瓦尔德的轰炸机装甲分析加以说明——由于"缺失的"（未返航的）轰炸机永远无法被直接观测到，只能对其进行结构性推理。
适用场景：当某个决策/情境是可重复、可测试的时候，实验最为适用；建模则在实验不可能（情境过于罕见）或成本过高（正如二战轰炸机存活率问题，"实验"意味着损失飞行员生命）时至关重要。
局限性：本章明确指出，建模技能需要深入的训练（引用了经济学博士项目和 MBA 课程，包括作者们在多伦多大学开发的课程），并警告指出，若没有这种技能，决策者就有陷入"未知的已知"陷阱（第 7 章）的风险——即在底层数据生成过程（包括像瓦尔德的幸存者偏差这样的选择效应）未被恰当建模的情况下，将预测机器的模式匹配输出误认为真正的因果理解。
```

## 7. 案例与故事

```
案例标题：Waymo 的自动驾驶汽车与令乘客感到舒适的刹车
人物/组织：Waymo（谷歌子公司）
背景：本章开篇，作为通过"人类会怎么做？"这一训练目标来"预测判断"的主要例证。
发生了什么：Waymo 成功测试了两点之间的自动化运输，但驾驶还需要管理对乘客的影响，而这比导航的机械层面要难以直接观察得多——例如，以让车内其他人感到舒适的方式刹车，这也是新手人类司机必须学习的一项技能。由于驾驶涉及成千上万个相关的微观决策，为每一种可能的情况手工编码判断是不切实际的；相反，Waymo 通过许多例子来训练其系统，学习预测人类判断（"人类在这种情况下会怎么做？"）。
结果：用于引出本章更宏观的论断——任何具有反复出现的人类决策以及可观察输入/结果数据的领域，很可能都能以同样的方式实现决策自动化。
体现的概念：预测判断作为硬编码判断的一种替代方案，尤其适用于涉及难以观察的效果（乘客舒适度），而非容易明确的目标（抵达目的地）的判断。
此案例为何有用：一个知名度高、真实、技术上颇为复杂的例子，通过一家广为人知的公司和产品类别，使一个抽象的"预测判断"概念变得具体。
复用潜力：高 (High)
```

```
案例标题：Grammarly 与预测编辑判断
人物/组织：Grammarly；创始人 Alex Shevchenko 和 Max Lytvyn（2009 年创立）
背景：本章第二个关于预测判断的重大例证，是在文本编辑而非物理驾驶领域。
发生了什么：Grammarly 率先运用机器学习来改进正式书面写作，主要聚焦于语法和拼写。它通过两个来源加以实现：一个由熟练编辑校对过的文档语料库，以及用户对其自身建议接受或拒绝的反馈——在这两种情况下，都是在预测人类编辑会怎么做。它超越了机械的规则应用，去评估偏离严格语法正确性的表述是否实际上更受人类读者的偏爱（暗示某些"错误"在文体上可能更受欢迎，而 Grammarly 也学到了这种偏好，而不仅仅是规则本身）。
结果：本章通过将其自己前面的一句话输入 Grammarly 直接展示了这一点，Grammarly 正确标记出一个缩写错误（"It's"应为"Its"）和一个拼写错误（"grammer"应为"grammar"），并单独标记出"main"一词在文体上被过度使用。
体现的概念：通过双重训练来源（专家校对过的语料库+用户接受/拒绝反馈）预测判断，并超越基于规则的正确性，去预测真实的人类/读者偏好。
此案例为何有用：一个立即可验证的、自我展示的例子（读者可以自行测试 Grammarly），使"超越机械规则预测判断"这一概念变得具体、可核实。
复用潜力：高 (High)
```

```
案例标题：Lola 与预测旅行预订判断的局限
人物/组织：Lola（旅行预订自动化创业公司）；《纽约时报》（被引用的报道）
背景：本章核心的警示性/细化性案例，展示了预测判断目前在哪些方面依然不及专家的人类默会知识——同时也展示了机器最终能够发现隐性标准。
发生了什么：Lola 的 AI 通过基于可描述标准（可得性、价格）寻找优质选项来自动化酒店预订，但据《纽约时报》报道，它最初无法匹配人类顾问的专业能力——例如，知道要在大门开放前在迪士尼世界内预订早餐，专门用以帮助一个家庭在灰姑娘城堡前为孩子们拍摄一张无遮挡的照片。然而，Lola 的 AI 确实最终发现了人类顾问实际上一直在运用、却无法事先描述的决策模式，例如偏好现代化酒店或街角酒店。
结果：为 AI 判断预测部署的核心开放问题提供了框架：除了那些容易描述、能够快速学会的标准之外，一台预测机器需要多少次观察，才能学会更微妙、更难以阐明的标准？
体现的概念：容易描述的判断标准（学习速度快）与细微/默会的判断标准（学习速度慢，但未必学不会，有时甚至连被模仿的人类专家自己都无法阐明）之间的梯度。
此案例为何有用：一个细致入微、诚实的案例（并非简单的"AI 成功"或"AI 失败"），捕捉了预测判断的真实复杂性，同时配以一个生动、具体、能引起情感共鸣的例子（迪士尼世界的家庭拍照瞬间），使抽象的"默会专长"概念变得具体。
复用潜力：高 (High)
```

```
案例标题：阿伯拉罕·瓦尔德与二战轰炸机幸存者偏差
人物/组织：阿伯拉罕·瓦尔德（统计学家）；盟军空军工程师；二战对德国的轰炸行动
背景：本章核心、最生动的例证，展示了"建模"作为一种独特的人类工具，用于对结构性缺失（而非仅仅是罕见）的数据进行推理。
发生了什么：盟军工程师希望在不影响性能的前提下为轰炸机增加装甲，这要求他们精确确定应在何处增加重量。原则上直接实验是可能的，但代价过于高昂（飞行员会因此丧生）。工程师们观察了从德国上空轰炸任务中*返航*的轰炸机上的弹孔损伤模式，最初假设这些被击中的位置正是需要更多装甲的地方。统计学家阿伯拉罕·瓦尔德被咨询后，经过仔细的数学推理，给出了相反的建议：为*没有*观测到弹孔的区域加装装甲。他的洞见在于，数据存在系统性的删失——一些轰炸机根本没有返航，瓦尔德推断，这些缺失的轰炸机很可能是在那些（不同于幸存者被击中的位置）被证明是致命的位置被击中的。空军工程师采纳了瓦尔德的建议，在没有弹孔的区域增加了装甲，提高了飞机的存活率。
结果：一个如今已成为经典的例子（在统计学中普遍如此，尽管本章未提及其更广泛的知名度），说明了如何通过对数据生成和数据删失过程的结构性推理，而非对观测数据模式的表面解读，来解决幸存者偏差问题。
体现的概念：建模作为一种正确解读（并纠正系统性偏差的）可用数据的方式，通过对产生该数据的过程进行推理——包括对结构性缺失（被摧毁的轰炸机）而非仅仅是统计学上罕见的数据进行推理。
此案例为何有用：一个异常知名、有充分记录、高风险的历史案例，使一个抽象的统计学概念（选择/幸存者偏差，以及结构性建模相对于天真模式匹配的价值）变得生动、令人难忘，并能立即迁移到商业/数据情境中。
复用潜力：高 (High)
```

## 9. 反直觉洞见

```
洞见：对于二战返航轰炸机弹孔损伤数据的正确应对，是在*没有*可见损伤的地方加装装甲，而非有损伤的地方——因为在那些看似未受损区域的真正危险地带被击中的飞机，根本没能返航被观测到。
常见看法：应当加固实际观测到损伤的区域，因为证据显示飞机就是在那里被击中的。
作者的论证：观测到的数据由于一种选择/删失过程而存在系统性偏差（只有幸存的轰炸机才能被观测到），因此天真地根据可见模式采取行动，本会适得其反；正确的行动需要对未被观测到的、"缺失"的数据（被摧毁的轰炸机）进行结构性推理。
证据：阿伯拉罕·瓦尔德对二战轰炸机装甲的分析及其在现实世界中的实施和结果。
为何令人惊讶：它颠覆了那个看似"数据驱动"的直觉结论（保护观测到损伤的地方），转而支持一个需要对数据中系统性*缺失*之物进行推理的结论——本章明确指出，这一课在可预见的未来"依然超出了预测机器的能力范围"。
```

```
洞见：机器有时能够发现并阐明连人类专家自己都从未能事先描述的隐性人类决策标准（例如，Lola 的 AI 揭示出旅行顾问对现代化或街角酒店的未言明偏好）。
常见看法：如果一位人类专家无法解释自己为何做出某个选择，那么这种判断一定过于默会/微妙，机器永远无法学会或复制。
作者的论证：只要有足够多配对的输入-决策数据，机器的模式匹配有时能够察觉出人类行为中一种真实、一致的标准，即便表现出该行为的人类自己也无法阐明它——这意味着默会知识并非总是机器学习无法逾越的硬性界限，只是无法被明确硬编码（第 9 章 McAfee/Brynjolfsson 的局限适用于编码化，而不一定适用于经学习得到的预测）。
证据：Lola 案例中具体提及发现了顾问对现代化酒店和街角酒店的偏好，而这些偏好是顾问"事先无法描述"的。
为何令人惊讶：它表明机器学习在某些情况下，能够超越人类对自身决策标准的自我认知——一台机器可能"知道"一位人类专家为何做某件事，甚至比该专家自己能解释得更清楚。
```

## 10. 独特或不寻常的观点

```
观点：将"判断"本身，而不仅仅是外部世界状态，视为一个合理的预测目标——通过展示判断本身可以作为一种从配对输入-决策数据中学到的模式，有效地打破了本书在第 8–9 章精心确立的预测/判断区分的一部分。
为何显得独特：本书大部分框架（第 8–9 章）将预测和判断视为可清晰分离、彼此互补的决策输入，判断被持久地保留给人类；本章则引入了一个有意义的复杂情况——判断只有在数据约束（感官、偏好、隐私、稀有性）阻止机器学习它的地方，才是持久属于人类的，而非作为一项原则性的问题。
与其他主题的潜在联系：机器学习中的模仿学习与行为克隆；对判断的习得性模仿是否构成"真正"判断这一哲学问题。
```

## 11. 张力、矛盾与开放问题

```
问题：本章的开篇论断（"在任何人类反复做出决策的环境中……我们很可能能够实现这些决策的自动化"），与第 8–9 章将判断构建为持久的、独特的人类预测互补品这一框架之间存在张力——本章相当程度上缩小了这一持久性论断，将真正持久的人类判断局限于仅仅三种基于数据的情形（感官/偏好/隐私数据）加上罕见事件情形，这比仅仅阅读第 8–9 章可能给人的印象要狭窄得多。
作者的立场：本章确实直接提出了"人类会被排挤出局吗？"这一问题，并回答"我们不这么认为"，但其自身的支撑性推理（三种具体的、有可能被侵蚀的数据优势，例如随着传感器的改进或隐私规范的变化）并不能完全保证这种持久性——本章自身的逻辑表明，随着传感器技术和数据共享规范的变化，这些优势原则上可能会随时间而缩小。
可能的反驳：持怀疑态度的读者可能会指出，这三种"持久的"人类数据优势（感官能力、揭示偏好、受隐私保护的数据）都是持续的技术和商业投资的目标（更好的传感器、更积极的消费者数据提取、不断演变的隐私规范/法规）——这意味着今天的持久优势未必能无限期地保持持久，而本章并未明确加以探讨或对此进行对冲。
有助于解决此问题的证据：后续关于 AI 风险（第 20 章）和社会影响（第 21 章）的章节，或许会具体涉及隐私这一维度（自第 1 章"权衡"框架以来已被标记为一个反复出现的主题）——值得核实它们是否重新审视了本章关于持久的隐私基础局限这一假设。
```

## 19. 跨书对比章节摘要

```
主要论点：前几章确立的预测/判断边界并非固定不变——机器往往能够通过在配对的输入-决策数据上进行训练（"人类会怎么做？"），学会预测人类判断本身，如 Waymo、Grammarly，以及（存在重要局限的）Lola 所展示的那样——但人类在三种具体的、受数据约束的情形（感官数据、揭示偏好、受隐私保护的数据）以及机器缺乏足够例子的罕见/新颖情形中，依然保有持久的优势，在这些情形中，独特的人类工具——实验，尤其是结构性建模（如阿伯拉罕·瓦尔德对二战轰炸机的分析）——依然是必要的。
前 5 大核心概念：（1）通过"人类会怎么做？"预测人类判断。（2）容易描述的判断标准与默会判断标准之间的梯度（Lola）。（3）人类拥有而机器没有的三种数据（感官、偏好、隐私）。（4）数据稀少下的预测——重温第 7 章的罕见事件和未知的未知。（5）实验 vs. 建模，作为应对数据不足决策的人类工具箱。
前 3 大核心论点：（1）任何具有可捕捉输入/结果数据的反复出现的人类决策，都很可能通过训练机器预测人类判断而实现自动化。（2）机器有时能够发现人类自己都无法阐明的隐性人类决策标准（Lola 的酒店偏好）。（3）需要结构性建模（而非原始数据解读）才能正确解读系统性删失/缺失的数据，正如瓦尔德的轰炸机案例所示——作者认为这项能力在可预见的未来依然超出了预测机器的范围。
前 3 大案例：（1）阿伯拉罕·瓦尔德对二战轰炸机幸存者偏差的分析。（2）Lola 的旅行预订 AI 与灰姑娘城堡拍照例子。（3）Waymo 的自动驾驶汽车通过"人类会怎么做？"学习令人舒适的刹车。
前 3 大研究：本章未正式引用任何独立的学术研究——证据来自真实公司案例和一段历史事件（瓦尔德），而非被引用的研究论文。
最独特的观点：将判断本身（而不仅仅是外部世界状态）重新构建为一个合理的、可学习的机器预测目标，有意义地缩小了第 8–9 章所确立的"判断持久地属于人类"这一框架。
最反直觉的观点：对二战轰炸机损伤数据的正确应对，是在没有观测到弹孔的区域加装装甲，而非被击中的区域——因为真正危险的被击中位置，会在其轰炸机被观测到之前就将其摧毁。
最大的弱点或开放问题：本章所述的三种"持久的"人类数据优势（感官、偏好、隐私），都是持续的技术和商业侵蚀的潜在目标（更好的传感器、更积极的数据提取、不断变化的隐私规范），本章并未探讨这些优势实际上能否持续、能持续多久。
最佳内容创作机会："为何统计学家告诉空军要在没有弹孔的地方加装甲"（第 17 节）——一个异常生动、高风险的历史案例，能够干净利落地迁移到商业分析、投资，以及关于幸存者偏差的一般性批判性思维内容中。
```
