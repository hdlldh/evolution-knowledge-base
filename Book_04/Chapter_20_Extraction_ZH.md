## 1. 本章论点

作为第四部分"战略"的收尾，本章主张，部署预测机器带来若干独立的、不可避免的风险类别，企业领导者必须提前预见这些风险，而不能指望将其彻底消除：责任风险（AI 可能产生歧视性结果——即便是无意的——从而带来真实的法律风险）、质量风险（仅基于相关性数据训练的 AI 可能将虚假的关联误认为因果关系，尤其是在"未知的已知"这种情况下——一个自信满满的预测其实是错的）、以及安全风险（AI 系统同样容易受到对其输入数据、训练数据与反馈数据的操纵）。每一种风险类型都通过一个真实的、往往令人吃惊的案例加以说明——种族倾向性的谷歌广告结果、性别倾向性的 Facebook 招聘广告、eBay 被高估的广告投资回报率、对抗性视频误分类、微软通过工具栏对谷歌搜索的逆向工程，以及 Tay 聊天机器人迅速沦为种族主义言论——这些都确立了一点：审慎的人类监督、审计与前瞻性的风险管理，依然是预测不可或缺的补充，而非可有可无的事后考虑。

## 2. 关键概念

```
概念名称：通过质量得分优化而产生的算法歧视（而非恶意意图）
定义：这一现象指的是，一套 AI 系统产生带有种族或其他歧视性色彩的输出，并非因为有人将其编程为具有歧视性，而是因为其优化目标（例如，一个促使更可能被点击的广告获得推广的"质量得分"）无意中放大了已经存在于人类总体点击行为中的偏见——这意味着，歧视可以作为一个看似中立的目标函数所产生的一种统计学意义上的涌现性副产品出现。
为何重要：确立了 AI 驱动的歧视并不需要一个心怀歧视的行为者或明确的意图——它可以纯粹地从一套优化算法与带有偏见的真实世界行为数据之间的相互作用中产生，而这恰恰使其难以被察觉，并容易被当作"数据本来就是这样"而被轻易搁置。
作者如何使用：通过 Latanya Sweeney 案例引入（谷歌广告暗示存在逮捕记录，这种情况在带有黑人色彩的姓名中出现的比例不成比例地高），作者们逐步梳理了一个具体的假设机制：如果潜在雇主在研究求职者时，对带有黑人色彩姓名旁边出现的暗示逮捕记录的广告更容易点击，那么该广告-关键词组合由此获得的更高"质量得分"，就会导致谷歌的算法为这些姓名更频繁地投放该广告——而无需谷歌或广告主一方有任何种族定向的意图。本章借助 Facebook 案例提出了一个更为犀利的相关观点：向男性而非女性展示 STEM 广告，实际上提振了短期运营业绩（展示给男性的广告成本更低），这意味着这一歧视性模式看起来像是良好的业务表现，即便它同时也在积累"可能要到为时已晚才会显现出来"的战略与法律风险。
相关概念：差别性影响、AI 黑箱问题
```

```
概念名称：差别性影响责任
定义：这是一个法律概念（区别于差别性对待，即故意对不同群体施加不同的标准），依据这一概念，一项表面中立的程序或算法，如果系统性地对一个受法律"保护类别"产生更差的结果，依然可能带来法律责任——无论这种歧视性效果是否出于故意，这一责任都会成立。
为何重要：确立了一家公司不能仅仅通过指出其 AI 的决策过程是中立的或自动化的，就为自己免除歧视责任——法律标准关注的是结果的模式，而非是否存在歧视意图，这意味着"是算法做的，不是我们"并非一个站得住脚的法律辩护理由。
作者如何使用：通过经济学家/律师 Ben Edelman 对 Facebook STEM 广告性别倾向案例的框定加以解释，随后落实到一个具体的先例（纽约市消防局因一场高度侧重阅读理解的入职考试而支付 9900 万美元和解金——该考试被发现与工作实效无关，却系统性地不利于黑人和西班牙裔申请者）。
相关概念：通过质量得分优化而产生的算法歧视、"AI 神经科学"
```

```
概念名称："AI 神经科学"——审计黑箱模型的歧视性行为
定义：计算机科学界部分人士用来指代这样一种做法的术语：调查一套不透明的 AI 模型（例如，一个无法直接检视其内部公式/算法、判断何种因素导致何种结果的深度学习系统）为何产生其所产生的输出——具体方法是先对可能驱动所观察到的差异的因素提出假设，然后为 AI 提供专门设计用于检验该假设的不同输入数据，最后比较由此产生的预测结果。
为何重要：为 AI 黑箱本质所带来的原本令人束手无策的问题，提供了一种具体的、可付诸行动的方法论——你无需能够读懂一个算法的内部逻辑，就能够从外部通过实验的方式，探测并诊断其歧视性行为。
作者如何使用：以经济学家 Lambrecht 与 Tucker 具体如何诊断出 Facebook STEM 广告性别倾向问题（发现其根源在于每次展示成本的经济学，而非点击率差异或存在歧视性劳动力市场）为例加以说明，并呈现为任何组织都应如何审计自身 AI 系统歧视性输出的一个模板。
相关概念：差别性影响责任、通过质量得分优化而产生的算法歧视
```

```
概念名称：未知的已知，作为一种质量风险失效模式
定义：这是一种具体的、尤其危险的 AI 质量风险类型（延伸了第 7 章的已知的已知/未知的未知框架），在这种情况下，一台预测机器给出一个自信满满、看似有充分依据的预测，但实际上是错误的——最常见的原因是，该 AI 所训练的数据从未包含正确评估因果影响所需要的那个反事实情境（例如，训练数据中有"大量的广告与销售"，却没有关于在广告很少或没有广告的情况下销售会是什么样子的数据）。
为何重要：识别出一种失效模式，其中 AI 自身的自信恰恰就是危险信号——这台预测机器并非明显故障或不确定，它是悄无声息地、令人信服地出错，这远比一个明显低置信度或功能失常的预测更加危险。
作者如何使用：通过 eBay 广告投资回报率案例加以展示，其中一份天真的相关性分析显示搜索广告带来了巨大的正投资回报率（超过 4000%），但一次真实的实验（在美国三分之一的地区关闭广告一整个月）却揭示出真实的投资回报率是负的——那个缺失的反事实数据（"广告很少时会发生什么"）正是一个未知的已知，只有刻意的实验才能将其揭示出来。
相关概念：已知的已知/未知的未知框架（第 7 章）、反向因果关系（第 7 章）
```

```
概念名称：安全风险分类法——输入、训练与反馈数据的漏洞
定义：一个三部分的框架，根据攻击者操纵的是哪一种数据类型（第 6 章确立的输入、训练、反馈三类），对 AI 安全风险加以分类。输入数据风险涉及向一台已部署的 AI 输入被污染的或经过对抗性设计的数据，以扭曲某一具体的预测（例如，插入短暂的闪现图像以欺骗视频分类系统，或输入虚假的身份数据以操纵一项个性化的医学预测）。训练数据风险涉及攻击者对一个已部署的模型进行足够多次的探询/查询，从而逆向推导出其底层算法，实质上窃取了嵌入其训练过程中的知识产权。反馈数据风险涉及攻击者刻意向一台正在真实世界中学习的 AI 输入被污染的互动数据，从而随着时间推移，系统性地教会它错误或有害的行为。
为何重要：将 AI 安全思维，从泛泛的"黑客攻击"顾虑，延伸到由 AI 依赖于三种不同数据流所产生的具体的、结构性的漏洞——每一种数据流都提供了不同的攻击面，需要不同的防御手段。
作者如何使用：以本章三个具名的小节（"输入数据风险"""训练数据风险"""反馈数据风险"）加以组织，每一部分都以一个独特的真实案例加以说明（对抗性视频误分类；微软对必应/谷歌工具栏的逆向工程；微软的 Tay 聊天机器人）。具体到输入数据，本章区分了一种可见的失效模式（崩溃——"看起来可能很糟糕，但至少你知道它何时发生了"）与一种不可见的失效模式（操纵——"你可能对此一无所知，至少在为时已晚之前是这样"），颠倒了"可见的失效更糟糕"这一直觉性假设。具体到训练数据，本章指出攻击会留下痕迹：提取一个模型需要进行大量查询，因此异常的查询量或多样性都应当引起警觉，从而使检测（尽管不是预防）成为可能。
相关概念：训练/输入/反馈数据（第 6 章）、单一化风险
```

```
概念名称：预测机器部署中的单一化风险
定义：这是将生态学类比应用于 AI 系统的一个例子：正如种植单一、统一农作物品种的农民，会降低个体层面的风险（在正常条件下，表现最好的品种胜出），同时增加系统层面的风险（一场疾病或不利条件可能一举摧毁整片统一的作物）一样，在整个车队或系统范围内统一采用某一款"最佳"预测机器的组织，会降低个体层面的失效风险，同时也创造了这样一种可能性——如果这唯一的算法遭到成功的攻击或操纵，整个系统可能同时发生、相互关联的灾难性失效。
为何重要：识别出 AI 标准化决策中一个真实存在、并不显而易见的权衡——使每一个个体单元表现更好、更安全的这种同质性，同时也使整个系统在面对单一的协同攻击时更加脆弱，这与生态学和农业中一项已经确立的原则直接呼应。
作者如何使用：通过农业单一栽培的类比引入，随后直接应用于自动驾驶汽车（对单一车辆的攻击是一种安全风险；同时对使用同一算法的所有车辆发起的攻击，则是一种国家安全威胁），并提出所部署预测机器的多样化，作为一种部分缓解手段，但这一手段本身会以牺牲一定程度的个体层面性能为代价。
相关概念：安全风险分类法、本地（脱离云端）预测作为一种安全缓解手段
```

## 3. 关键主张

```
主张：Latanya Sweeney（美国联邦贸易委员会前首席技术官，现为哈佛大学教授）感到惊讶的是，一位同事在谷歌上搜索她的名字、以查找她的一篇论文时，发现了暗示她曾被逮捕的广告；Sweeney 点击了该广告，支付了费用，确认了她本已知道的事实——她从未被逮捕过。在通过搜索各种姓名系统性地测试这一现象之后，她发现，谷歌搜索一个带有黑人色彩的姓名（如 Lakisha 或 Trevon）比搜索一个像 Jill 或 Jack 这样的姓名，多出 25% 的概率会出现暗示存在逮捕记录的广告。
类型：实证性（有记录的研究发现）
提供的证据：一个具体的、经过量化的数字（高出 25% 的概率），一段第一手的发现叙事，涉及一位具名的、有资历的研究者测试自己以及一位同事（Adam Tanner）的姓名，引用于尾注 2。
支持力度：强——一项来自具名的、有资历的专家（联邦贸易委员会前首席技术官）的具体的、经过量化的、经过系统性检验的发现，与关于在线广告中算法偏见的、有充分记录的、可独立核实的研究相符。
```

```
主张：谷歌种族倾向性逮捕广告模式背后可能的机制，未必是广告主有意进行种族歧视（谷歌对此予以否认），而可能是谷歌自身的质量得分算法：如果潜在雇主在调查求职者时，对出现在带有黑人色彩姓名旁边的暗示逮捕记录的广告更容易点击（相较于其他姓名），那么该广告-关键词组合由此获得的更高"质量得分"，就会导致谷歌的算法为这些姓名更频繁地投放该广告——这意味着，谷歌的算法可能在谷歌或广告主一方都没有任何歧视意图的情况下，放大了一种已经存在的社会偏见（雇主基于姓名产生的差别性怀疑）。
类型：解释性（作者构建的因果假设）
提供的证据：一段逐步的机制性解释，根植于谷歌广告质量得分系统已知的运作方式，呈现为作者们所考虑的可能性之一（另一种可能性是广告主的意图，被谷歌否认），引用于尾注 3。
支持力度：中等——一个合理的、机制上连贯的假设，与广告质量得分算法通常的运作方式相符，但呈现方式是作者们自己的解释性重构，而非一项经谷歌内部数据独立证实的主张。
```

```
主张：经济学家 Anja Lambrecht 与 Catherine Tucker 在一项 2019 年的研究中发现，Facebook 上推广 STEM（科学、技术、工程与数学）岗位的广告，展示给女性的频率低于男性——原因不在于女性点击广告的可能性更低，也不在于某些国家存在歧视性劳动力市场，而是因为年轻女性在 Facebook 上是一个更有价值（因而广告成本也更高）的人群，这意味着 Facebook 的广告投放算法在为每一广告美元的回报进行优化时，自然而然地更倾向于将（同样具有点击效果的）STEM 岗位广告展示给成本更低的受众：男性。
类型：实证性（引用外部经济学研究）
提供的证据：具名的研究者（Anja Lambrecht、Catherine Tucker），一个具体的研究年份（2019 年），引用于尾注 4，配有一条清晰的、经过机制性解释的因果路径（人群广告定价经济学，而非点击率或劳动力市场差异）。
支持力度：强——一项具体的、正式引用的、具有同行评议风格的经济学研究，为一个观察到的歧视性模式识别出了一个精确的、并不显而易见的因果机制。
```

```
主张：即便完全是意外/无意的，个人或组织依然可能因歧视而承担法律责任，纽约市消防局案确立了这一原则——法院认定，该局通过一场侧重阅读理解题目的入职考试歧视了黑人与西班牙裔消防员申请者，该考试被发现与实际工作实效毫无关系，但黑人和西班牙裔申请者在该考试中系统性地表现更差——该案最终以约 9900 万美元和解。
类型：实证性/法律性（有记录的法院判例）
提供的证据：一起具体的、具名的法律案件（纽约市消防局），一个具体的和解金额（9900 万美元），以及一项具体的法律认定（该考试对阅读理解的侧重与工作实效无关），引用于尾注 5。
支持力度：强——一起具体的、正式记录在案的、真实的法律案件，配有可核实的和解金额，用以确立差别性影响责任原则，并附带具体的法律利害关系。
```

```
主张：为 eBay 工作的经济学家（Thomas Blake、Chris Nosko、Steve Tadelis）说服 eBay 在 2012 年将美国三分之一地区的全部搜索广告关闭整整一个月，尽管这些广告（使用传统的相关性统计方法）显示出的投资回报率超过 4000%——而这场为期一个月的真实实验揭示出，这些搜索广告对销售额几乎没有任何影响（真实投资回报率为负），因为 eBay 的消费者足够精明，即便没有看到付费广告，也能通过谷歌普通的（自然）搜索结果找到 eBay，因为无论如何谷歌都会将 eBay 的商品列表排在很高的位置（宝马和亚马逊等品牌也是如此模式）；广告似乎真正起到作用的唯一领域，是为 eBay 吸引新用户。
类型：实证性（有记录的经济学实验）
提供的证据：具名的研究者（Thomas Blake、Chris Nosko、Steve Tadelis），一个具体的年份（2012 年），一个具体的实验设计（在美国三分之一的地区关闭广告一个月），具体的数字（超过 4000% 的测量/相关性投资回报率，对比负的真实/实验性投资回报率），以及具名的对比品牌（宝马、亚马逊），引用于尾注 7。
支持力度：强——一项具体的、正式记录在案的真实对照实验（在本书中，这是真正的因果性实验、而非观察性相关关系的罕见案例），配有戏剧性的、经过量化的、可独立核实的前后发现。
```

```
主张：华盛顿大学的研究者证明，谷歌的视频内容检测算法可以通过插入随机的、不相关的图像（仅持续几分之一秒）而被诱骗产生误分类——短暂到人类观看者永远不会有意识地注意到这些插入的图像（例如，在一段动物园视频中插入汽车图像），但足以扰乱该 AI 的分类结果——这在任何需要可靠地了解实际发布内容以便恰当匹配广告主的环境（例如视频内容广告匹配）中，都构成了一个严重的漏洞。
```

## 4. 框架、模型与思维模型

```
名称：AI 部署的六种风险分类法（要点摘要）
描述：一份总结性分类，明确陈述于本章的"要点"部分，将整章的风险讨论组织为六种独立的、具名的风险类别，任何部署 AI 的组织都应当加以预见。
构成要素：（1）歧视风险——预测可能导致歧视，即便是无意的歧视，也会产生责任。（2）来自数据稀疏的质量风险——当数据稀疏时，AI 效果不佳，尤其是"未知的已知"这种失效模式，即一个自信的预测其实是假的。（3）输入数据安全风险——不正确/被操纵的输入数据可能欺骗预测机器，使用户暴露在黑客攻击之下。（4）单一化/多样性风险——如同生物多样性一样，预测机器的多样性涉及个体层面性能与系统层面失效风险之间的权衡；较低的多样性可能改善个体层面表现，但增加大规模失效的风险。（5）训练数据安全风险——预测机器可以被探询/查询，使你暴露在知识产权盗窃以及能够识别弱点的攻击者面前。（6）反馈数据安全风险——反馈可能被操纵，使预测机器学会具有破坏性的行为。
运作方式：为一个组织的领导层提供了一份检查清单，用以系统性地审计自身的 AI 部署，将本章详述的每一个案例（Sweeney/谷歌广告、Facebook STEM 广告、纽约市消防局、eBay、华盛顿大学视频攻击、微软/必应工具栏、Tay）映射到六个具名风险类别中的某一个。
适用场景：作为任何组织 AI 风险管理规划流程的一份全面的、令人难忘的总结性框架——本章自身对所涵盖全部内容的明确收尾综合。
局限性：本章明确指出，彻底消除所有这些风险是不可能的（"没有简单的解决方案"）——这一框架是诊断性的（有助于识别和预见风险），而非规定性的（它没有为消除每一个风险类别提供一套完整的解决方案）。
```

```
名称："AI 神经科学"——假设、检验、比较的黑箱审计方法论
描述：一套三步走的实用方法，用于诊断一个不透明的 AI 模型为何产生歧视性或其他有问题的输出，而无需直接检视该模型的内部逻辑。
构成要素：（1）对可能驱动跨群体输出差异的因素提出假设。（2）为 AI 提供专门设计用于检验该假设的不同输入数据（保持其他因素不变）。（3）比较由此产生的预测结果，以证实或推翻该假设。
运作方式：完全按照 Lambrecht 与 Tucker 在 Facebook STEM 广告案例中的做法加以应用——假设广告成本/定价（而非点击率或劳动力市场歧视）能够解释这一性别倾向，然后通过专门检视每次展示成本数据来加以检验。
适用场景：每当一个组织怀疑（或希望主动检查）一套无法在算法/公式层面直接探询的黑箱 AI 系统中存在歧视性或其他意外行为时。
局限性：需要审计者已经拥有值得检验的合理假设——这一方法能够证实或推翻关于机制的某个具体猜测，但不能保证发现审计者从未想过要去检验的、未曾预料到的原因。
```

## 9. 违背直觉的洞见

```
洞见：即便没有任何相关人员——无论是广告主，还是平台的工程师——有意进行任何歧视，一套 AI 系统也可能产生系统性的歧视性结果，仅仅因为该系统正在为一个代理指标（点击"质量得分"、每次展示的成本效率）进行优化，而这一指标恰好通过其他人类的总体行为，与某个受保护的特征产生了相关关系。
常见看法：歧视需要一个心怀歧视的行为者（有人有意对不同群体区别对待），或一个明显带有偏见的数据集。
作者的论点：谷歌逮捕广告案例与 Facebook STEM 广告案例都说明，歧视纯粹是从一个中立的优化目标与人类总体行为中既有的模式（不同姓名的点击率差异；不同人群的广告成本差异）之间的相互作用中产生的——无需任何人有意造成或甚至意识到这一歧视性模式，它就能够产生，并带来真实的法律责任。
证据：Lambrecht/Tucker 的 Facebook 研究给出的精确机制性诊断（每次展示成本的经济学，而非点击率差异或劳动力市场歧视），以及作者们提出的谷歌质量得分假设机制。
为何令人意外：它说明了"我们没有歧视的意图，我们的算法是中立的"，不仅是（依据差别性影响法律）一个不充分的法律辩护理由，往往在事实层面也是不完整的——即便系统构建过程中每一个相关人员都是真心无意的，这种歧视依然可能是真实的、可衡量的、机制上可以解释的。
```

## 10. 独特或不寻常的想法

```
想法：将单一栽培风险这一生态学概念（农业作物品种单一化以牺牲个体层面的收益为代价、换取系统层面的灾难性脆弱性）直接应用于 AI 部署标准化决策。
为何显得独特：大多数 AI 安全讨论聚焦于单个系统的漏洞；本章明确借用了一个来自生态学/农业的框架，来推理*车队层面*或*系统层面*的 AI 风险，说明决定一个农业地区是否应该实现作物品种多样化的那套逻辑，同样适用于一个组织（或整个社会）是否应该在其自动驾驶汽车车队或其他依赖 AI 的系统中，实现预测机器算法的多样化。
与其他主题的潜在联系：网络安全领域更广泛的"多样性即防御"原则（例如，软件多样化以防止单一漏洞造成大规模沦陷），以及金融风险管理中的相关性/分散化逻辑。
```

## 11. 张力、矛盾与开放问题

```
议题：本章自身对单一化/系统性失效风险提出的缓解措施（鼓励所部署预测机器的多样性），被明确承认要"以性能下降为代价"，并可能"由于缺乏标准化而增加发生意外性、较小规模失效的风险"——这意味着，针对一个风险类别的解决方案，会直接与个体层面质量以及另一种失效风险类别产生权衡。
作者的立场：透明地承认这是一个真实存在的权衡，而非以一个干净利落的建议加以化解——本章指出这"涉及个体层面与系统层面结果之间的权衡"，却没有具体说明一个组织应当如何权衡这两者。
可能的反驳：读者可能会敦促作者们给出更具体的指引，说明在何种情况下，系统层面灾难性失效的风险严重到足以证明为多样化承担性能代价是合理的（例如自动驾驶汽车或国家基础设施这类安全攸关的系统），而在何种情况下，统一采用单一的最佳表现系统显然是正确的（例如低风险的消费级应用）。
有助于解决此问题的证据：需要有正式的风险建模研究，量化针对不同规模的 AI 部署发起协同性系统级攻击的实际概率与成本，而本章并未引用在本书写作时已存在此类研究。
```

## 19. 用于跨书比较的本章摘要

```
主要论点：部署预测机器带来了不可避免的责任、质量与安全风险，组织必须加以预见和管理，而非彻底消除——歧视可能在没有意图的情况下从中立的优化中产生，相关性 AI 在反事实数据缺失时可能自信满满地给出错误预测，AI 系统在结构上易受对其输入、训练与反馈数据的操纵影响，除了系统性的审计与前瞻性的风险管理之外，没有简单的通用解决方案。
五大核心概念：（1）通过质量得分优化而产生的算法歧视（而非恶意意图）。（2）差别性影响责任。（3）"AI 神经科学"——审计黑箱歧视性行为。（4）未知的已知，作为一种质量风险失效模式。（5）预测机器部署中的单一化风险。
三大核心主张：（1）Latanya Sweeney 发现，暗示存在逮捕记录的谷歌广告，在带有黑人色彩的姓名中出现的概率高出 25%。（2）Lambrecht 与 Tucker 精确诊断出 Facebook STEM 广告的性别倾向是广告定价经济学的产物，而非点击率或劳动力市场歧视。（3）eBay 搜索广告的投资回报率从超过 4000%（相关性）反转为负值（实验性），说明了未知的已知陷阱。
三大核心案例：（1）Latanya Sweeney 与谷歌种族倾向性的逮捕广告。（2）eBay 的搜索广告投资回报率实验。（3）微软的 Tay 聊天机器人。
三大核心研究：（1）Lambrecht 与 Tucker 2019 年的 Facebook STEM 广告研究。（2）Blake、Nosko 与 Tadelis 2012 年的 eBay 广告实验。（3）2016 年的深度学习模型提取研究（650 至 4000 次查询）——均为正式引用的、方法论严谨的研究，使本章成为一个研究密度异常高的章节。
最独特的想法：将农业单一栽培风险这一生态学概念，直接应用于 AI 部署标准化决策，说明车队范围内的算法统一性，会以牺牲系统层面的灾难性脆弱性为代价，换取个体层面的安全性。
最违背直觉的想法：即便没有任何相关人员——无论是广告主，还是工程师——有意进行任何歧视，一套 AI 系统也可能产生真实的、可衡量的、可依法追究的歧视，仅仅是通过一个中立的优化目标与既有的、带有偏见的人类行为之间的相互作用。
最大的弱点或开放问题：本章自身对单一化/系统性失效风险提出的缓解措施（使所部署的 AI 系统多样化），被明确承认会牺牲个体层面的性能，并可能引入与标准化相关的新失效，却没有提供一条明确的规则，说明这种权衡在何时是值得的。
最佳内容创作机会："那个意外变成种族主义的谷歌广告——它揭示了 AI 偏见的什么道理"（第 17 节）——一个具体的、个人化的、经过严谨记录的案例，使无意识算法歧视这一抽象且常被轻视的担忧，变得具体、可量化，并具有法律上的实际后果。
```
